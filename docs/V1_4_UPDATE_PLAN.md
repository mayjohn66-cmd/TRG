## 2. 신규 보드판: 「유령 늪 (`ghost_swamp`)」

### 2.1 트릭컬 리바이브 세계관 반영 설정

- **기원 고증:** 엘리아스의 유령은 사후 영혼이 아니라 **세계수의 꿈에서 태어난 추상 관념계 정령**(혼돈·질서·꿈·정체성·집착)이다. 본래 '어둠의 정령'이었으나 수장 **셰이디**가 촌스럽다며 '유령'으로 개명했고, 늪지대 곳곳의 **폐가**를 제멋대로 점거해 살며 엘리아스 최대 스케일의 장난을 일으킨다.
- **시각 톤 & 팔레트 (`BoardCatalog` 규격):**
  - 바닥 타일(`fill`): `#e8f1f0` (안개 낀 늪지 회청색) · 테두리(`edge`): `#465973` · 잉크(`ink`): `#223147` · 띠(`band`): `#8fa9c2`
  - 코너(`corner_fill` / `corner_edge`): `#ebe5f5` / `#5c4680` (보랏빛 늪 안개)
  - 반환점(`half_fill` / `half_edge`): `#dff2ea` / `#2f7d6e` (도깨비불 청록)
  - 부스터 발판(`dash_base` / `dash_inner` / `dash_pulse`): `#192938` / `#52e5b7` / `#a678ff` (인광 도깨비불)

### 2.2 32칸 특수 발판 규격 (`SHOP_KINDS` + `PORTAL_KINDS`)

| 자리 (칸 수) | 칸 이름 (`id`) | 규칙 및 밸런스 조정안 |
|---|---|---|

|---|---|
| `name` | **어서 와, 내 집이야!** (`WELCOME HOME!`) |
| `condition` | 점거된 폐가에 `{p1}`(6)회 방문 |
| `win_reason` | 점거된 폐가 `%d`회 방문 · 어서 와, 내 집이야! 완성! |
| **승리 컷신 연출** | 삐걱거리는 폐가 문이 열리자 안식의 유령 **메죵**이 앞치마를 두른 채 *"어서 와!"* 하며 집주인 행세를 하는 호러코미디 연출 (`PRESENTATION_SPEC` 비침범 규격 준수). |

### 2.4 보드 예외 규칙

1. **후퇴 하한:** 혼돈 표식 폐가·제단의 `-2칸` 효과로 출발선(`0번`) 이하로 밀리지 않는다 (`maxi(pos - 2, 1)` 고정, 대기실 강제 복귀 불가).
2. **워프 재발동 방지:** `차원 틈새 워프`로 반대편 제단에 도착한 직후의 `±2칸` 튕김은 제단 효과를 다시 발동하지 않는다. 단, 튕겨 도착한 칸의 적 말 처치·함정 발동은 정상 처리한다.
3. **비침범 연출:** 폐가 카드 지급 → 혼돈 표식 `±2칸` 이동 → 도착 칸 판정이 모두 단일 FIFO 연출 큐에서 순차 `await`한다.

### 3.2 도구별 세부 규칙 · 확률표 · 물리 연출 명세

1. **`DICE_PENCIL` — 육각 연필 굴리기 (시험지 찍기)**
   - **족보표:** 6면 균등 — `1번(1칸)` · `2번(2칸)` · `3번(3칸)` · `4번(4칸)` · `5번(5칸)` · **`★주관식 적중(10칸 + 한 번 더!)`** → 1회 EV `4.17`, 재굴림 포함 **`5.00`**.
   - **물리 연출:** 보드 위 3D 육각 연필(5개 면에 볼펜 숫자 `1~5`, 1개 면에 빨간 `★`)이 파워 게이지 세기로 굴러 멈춘 뒤 윗면을 향해 카메라 살짝 틸트 (`0.45초` 뜸).
2. **`DICE_CROC` — 악어 룰렛 (이빨 누르기)**
   - **족보표:** 이빨 8개 중 함정 1개. 누를 때마다 **가속 누적**: 1회 `+2` → 2회 `+3`(누적 5) → 3회 `+3`(누적 8) → 4회 `+4`(누적 12, 최대 4회). `[멈추기]`로 확정, 물리면 **`0칸 + 턴 종료`**. *(해적 룰렛의 고정 `+2`와 차별화, 3회 정지 EV `5.00` · 4회 풀도박 EV `6.00`)*
   - **물리 연출:** 3D 악어 입이 열려 있고 클릭한 이빨이 실제로 쏙 내려감. 함정 이빨이면 턱이 `콰직!` 닫히며 화면 흔들림 + 턴 종료.
3. **`DICE_BOTTLECAP` — 병뚜껑 치기 (책상 절벽 치킨게임)**
   - **족보표:** 파워 게이지(`0~100%`) + 난수 미끄러짐(`±10%`)으로 책상 끝 도달 거리 결정: `0~44%` → `3칸`, `45~69%` → `5칸`, `70~84%` → `7칸`, **`85~96%` (절벽 아슬아슬 걸침) → `★11칸 + 한 번 더!`**, **`97%+` (책상 밖 추락) → `0칸 + 턴 종료`**.
   - **시너지 · 예외:** `[패시브] 풀 파워`(85%+ 보너스 `+2칸`)와 최고의 궁합. 97%+ 추락 시에는 `ends_turn = true`이므로 풀 파워 `+2칸` 미적용.
