## 1부. 규칙 판정 경계 (`core_engine/`)

### 1.1 순위 · 졸업 · 최종 정산

- **완주 판정 (`VictoryChecker.newly_qualified`):** 이동 도중에 말 4개 완주 조건을 채운 플레이어를 즉시 확인한다. 한 번의 이동에서 여러 명이 동시에 말 4개를 완주하면 **현재 차례 플레이어가 먼저**, 그다음은 턴 순서대로 순위를 받는다.
- **특수 승리 판정 (`TurnManager._judge_special_victory`):** 각 차례가 끝나는 정산 시점(이동·처치·방어가 모두 끝난 뒤)과 라운드 끝 NPC 페이즈 직후에만 판정한다(이동 도중이나 말 선택 중에는 기록만 오르고 즉시 졸업하지 않음). 같은 판정에서 여러 명이 동시에 달성하면 **레이스 진행도가 앞선 사람**(`완주 말 수 많음 → 결승까지 남은 거리 합 짧음` 순)이 먼저 순위를 받는다. 앞사람이 졸업하며 법전에서 소멸한 교칙은 뒷사람에게 중복 적용되지 않으며, 뒷사람은 남은 교칙으로 다시 판정한다.
- **졸업 처리 (`GameState.graduate`):** 졸업한 플레이어의 남은 말은 완주 처리되어 트랙에서 빠지고(업기·강제 연대책임 결속도 해제), 그 플레이어가 보드에 깔아 둔 **모든 설치물(함정·호텔)은 즉시 철거**한다(차례가 다시 오지 않아 유지 턴이 줄지 않기 때문). 이미 졸업한 플레이어는 이후 어떤 판정에서도 다시 검사하지 않는다.
- **졸업 이후 진행:** 졸업자의 차례와 증강 드래프트는 건너뛴다. 자기 차례 도중 졸업하면 그 차례는 즉시 종료된다. 남은 미졸업 플레이어가 `1명`이 되면 자동으로 마지막 순위가 확정되며 경기가 끝난다.
- **결과 화면용 스냅샷 보존:** 졸업 시 남은 말을 철수시키므로, 결과 화면 표에는 **졸업 직전 시점의 실제 완주 수·진행도 스냅샷**을 기록해 표시한다. 마지막까지 남은 플레이어는 경기 종료 시점의 기록을 표시한다.
- **최종 순위 산정 (`VictoryChecker.standings`):** 경기 종료 시 미졸업 플레이어는 `완주한 말 수 → 결승까지 남은 거리 합 → 승자 다음 차례부터의 턴 순서`로 순위를 매긴다(미출발 말은 한 바퀴 전체 거리로 계산). 라운드 상한(`PacingDirector.HARD_CAP_ROUND = 25`) 도달 종료 시에도 동일 기준으로 확정한다.
- **AI 대전 조기 종료 (`6.65`):** 싱글 놀이터에서 사람 플레이어가 졸업한 같은 판정 시점에 함께 조건을 채운 AI가 있으면 그 AI는 해당 사유로 먼저 순위를 확정하고, 남은 AI들만 진행도 순(동률 시 턴 순서)으로 매겨 즉시 종료한다. 온라인 대전(빈자리 AI 포함)과 한 화면 4인 수동 모드는 마지막 순위가 날 때까지 끝까지 진행한다.
- **되감기 복원:** `바이츠 더 더스트`(`CNT_01`)로 턴을 되감으면 졸업 여부와 순위 상태도 스냅샷 시점으로 되돌아간다.

### 1.2 특수 승리 기록 집계 경계

> 기본 교칙 목록과 목표 수치는 [`GDD_TDD_Master.md` 4.3절](GDD_TDD_Master.md#43-중앙-법전-공용-특수-승리-교칙-9종)을 따른다.

- **제정 시점 0 초기화 (`SpecialVictory.on_law_enacted`):** 교칙이 법전에 새로 등록되는 순간 전원의 해당 누적 기록을 **`0`으로 초기화**한다. `무한의 함정`(`LAW_03`) 역시 제정 이전에 깔려 있던 설치물은 세지 않는다.
- **방어 창과 기록 반영 지연 (`7.104`):** 피해자가 유효한 방어 카드를 보유해 방어 창이 열리면, 방어 결정이 끝날 때까지 해당 처치를 기록에 반영하지 않는다(법전 진행도 UI에서도 미정 공격은 제외). 방어로 막히면 세지 않고, `[그냥 맞기]`로 확정될 때 비로소 가산한다. `CNT_01` 되감기 시 공격 전 기록으로 복원된다.
- **교칙별 세부 집계 규칙:**
  - `기물 슬레이어`(`LAW_01`): 다른 플레이어가 보드 위에 출격해 있던 내 말을 출발선으로 보낸 경우만 센다. 업힌 스택이 잡히면 **업혀 있던 말 수만큼 각각 가산**한다.
  - `봉인된 에르핀의 식권` 및 보드별 변형(`LAW_02`): 상점 칸(빵집 · 편의점 · 마녀 상점 · 정령산 정령 칸 6곳)에 **정확히 멈춘 횟수**만 센다(`bakery` 키·목표 `6회`·도장 공유).
  - `JACK POT`(`LAW_04`): 한 차례에 말 하나가 전진한 칸 수 합계(부스터 · 템포 업 · 추가 굴림 포함, 최소 `0` 이상)다. 필살기 직선 이동은 템포 업 보너스 없이 실제 이동 칸 수만 센다.
  - `보드연성진`(`LAW_05`): 출발선·완주·업힌 말을 제외하고 트랙 순서대로 앞 말과 **`4칸` 이상**(`VictoryLaw.SPREAD_GAP`) 떨어진 내 말만 센다. 내 차례 끝에 처음 `3개`를 완성하면 **경보(사이렌)**만 울리고, 다음 내 차례 끝까지 깨지지 않고 유지해야 졸업한다(도중 피격·위치 변경으로 깨지면 경보 해제).
  - `구축해 주겠어!`(`LAW_08`): 처치 순간 내 완주 말이 `0개`이고, 잡힌 말의 주인이 나를 제외한 미졸업 플레이어 중 **레이스 1위**일 때만 센다.
  - `방해령 허리케인 포스!!`(`LAW_09`): 손패에 보유한 방해령 종류(`베루·사리·메죵`) 수로 판정하며, **오직 내 차례가 끝날 때만** 달성된다(남의 차례 끝·라운드 끝에는 미판정).

### 1.3 이동 · 부스터 · 결승선 · 보드 칸 경계

- **음수 눈금 없음:** 판정 도구는 음수 눈금을 내지 않으며(실패는 `0칸 + 턴 종료`), 음수 값이 전달되어도 `0칸`으로 고정한다. 뒤로 이동하는 경우는 `방해령 베루`, 벨라티엔 `폭발 물약`, 정령산 `하급 불 정령`처럼 명시된 특수 효과뿐이다.
- **완주 및 당겨진 결승선 (`TempoUp.in_zone_for`):** `0번` 칸을 밟거나 지나치면 남은 눈금과 무관하게 즉시 완주한다. `슬슬 지루한데...`(`AUG_UTIL_SHORTEN_GOAL`)로 앞당겨진 결승선 구간 진입 시에도 즉시 완주하되 다음 예외를 따른다.
  - 미출발 말은 당겨진 결승선 판정 대상이 아니며, 업힌 말은 대표 말과 함께 완주한다.
  - 역주행 이력(`retreated_run`)이 있는 말은 당겨진 결승선 구간 안에 서 있어도 완주하지 않는다.
  - 순간이동 등으로 당겨진 결승선 구간 안에 놓인 말은 다음 라운드 시작 시 완주 처리된다.
- **리벤지 부스터 (`RULE_REVENGE_BOOST`):** 사출 시점에 이미 출발해 트랙 위에 있었고 미완주인 말만 획득한다(업힌 말도 각자 획득). 다음 출발 이동에 기본 `+4칸`(템포 1단계 `6칸`, 2~3단계 `8칸`)이 합산된 뒤 1회 소비되며, 이미 출발선 대기 중인 말을 재사출해도 중첩되지 않는다(`TurnSnapshot` 저장 대상).
- **부스터 발판 (`3·27번`, `RULE_DASH_PAD`):** 일반 굴림 이동(`charge_depth == 0`)으로 정확히 멈췄을 때만 `+3칸` 후속 이동을 수행하며 재연쇄하지 않는다(무인도 감금 말·완주 말 제외). 발판 칸 처치와 착지 칸 처치는 하나의 이동 결과로 합산된다.
- **말 밟고 점프 (`RULE_LEAPFROG`):** 현행 밸런스 테이블에서 비활성화(`enabled=FALSE`)되어 있다.
- **코너 버프 (`8·16·24번`):** 함정이 깔려 있지 않은 코너에 **정확히 멈춘** 말만 다음 굴림 `+1칸` 버프를 받는다(함정이 깔린 코너는 피아·방어·해체 여부와 무관하게 함정 판정만 수행). 옷장 워프·감옥·완주로 코너를 벗어나거나 순간이동 필살기로 진입한 경우에는 받지 못하며, 중복 정차 시에도 `+1`로 유지된다. 다음 실제 굴림 시 기본 눈금(템포 업·도박사 배수 계산 전)에 합산 후 소멸한다.
- **옷장 포탈 (`12·22번`):** 에르핀 왕국 보드에서 정확히 멈췄을 때만 `12 ↔ 22`로 이동하며 도착한 반대편 옷장에서는 재워프하지 않는다. 다른 보드의 동일 번호 칸(자판기 · 마녀의 가마솥 · 정령 칸)은 워프하지 않는다.
- **정령산 정령 배치 (`MountainSpirits`, `1.3.1` 개편):** 판 시작과 **매 라운드 시작(`2라운드~`)마다** 정령 칸 6곳(`5·12·13·19·22·30`)에 `GameState.rng`로 재배치한다. `하급 땅 정령`은 초반 정체를 막기 위해 **언제나 결승선 쪽 `22·30번` 중 1곳(`MountainSpirits.earth_spots`)에만** 배치되고, 나머지 5곳에 불·물·바람이 `2·2·1`곳씩 배치된다. 땅 정령은 지나가기만 해도 그 칸에 강제 정지시켜 남은 걸음을 소멸시킨다. 정령 칸이 없는 보드에서는 난수를 소비하지 않아 타 보드 RNG 시퀀스에 영향을 주지 않는다.
- **호텔 통행료와 후속 이동:** 발판 가속·처치 돌진 등 후속 이동이 호텔 칸에 **정확히 멈추면** 통행료가 발동하고, 지나치기만 하면 발동하지 않는다.
- **단위 테스트 전역 상태 (`BoardSpec` · `boost_gimmicks`):** 칸 번호 정의는 `BoardSpec` 정적 값을 따르므로 테스트에서 `BoardSpec.apply(24)` 변경 시 `TestCase.cleanup`에서 32칸 기본값으로 복원한다. 리벤지 부스터·부스터 발판은 `GameState.boost_gimmicks`(기본 `true`)로 제어하며 순수 이동 단위 테스트에서는 끄고 전용 테스트(`test_boost_gimmicks.gd`)에서 검증한다.

### 1.5 생떼 카드 · 방어 · 함정 경계

#### 1.5.1 방어 창 · 되감기 · 사출 면역 경계 (`CardCounter`)

- **공격 기록과 방어 가능 시점 (`GameState.attack_log`):** 공격 기록은 새 차례 시작 시 비워지므로 방어는 공격한 사람의 차례 안에서만 가능하다. 한 번의 공격 출처(잡기 1회 · 공격 카드 1장 · 상대 함정 1회)는 피해자별로 독립 기록을 남긴다(지뢰 폭발에 여러 명이 휘말리면 각자 방어 결정). 내 차례에 내 말이 상대 함정을 밟아도 방어할 수 있으나, **내 함정 · 내 카드 자해 · 중립 기물 · 모든 초증강 효과**는 방어 대상이 아니다.
- **방어 발동 조건:** 방어 창이 열려 있고 내가 해당 피해자일 때만 1장 낼 수 있다(그 외 시도는 `counter_only_when_attacked` / `counter_pending` 거절). 피해자가 `알고리즘 밴` 상태면 방어 창 자체가 열리지 않는다.

| 방어 세부 구분 | 해당 카드 (`11종`) | 대응 가능한 공격 출처 및 특이사항 |
|---|---|---|
| **`만능 방어`** (1종) | `바이츠 더 더스트`(`CNT_01`) | 모든 공격(잡기 · `[공격 발동]` 카드 · 상대 함정) — 공격자의 이번 턴 전체를 스냅샷으로 되감고 공격자 턴 즉시 종료 (사용된 손패 소비 자체는 유지) |
| **`잡기 방어`** (3종) | `거울의 힘`(`CNT_02`) · `이쪽을 봐라!`(`CNT_08`) · `비상 식량`(`CNT_09`) | 상대 말의 잡기 전용 (`CNT_02`는 공격한 말이 보드 위에 남아 있어야 발동 가능) |
| **`공격 방어`** (4종) | `UDO 리버스`(`CNT_03`) · `감나빗!`(`CNT_04`) · `민트초코`(`CNT_10`) · `긴급수리`(`CNT_11`) | 오직 상대의 **`[공격 발동]` 8종**(`BANG!` · `UDO +4` · `무너지는 탑` · `운명의 수레바퀴` · `일기토 데스매치` · `내 앞을 막지마!` · `펭짱 8호` · `전문적 해킹`)만 방어 가능. **`[너프 발동]` 5종**(`이의 있음!` · `알고리즘 밴` · `UDO 스킵` · `방해령 베루` · `방해령 메죵`)은 공격 기록을 남기지 않아 어떤 방어 카드로도 막지 못함 (`CNT_03` 반사는 공격자 선두 말 사출, `전문적 해킹`만 공격자에게 그대로 반사) |
| **`함정 방어`** (3종) | `싸이크론`(`CNT_05`) · `교단의 칙령`(`CNT_06`) · `도굴꾼`(`CNT_07`) | 상대 함정 전용 (`CNT_07`은 함정 무효화·제거 후 동일 함정 ID를 내 손패로 획득하되 손패 7장 포화 시 획득 생략) |

- **부분 복원 vs 전체 되감기:** 일반 방어 카드(`CNT_02 ~ CNT_11`)는 피해 직전의 말 위치·출발 여부·업기·감옥·보호막 상태 및 해당 공격으로 올랐던 기록만 부분 복원한다.
- **사출 보호막·면역별 허용 출처 (`send_to_start`):**
  - `기억상실빔`(`ACT_16`): 이번 라운드 동안 모든 사출 면역
  - `평화주의자`(`SUPER_13`): 지속 기간 중 말끼리의 잡기 면역
  - `수은 가드`(`ACT_26`): **공격 카드로 인한 사출만 1회 방어** (잡기·함정·중립 기물·초증강에는 미반응 및 보호막 유지)
  - `백돌 방어막` · `긴급 엄폐`(`ACT_22`) · `관심사도 지정` · `이온음료` · `보호의 물약`: **잡기 및 직접 밟은 함정 1회 방어**

#### 1.5.2 개별 발동 카드 예외 경계

- **`UDO +4` (`ACT_03`):** 진행 방향의 다음 플레이어를 지정하되 **이미 졸업한 플레이어는 건너뛰고** 다음 미졸업 플레이어를 대상으로 삼는다(대상의 출격 말이 없으면 사용 불가).
- **`X. 운명의 수레바퀴` (`ACT_08` 빈 보드 예외):** 보드 위에 내 출격 말이 하나도 없을 때 사용하면, 1등 상대의 선두 말(업힌 말 포함)을 출발선으로 사출한 뒤 내 대기 말 중 슬롯 번호가 가장 낮은 1개를 그 자리에 배치한다. 배치된 말은 사출된 말의 진행 상태(반환점 통과 여부 등)를 이어받으며 출발선을 거치지 않으므로 리벤지 부스터를 소모하지 않고 도착 칸의 다른 말도 잡지 않는다(내 말이 전원 완주 상태면 사출만 수행).
- **`싸늘한 밑장빼기` (`ACT_11`):** 야추·블랙잭·홀덤 교환의 중간 단계에는 개입하지 않고 최종 확정되는 결과를 `1~6칸` 지정값으로 덮어쓴다(`0칸` 실패·턴 종료 결과도 지정값으로 변경됨).
- **`XI. The World!!` (`ACT_12`):** 예약된 추가 차례는 그 전에 플레이어가 졸업하면 자동 소멸한다.
- **`슈팡 특급 배송` (`ACT_13`):** 이동 가능한 빈 칸은 `1번 ~ 반환점(16번)` 중 말도 설치물도 없는 칸이다.
- **`피라 대출` (`ACT_24`):** 상환할 빚이 남아 있는 동안 재사용할 수 없다. 사용 당일 턴에는 갚지 않고(`loan_fresh`), 다음 내 차례부터 첫 굴림에 `-3칸`(최소 `1칸` 보장)이 적용되며 실제 이동 굴림이 성사될 때마다 잔여 횟수가 1씩 차감된다(`0칸` 실패 굴림·스킵 턴에서는 미차감 이월).
- **`회유책` (`ACT_25`):** `알고리즘 밴` 중에도 발동 가능하며 **턴당 1장 사용 제한에 포함되지 않는다**. 상태이상이 걸린 차례 시작 시 손패에 보유 중이면 휴식 처리 전에 발동 여부를 먼저 묻고, `[그냥 두기]` 또는 시간 초과 시 원래대로 진행한다(AI는 항상 발동).
- **추가 굴림과 카드 · 밴 · 사용 불가 안내:** 첫 굴림 전에 카드를 쓰지 않았다면 추가 굴림 전 단계에서 카드를 1장 쓸 수 있다(한 차례 총 1장 제한). `알고리즘 밴` 중에는 도구의 추가 굴림 자체가 발생하지 않으며, 추가 굴림 도중 `ends_turn` 결과가 나오면 즉시 차례가 끝난다. 사용 조건 미충족(`could_play == false`)·밴·턴당 제한 카드는 손패에서 어둡게 표시하고 드래그 시 중앙에 구체적 사유를 안내한다.

#### 1.5.3 함정 설치 · 연쇄 발동 경계

- **일반 함정 설치 금지 칸:** 출발선(`0`) · 코너(`8·16·24`) · 상점(`5·13·19·30`) · 장치(`12·22`) · 부스터 발판(`3·27`)에는 일반 함정을 매설할 수 없다.
- **`도미노 연쇄` (`TRP_05`):** 설치자 본인의 말도 걸린다. 밟은 말은 즉시 멈추고 반경 `2칸` 이내의 다른 함정을 가까운 순서대로 모두 강제 기폭한다(눈금 조건 충족 간주, 빈 칸 함정도 폭발 소멸, **연쇄 기폭된 함정은 방어 카드 사용 불가**).
- **강제 이동과 연쇄 함정 한도 (`최대 3회`):** `바나나 껍질`(`TRP_06`) 등으로 밀려난 도착 칸의 함정도 이어서 발동하되 한 이동당 함정 연쇄는 **최대 `3회`**까지만 허용한다(완주·사출 시 즉시 중단). `강제 환승 포탈`(`TRP_08`)로 끌려온 반대편 꼴찌 말은 도착 칸 함정을 판정하지 않는다.
- **코너 함정 세부 판정 (`TRP_C01 · C04 · C05`):**
  - `무인도 감옥`(`TRP_C01`): 감금된 말은 다음 이동 시 **짝수 눈금**이면 정상 탈출, **홀수 눈금**이면 무작위 손패 `1장`을 버리고 탈출한다(버릴 손패조차 없으면 탈출 실패·이동 무효).
  - `물의 세례를 받아라`(`TRP_C04`): 코너로 끌려온 적 말이 기존 코너의 말과 적대 관계면 도착 칸 잡기 규칙이 그대로 적용된다.
  - `이프리트의 분노`(`TRP_C05`): 공개 코너 함정으로 `3라운드` 동안 적 말이 통과·정차할 때마다 주인의 손패 `1장`을 소각해 **덱 맨 밑**으로 보낸다(손패 없으면 무효).

### 1.6 증강 · 초증강 · 범용 보급 경계

- **드래프트 추첨 및 단계별 확장 (`AugmentRegistry`):** 한 번의 3지선다에는 서로 다른 계열이 나오도록 추첨하므로 초증강은 한 드래프트에 최대 `1장`만 등장한다(초증강은 템포 2단계 `14라운드~` 합류). 첫 드래프트(`4R`) 시점에 기본 말이 하나도 없어 기물 진화가 불가능한 경우 타 계열로 3장을 채운다. `알고리즘 밴` 중에도 증강 리롤은 허용된다.
- **`[패시브] 풀 파워` (`AUG_UTIL_FULL_POWER`, `1.3.1`):**
  - **드래프트 등장 조건:** 아직 `풀 파워`를 보유하지 않았고 현재 장착 도구가 **게이지 도구 5종**(`D6 · 윷 · 친치로 · 야추 · 핀볼`) 중 하나일 때만 후보에 등장한다(`test_utility_supply.gd`).
  - **발동 경계:** 굴리기 버튼을 길게 눌러 파워 게이지 `85% 이상`(`FULL_POWER_ZONE = 0.85`) 구간에서 놓았고 기본 굴림 눈금이 `1 이상`(`ctx.dice_value > 0`)일 때만 **`+2칸`**이 합산된다. 짧게 탭해 게이지를 쓰지 않은 굴림(`NaN`), `0칸` 실패 굴림, 비게이지 도구 교체 후 굴림에는 적용되지 않는다. AI 역시 난이도에 비례한 확률로 `0.85~1.0` 구간을 맞힌다(`TurnSnapshot` 복원 지원).
- **범용 보급 · 카드 패키지 예외:**
  - `랜덤 변이 물약`(`UTIL_01`): 대상 말이 업혀 있거나 미출발·`0번` 칸이면 기물만 변이하고 `+3칸` 전진은 생략한다(기존 퀸·쇼기 승급 상태 초기화).
  - `전군 돌연변이`(`UTIL_02`): 완주한 말은 유지하고 미완주 말들을 서로(및 완주 말과도) 겹치지 않는 세부 기물로 일괄 변이시키며 업기 스택은 유지한다.
  - `필살기 리필 주사`(`UTIL_03`): 손패가 가득 차 있으면 카드 보상은 생략하고 필살기만 재충전한다.
  - `종류 지정 카드 패키지`(`CARD_02 · 03`): 내 손패가 가득 차 있거나 해당 풀의 모든 카드가 비활성/밴 상태면 드래프트에 등장하지 않는다.
- **초증강 개별 예외 (`SuperAugments`):**
  - `공산주의 재분배`(`SUPER_02`): 졸업자는 제외하고 미졸업 전원의 진행도를 꼴찌에 맞추며 모든 업기를 해제한다. 회수한 손패는 셔플 후 `2장`씩 재분배한다(덱 잔량 부족 시 가능한 만큼만 분배).
  - `악마의 계약`(`SUPER_03`): 완주한 내 말 1개를 출발선으로 되돌리는 것은 사출이 아닌 **반납**이므로 리벤지 부스터나 피사출 기록이 오르지 않는다.
  - `도적단 대습격`(`SUPER_05`): 카드 없는 상대는 건너뛰며, 내 손패 상한 초과분은 원래 주인에게 반환한다.
  - `에르핀의 빵집 털이`(`SUPER_08`): 대기 말이 없으면 카드 `3장`만 획득하고, 출격한 말은 `5번` 상점 칸 도착 판정(카드·함정·잡기)을 정상 수행한다.
  - `폭주 기관차`(`SUPER_11`): 무작위 한 변의 모든 말(내 말 포함, 적 처치는 내 기록 인정)을 사출하고 **함정만 파괴**하며 호텔 등 비함정 설치물은 남긴다.
  - `강제 연대책임`(`SUPER_12`): 이미 연대 중인 말은 중복 지정하지 않으며, 묶인 짝이 업혀 있으면 스택 전체가 함께 완주·사출된 즉시 연대가 해제된다.
  - `주사위 도박사의 영혼`(`SUPER_06`): 최종 눈금이 `1 이하`면 말 사출 없이 `0칸 · 즉시 턴 종료` 처리된다.
  - 지속형 초증강 4종(`SUPER_13 ~ 16`)의 라운드 정산 세부 규칙은 [`DEV_HISTORY.md` 7.93절](DEV_HISTORY.md)을 따른다.

### 1.7 템포 업 · 라운드 흐름 · 봇 행동 경계

- **템포 업 이동 보너스 (`TempoUp`):** 단순 `0칸` 굴림(스크래치 복권 꽝 등)에는 템포 보너스가 합산되지만, 턴 자체를 종료시키는 실패 굴림(`ends_turn`: 윷 `낙` · 친치로 `쇼벤(낙)` · 타로 `광대` · 블랙잭 `버스트` · 리볼버 `폭죽` · 해적 `당첨` 등)에는 붙지 않는다.
- **8라운드 법전 자동 제정 (`TurnManager._auto_enact_law`):** 8라운드 시작 시 법전에 활성 특수 승리가 하나도 없으면 비활성·중복·방 규칙 밴 항목을 제외한 후보 중 무작위 `1개`를 자동 제정한다(Lv.1 등 상한 0개 설정 시 생략).
- **라운드 종료와 설치물 수명:** 전원이 정확히 1회씩 차례를 마치면(`The World!!` 추가 턴 제외, 졸업·스킵 포함) 라운드가 종료된다. `UDO 스킵` 등으로 차례를 쉬더라도 해당 플레이어의 기간제 설치물 유지 턴은 정상 차감된다.
- **NPC 위험 칸 예고 (`NeutralNPC.danger_preview`):** 난수를 소비하지 않는 순수 함수로 위험 범위를 계산해 락스텝 상태에 영향을 주지 않는다.
- **봇의 공정 정보 제한 및 초반 자비 (`BotBrain`, `1.3.1`):**
  - AI는 상대의 은신 함정 위치·종류를 알지 못하며 오직 자신의 손패와 공개 설치물(호텔 · 코너 함정 · 공개 함정)만 판단 근거로 삼는다. 밴 상태인 봇은 일반·방어 카드를 모두 내지 않는다.
  - **초반 자비 (`1.3.1`):** 난이도 `Lv.1 ~ Lv.2` 봇은 `4라운드` 이전에는 사람 말을 잡는 선택지를 크게 회피한다(유일한 합법 이동이 사람 말 위인 경우에만 처치).

### 1.8 판정 도구 세부 경계

- **공통 결정성과 직접 조작 불변성 (`ToolRegistry` · `ToolPick`, `1.3.1`):**
  - 모든 도구의 판정 결과(족보·합계·핀볼 구멍·복권 문양 등)는 엔진이 `GameState.rng`로 먼저 확정하고 화면은 이를 연출로 재현하므로 락스텝 해시가 어긋나지 않는다(제한 시간 만료 시 다단계 도구는 `cash_out` 자동 확정).
  - 마작·포츈쿠키·아이스크림·오미쿠지·캡슐 손 연출, 해적통 회전·구멍 지정(`prefer_hole`은 연출 순서만 변경), 다트 과녁 회전, 슬롯 레버 정지, 복권 은박 긁기는 순수 연출이므로 난수와 결과에 영향을 주지 않는다. 타로·화투 뒷면 선택(`pick`) 역시 `details.picked`에만 기록되고 난수 소비 순서는 동일하다.
- **`텍사스 홀덤 딜러` (`HOLDEM`, `1.3.1` 1회 교환):** 첫 굴림은 5장을 받는 `can_continue` 단계다. 두 번째 굴림의 `keep`(길이 5 `bool` 배열, `true` = 유지, 누락·길이 불일치 시 전량 교체)에 따라 처음 5장과 버린 카드를 제외한 잔여 덱에서 `GameState.rng`로 새 카드를 뽑는다. 멈추기·시간 초과 시 받은 패 그대로 확정하며, 직접 교환 도입에 따라 페이싱 재굴림·행운 재굴림 대상에서는 제외된다.
- **`야추 다이스` (`DICE_YACHT`):** `keep`(길이 5 `bool` 배열, 첫 굴림 무시)으로 주사위를 고정하며 리롤 잔여 0회 시 현재 족보로 확정한다. 추가 굴림은 오직 5개 동일 눈금(`★야추`)일 때만 부여된다. 족보 우선순위: `야추(12) > 포카드·5연속(9) > 풀하우스·4연속(7) > 트리플(5) > 찬스((최고 눈금+1)/2, 투페어 포함)`.
- **`블랙잭 21 딜러` (`DICE_BLACKJACK`):** 첫 2장 합계가 `11 미만`이면 `11 이상`이 될 때까지 자동 추가 드로우한다(에이스 `11`, `21` 초과 시 `1` 환산). 합계 `21` 달성 시 즉시 `11칸 + 한 번 더`, `22 이상` 버스트 시 `0칸 + 턴 종료`, 스탠드는 합계 `11~20`(`1~10칸`)에서만 가능하다.
- **`클래식 구슬 핀볼` (`DICE_PINBALL`):** 발사 게이지는 속도 연출 및 `풀 파워` 판정용이며, 목표 구멍(`★10` 확률 8%)과 못 튕김 좌우 궤적 6단계 모두 엔진 RNG로 결정된다.
- **`전통 박달나무 윷` · `점성술사의 타로 덱`:** 윷 `낙`과 타로 `광대`는 `0칸 + 턴 종료`(`ends_turn`)이므로 말 선택 단계 없이 즉시 차례가 끝난다. 타로 `매달린 남자`의 다음 굴림 `+8칸` 예약은 다음 차례에 `광대`가 나와도 소멸하지 않고 그다음 유효 굴림까지 이월된다.
- **`지하노역장 친치로` (`CHINCHIRO`, 카이지 4·5·6 3주사위 리워크):**
  - 먼저 `GameState.rng`로 독립 **`1/6` 쇼벤(낙)** 여부를 판정한다. 쇼벤 당첨 시 **`0칸 + 턴 종료`(`ends_turn = true`)** 처리되며 템포 업 이동 보너스와 `[패시브] 풀 파워`는 적용되지 않는다(단, `다이스: 리바이브` 1회 추가 턴 · `수집품: 치비구루미` 50% 재굴림 · `싸늘한 밑장빼기` 덮어쓰기 대상에는 정상 포함).
  - 비낙(`5/6`)일 때 6면이 `[4, 4, 5, 5, 6, 6]`인 사기 주사위 3개를 `GameState.rng`로 각각 추첨한다(메나시 원천 불가, 27조합 등확률). 족보: `4·5·6의 눈`(`4·5·6칸`, 각 6/27) · `시고로 4·5·6`(`8칸`, 6/27) · `444·555 아라시`(`10칸`, 2/27) · `★666 아라시`(`12칸 + 한 번 더`, 1/27). 결과 `details`에 확정 3눈금 배열(`dice`)·족보 키(`hand`)·쇼벤 여부(`shoben`)·장외 이탈 주사위 인덱스(`out_index`)를 실어 연출과 락스텝을 일치시킨다.
- **`해적 룰렛` · `스크래치 복권` (`1.3`):** 해적 룰렛에서 칼 `7자루`(`14칸`)를 모두 안전하게 꽂으면 남은 안전 구멍이 없으므로 자동 확정되고, 해적 당첨 시 누적 칸수가 `0`이 되며 턴이 끝난다. 스크래치 복권의 황금 `×2배` 보너스는 **당첨 문양과 일치한 칸이 황금일 때만** 적용된다(불일치 황금 칸이나 `0칸` 꽝에는 미적용).

### 1.9 일기토 데스매치 세부 경계

### 1.10 데이터 테이블 · 방 규칙 밴 · 버전 잠금

- **CSV 안전 폴백 (`GameData`):** CSV 파일 누락·열 변경 시에도 코드 내장 기본값으로 동작하며 비숫자 문자는 빈 값으로 처리한다. `enabled=FALSE` 또는 `weight=0` 항목은 신규 드래프트·덱 구성에서 빠지되 이미 보유·제정된 상태는 유지한다(`jackpot_step`은 `max_step` 상한 미적용).

### 2.1 단일 FIFO 연출 대기열과 비침범 불변식

> [!IMPORTANT]
> **전 구간 시각 · 청각 비침범 불변식 (`scenes/main_board.gd`)**
> 판정 도구뿐 아니라 **특수 발판 · 이동 · 함정 · 처치 · 중립 기물 · 템포 업 · 법전 · 배너 · 모달** 등 게임 내 모든 연출은 직전 연출의 화면 퇴장과 사운드가 완전히 끝난 뒤에야 다음 연출이 시작된다.

1. **시각 모션 + 사운드 완전 종료 전 후속 스텝 진입 금지:** 도구 연출은 물론 **특수 발판(자판기 · 마녀의 가마솥 · 상점 · 정령 칸 · 옷장 워프 · 부스터 발판 · 코너 버프), 이동, 함정, 처치·사출, 중립 기물, 법전 경보/달성, 템포 업 경고, 배너, 컷신** 모두 화면 퇴장(페이드아웃 · 소품 수거 · 시점 복귀)과 전용 효과음/보이스가 끝난 시점을 종료로 본다. 직전 연출이 끝나기 전에는 다음 단계의 **효과음(경보음 · 팡파르 등) · 화면 흔들림 · 배너 · 모달 · 다음 차례가 절대 먼저 울리거나 화면에 침범하지 않는다.**
2. **조기 반환(Fire-and-forget) 큐 스텝 금지 (`await` 의무화) 및 명시적 비차단 부가 배지 예외:** 연출 큐(`enqueue_step`, `_enqueue_late`)에 등록된 스텝이 내부에서 모달·트윈만 띄우고 `0ms` 만에 즉시 반환하면, 큐가 종료된 것으로 오인해 바로 뒷순서 스텝(템포 업 경보음 등)을 동시에 실행하게 된다. 따라서 자판기 뽑기(`_play_vending_pull`) · 마녀의 가마솥(`_play_cauldron_brew`) · 워프(`_stage_warp`) · 상점/정령/발판 피드백 · 템포 업 배너 등 시간을 소비하는 모든 연출 스텝은 반드시 **자신의 트윈·모달 퇴장 완료까지 스텝 안에서 `await`**한 뒤 다음 스텝으로 넘겨야 한다(`_fx_until_msec`만 늘리고 스텝을 조기 반환해 뒷 스텝 사운드가 먼저 재생되게 하는 처리 금지).
   - **비차단 부가 배지 예외 (`HANDOFF-005`, `2026-11-28` 확정):** 처치·방어 장면의 템포를 해치지 않기 위해, 아래 **2종 소형 시각 배지**는 `1.5초` 완전 퇴장을 기다리지 않고 짧은 여운 후 다음 단계로 넘어가는 것을 예외로 허용한다(단, 턴 종료·템포 업 경보음과 겹치는 특수 발판·모달·배너에는 이 예외를 적용하지 않는다).
     - 리벤지 부스터 장전 팝업 `+N` (`_revenge_charged_popup` · `0.12초` 대기)
     - 방어 성공 `방어!` 배지 (`_show_defended` · `0.45초` 대기)
3. **라운드 말미(특수 발판 · 처치 · NPC) → 템포 업 경고(`tempo_warning`) → 자동 법전 → 증강 드래프트 엄격 직렬화:**
   - 라운드 마지막 차례의 **말 이동 · 특수 발판 연출 · 처치/사출 · 법전 달성 연출**과 라운드 끝 **중립 기물 주행·처치 연출**이 퇴장까지 완전히 끝난 뒤에야 다음 라운드의 `tempo_up` 큐 스텝이 시작된다.
   - `tempo_warning` 반복 효과음(`Sfx.play_repeated`) · 화면 흔들림 · `[템포 업 Lv.N]` 배너는 시그널 수신 즉시 울리지 않고 **반드시 자기 큐 스텝이 실행되는 순간 함께 시작**하며, 배너 퇴장까지 `await`한 뒤에야 `중반 법전 자동 제정 알림 → (0.4초 여운 후) 증강 드래프트 또는 다음 라운드 배너`로 넘어간다(법전 리치 사이렌 · 포위망 경보음도 동일).
4. **진행 중 입력 · 봇 · 턴 전환 잠금:** 연출 큐나 스테이지/모달/컷인/배너가 하나라도 재생 중이면(`_ui_busy()`, `_fx_motion_pending()`, `_fx_holding()`) 유저 입력, `BotController`의 다음 행동, 다음 페이즈 화면 전환을 모두 보류한다(헤드리스 `instant_roll_for_test`에서는 모든 대기 `0초`).
5. **전면 모달과 하위 위젯의 상호 배타성:** 증강 드래프트·확인 창, 방어 팝업, 일기토 결투장, 특수 발판 모달(`VendingPullModal` · `CauldronBrewModal`), 판정 도구 스테이지/매트, 강화·해킹·대상 선택 창이 떠 있는 동안 중앙 굴리기/꺼내기 버튼, 대기 소품(`ToolRestProp`), 타일 툴팁 등 하위 요소는 즉시 숨긴다.
6. **세대 관리 및 필수 회귀 검증 경계:** 새 게임·되감기로 큐 세대(`_fx_generation`)가 바뀌면 `_reset_presentation()`이 진행 중 스텝과 잔류 사운드·노드를 즉시 폐기한다. 연출 수정 시 ① 차례 배너 직후, ② 말 도착 → **특수 발판 완료 후 템포 업 경고음/배너 진입**, ③ 소품 수거 후 말 이동/실패 배너 진입, ④ AI 연속 턴(터보 ↔ 일반 속도 전환), ⑤ `2x`/`3x` 배속, ⑥ 방어 팝업 개입 및 `CNT_01` 되감기를 필수로 검증한다.

### 2.2 이동 · 사출 · 중립 기물 · 결투장 연출

- **장외 홈런 사출과 리벤지 불꽃:** 출발선으로 사출되는 말은 보드 밖으로 날아가는 장외 홈런(`_glide_homerun`) 연출 후 대기석으로 복귀한다. 리벤지 부스터 보유 여부는 프로필 및 기물 독의 불꽃 이펙트로만 표시하며 소비 즉시 꺼진다(발동 시 1~3번째 걸음은 로켓 점프 한 번으로 압축 연출).
- **워프 2단계 연출 (`_stage_warp`):** 옷장 포탈(`12·22번`) 진입 시 `발판 정차 대기 → 워프 배너·효과음(0.45초) → 축소·확대 이동 → 도착 칸 잡기·함정 연출` 순으로 재생한다.
- **상점 카드 획득 알림 및 비공개 원칙:** 최종 도착 칸이 상점이고 미완주일 때만 획득 알림을 띄우며(통과 시 생략), 모든 카드 획득 알림·로그는 장수만 공개하고 카드 정체는 본인 손패에서만 공개한다(손패 7장 포화 시 가득 참 안내).
- **이동 실패 배너:** `0칸` 턴 종료(`ends_turn`), 무인도 탈출 실패(`jailed`), 이동 가능 말 부재(`turn_skipped`) 시 굴림 연출 정리 직후 `[... 이번 턴 이동 실패!]` 카드를 `0.9초`간 표시한다.
- **중립 기물 · 폭주 기관차 · 도미노 알림:** 중립 기물은 소환 알림 1장, 라운드 끝 `[중립 기물 이동]` 알림 1장 뒤 임시 `NpcRunner`가 트랙을 달리며 처치·사출 연출을 이어간다(`폭주 기관차`는 상주 NPC 미등록 주행 연출만 수행). 도미노 연쇄는 `[도미노 연쇄!]` 알림 후 주변 기폭 함정들의 `[발동!]` 알림을 순서대로 띄운다.
- **결투장 모달 (`DuelArenaModal`):** 카드 발동 알림 직후 열려 `2.6초 슬롯 추첨 → 종목 안내 → 미니게임 → 동시 공개 → 결과 → 페이드아웃 및 queue_free` 순으로 동작하며, 모달이 완전히 닫히기 전까지 보드 위 사출·전진 연출은 대기한다(`ui_fx_test`로 노드 완전 해제 검증).

### 2.3 HUD · 판정 패드 · 배속 · 로그 · 알림 배너

- **굴리기 뷰 노출 조건 (`_roll_view_allowed`):** 배너·연출 큐·처치 컷인·오프닝·드래프트·증강 확인 창이 남아 있거나 카드를 드래그·조준 중일 때는 중앙 굴리기/꺼내기 버튼과 대기 소품을 숨기고, 모든 선행 연출이 비워진 프레임에 노출한다.
- **비차단 배너 vs 차단 알림:** 법전·휴식·`The World!!` 같은 비차단 배너는 굴림 시작이나 차단 알림 진입 시 즉시 페이드아웃하며, 라운드·차례 배너, 함정 관문, 템포 업 경고는 종료될 때까지 다음 행동을 잠근다.
- **고아 노드(Orphan Node) 원천 방지 (`PendingAnnouncementExtras` / `ParkedExtras`):** 대기 중인 알림의 카드 미리보기 노드는 숨김 컨테이너에 보관하다가 큐 초기화·취소 시 함께 해제한다.
- **증강 확인 단계 (`PHASE_TIME_REVIEW = 4초`):** 전원 확인 또는 `4초` 경과 시 자동 진행하며, 열려 있는 동안 굴리기 입력을 잠근다.
- **액션 로그 (`MainBoard._record`) 및 텍스트 자동 축소:** 연출 큐 타이밍에 맞춰 기록되어 되감기 시 미노출 로그도 함께 취소된다(은신 함정은 발동 시 공개, 대괄호는 BBCode 충돌 방지용 `[lb]` 치환). 카드·증강 프레임 크기는 고정하고 문구 길이에 맞춰 글자 크기를 자동 축소한다.
- **상태 도장 · 이모트 · 배속 (`1x/2x/3x`):** `밴`·`스킵` 도장은 재접속·되감기 시 즉시 재부착되며 감정 표현(`0~7`)은 연속 사용 시 이전 말풍선을 교체한다. 배속 변경은 싱글 대전 전용이며 배속을 높여도 턴 제한 시간은 실제 초 단위로 흐른다.

### 2.4 모바일 터치 · 다국어 · 사운드

- **모바일 드래그 스크롤 및 더블 탭 차단 (`MobileSupport`):** 터치 기기에서 `10px` 이내 해제는 탭, 그 이상 이동은 드래그 스크롤로 처리해 버튼 오작동을 막는다. 또한 터치 직후 `600ms`·`60px` 내 합성 마우스 클릭을 차단해 배속 버튼 등이 두 번 눌리는 현상을 방지한다.
- **알까기 · 컬링 터치 조준:** 돌이나 병뚜껑 위를 정확히 누르지 않아도 화면 내 터치 시작 지점을 당김 기준점으로 삼는다(컬링은 보드 바깥 터치 시 미시작).
- **다국어 실시간 전환 (`L10n`):** 내부 상태 원문은 한국어로 유지하고 렌더링 시점에 `한국어` / `English` / `日本語`로 변환한다(유저 직접 입력 닉네임은 미번역, 일본어 선택 시 전역 폰트 `Mochiy Pop One` 전환).
- **사운드 재생 경계 (`Sfx`):** 연출 끔 설정 시 차례 배너·설치·경보·초읽기 효과음은 생략하되 증강 확인 창과 결과 시상대 사운드는 유지한다. 헤드리스 테스트에서는 모든 오디오 재생을 생략한다.

### 2.5 성능 · 메모리 · 웹 분할 패키지

- **화면 갱신 배칭 (`processing_started/finished`):** 행동 하나를 처리하는 동안 발생하는 다중 UI 갱신 요청을 중첩 깊이 기준으로 모아 바깥 처리가 끝날 때 단 1회만 다시 그린다.
- **터보 AI 턴 (`TURBO_PACE_SCALE = 0.75`):** AI 차례 연출은 **`0.75배` 시간**(AI 간 처치 컷인 2배속, `2026-11-28` 현행 고정)으로 가속하되, 사람 말이 잡히거나 특수 승리 진행도가 변하는 턴에는 즉시 일반 속도로 복귀한다.
- **메모리 · 3D 저용량 예산 · 웹 분할 팩 관리 (`Web3DBudget` · `GamePack`):**
  - **3D 모델 경량본 참조 강제 (`tests/lowpoly_models_test.gd`):** 런타임 씬은 `assets/models/optimized/v4/`·`v5/`(또는 신규 `vN/`)의 압축 `.scn`/`.res`만 참조해야 하며 원본 `.glb`/`.blend`를 직접 참조하면 테스트가 실패한다. 신규 모델은 [`visual/Visual_Asset_Guide_Draft.md` 6절](visual/Visual_Asset_Guide_Draft.md#6-3d-모델링-폴리곤-수--저용량-운영-상한-규격-131-전수-계측)의 등급별 삼각형·용량·`512px` 텍스처 상한을 넘길 수 없다.
  - **비활성 3D `SubViewport` 파킹 (`Web3DBudget` · `tests/ui_web_3d_budget_test.gd`):** 사전 로딩·재사용 대기 중인 모든 3D 뷰포트는 반드시 `32×32 px` + `UPDATE_DISABLED`로 축소 보관하고 실제 사용 시에만 원래 해상도(표시 크기 `≤ 1.5배`, `MSAA_2X` 상한)로 복원한다(2D 인쇄용 뷰포트는 미축소).
  - **캐시 및 UI 겹침 검증:** 축소 텍스처 영역 캐시는 인스턴스 ID로 식별하고 3D 마작 패 앞면 `SubViewport`는 최근 6장만 유지한다(`MahjongSlam3D.MAX_FACE_VIEWS`). 웹에서 아바타·게임 팩 마운트 시 해당 폴더의 `.import`만 스캔해 중복 없이 UID를 등록한다. UI 버튼·텍스트 치수는 [`visual/Visual_Asset_Guide_Draft.md` 7절](visual/Visual_Asset_Guide_Draft.md#7-화면별-ui-버튼-크기--배치-좌표-고정-규격-1366768) 규격을 따르며 한·영·일 겹침 여부는 `tests/ui_overlap_audit.gd`로 검증한다.

### 2.6 인게임 피드백 · 통계 텔레메트리

- **하이브리드 피드백 전송:** `5자` 미만 입력은 차단하고 전송 성공 후 `60초` 쿨타임을 둔다. 디스코드 웹후크와 구글 폼 중 한 곳만 성공해도 완료 처리하며, 브라우저 정책(CORS·광고 차단기)으로 모두 실패할 경우 쿨타임 없이 클립보드 복사 및 사전 입력 폼 링크 안내로 자동 전환한다.
- **디스코드 통계 3단계:** `로비 최초 입장(세션당 1회) → 매치 시작 → 결과 화면 완료` 3단계로 집계하며, 온라인 방에서는 중복 집계를 막기 위해 **방장 클라이언트만** 대표로 전송한다.
