# 러시안 룰렛 · 폭죽 깃발 장난감 총 v0.1

2026-10-18. 임시 도형 리볼버를 녹색 플라스틱 몸체·크림색 총열·주황색 총구·분홍색 손잡이의 실제 3D 장난감으로 교체했다. 빈 약실에서는 원통이 한 칸 돌고 가볍게 찰칵 잠긴다. 발사 판정에서는 부착된 막대가 뻗고 별 무늬의 분홍 깃발이 펼쳐지며, 총구에서 종이 색종이가 흩어진다. 몸체는 작게 들썩인 뒤 원래 자세로 돌아온다.

`ToyFlagGun3D`를 직접 조작 패드와 다른 플레이어의 결과 팝업에서 공유한다. 총구 화염·탄환·연기와 총성은 사용하지 않는다. 새 이미지나 외부 음원을 가져오지 않고 실제 3D 메시·재질·천 셰이더로 구성했다.

## 기존 판정과 결과 연결

`ToolRussianRoulette`의 추첨과 이동 규칙은 유지한다. 빈 약실은 3칸씩 누적하고 최대 15칸에서 자동 확정한다. 발사되면 기존 누적이 사라지고 턴이 끝난다. 자발적 멈추기는 누적치만큼 이동을 확정한다. 렌더러에는 공개된 `fired`, `accumulated`, `lost`만 전달하며 비공개 장전 위치를 표시하지 않는다.

| 상태 | 시각·문구 |
| --- | --- |
| 빈 약실 | 원통 60° 회전, 사용한 위치만 밝아짐, `찰칵! 누적 N칸` |
| 발사 | 스프링 막대·별 깃발·색종이, `뿅! 누적 N칸 사라짐 · 턴 종료` |
| 자발적 멈추기 | 추가 방아쇠·원통·폭죽 없이 `N칸 이동 확정` |
| 15칸 자동 확정 | 마지막 빈 약실 연출 후 `15칸 이동 확정` |

기존 HUD·결과 로그·규칙 도감의 관련 `탕!`·`실탄 폭발` 문구도 폭죽 깃발 표현으로 바꿨다. 엔진의 식별자와 규칙은 변경하지 않는다.

## 고정 수치

| 항목 | 값 |
| --- | --- |
| 표시 / 렌더 | 결과 팝업 500×300 / 1000×600px, MSAA 2× |
| 직접 패드 | 기존 190×120px를 1.9배 확대하는 배치 유지 |
| 카메라 | 직교 size 4.0, (0,1.6,12) → (-0.15,0.10,0) |
| 본체 기준 / 총구 | (0.85,0.10,0) / 본체 로컬 (-1.38,0.55,0) |
| 원통 회전 | 0.06~0.24초, 매 당김 60° |
| 방아쇠 / 결과 접촉 | 0.16~0.32초 / 0.32초 |
| 빈 약실 결과 공개 / 전체 | 0.48 / 0.85초 |
| 발사 결과 공개 / 전체 | 0.92 / 1.65초 |
| 스프링 막대 | 0.32초부터 0.26초 동안 길이 0→1.8 |
| 깃발 펼침 | 0.43~0.69초, 폭 1.45·높이 0.78 |
| 깃발 메시 | 21×9 = 189개 정점, 실제 천 파형 |
| 천 파형 | Z축 진폭 계수 0.045, UV.x×9 - phase×8 |
| 본체 반응 | 발사 후 0.30초, 감쇠 사인·작은 위치/회전 반응 |
| 색종이 | 18개, 1.02초 비행, 마지막 0.30초 축소 |

막대는 `1-(1-u)^3`으로 뻗고, 깃발은 막대에 붙은 채 펼쳐진다. 천의 별과 테두리는 같은 UV에 그려 함께 흔들린다. 별은 5개 꼭짓점과 내부 반지름 0.105/외부 0.23이다. 발사된 종이는 고정된 속도·각도와 포물선으로 이동하므로 매 재생이 일관되고 게임 RNG를 소비하지 않는다. 본체는 강체 자세를 유지하며 다음 당김 전에 정확한 원점으로 복귀한다.

플라스틱 녹색 `#8ECB6A`, 크림색 `#FFF0C9`, 손잡이 `#EEA0BD`, 총구 `#F6BB61`. 색종이는 `#EFA3C2 / #A5DB76 / #F6CD63 / #8DCFE4 / #FFF0BF`. 빈 위치는 `#88AE68`, 사용한 위치는 `#FFF7DE`다. 장전 위치를 구분하는 색은 없다.

## 수명·UI 충돌 처리

완료·중도 취소·새 게임·도구 교체에서 대기 중인 호출을 풀고 렌더링을 정지한다. 취소한 총은 숨기고 깃발·진행 표시를 정리하며, 다음 당김에서는 같은 캐시를 재사용한다. 천과 종이 메시도 재사용한다.

발사 시 엔진은 즉시 다음 턴으로 넘어간다. `_refresh_roll_pad`는 활성 연출 중일 때 기존 패드와 배치를 유지해 다음 플레이어의 도구가 깃발을 지우지 않게 한다. 빠르게 두 번째 방아쇠를 당길 때 이전 결과 배너가 총을 가리지 않도록 기존 배너의 페이드를 끝내고 숨긴다. 자발적 멈추기는 이전 연출을 안전하게 취소하고 추가 발사를 하지 않는다. 전역 시간 배율이나 네트워크 시계는 멈추지 않는다.

## 임시 사운드

외부 음원 선정은 보류했다. `toy_click`은 약 47ms의 작은 플라스틱 클릭, `toy_party_pop`은 약 236ms의 스프링 같은 `뿅` 합성음이다. 둘 다 0.32초에 한 번, -4dB 보정으로 재생한다. 지나간 프레임의 소리를 늦게 몰아서 재생하지 않는다. 실제 총성인 `shot` 이벤트를 재사용하지 않는다. 기존 사용자 파일 로더·음량·음소거 설정으로 교체할 수 있다.

## 검증

Godot 4.7.1: **355 tests / 74,710 assertions / 실패 0**, `TOY_REVOLVER_OUTCOME_COVERAGE 6/6`, `TOY_FLAG_GUN_FX_OK`, `UI_FX_OK`. 여섯 장전 위치의 기존 판정, 누적·소멸·15칸 자동 확정·자발적 이동 확정, 부드러운 막대 전개, 강체 자세 복귀, 천의 면 방향·카메라 여유, 종이 비행 경계, 결과 숨김, 단일 접촉 이벤트, 캐시·완료·취소·도구 전환·다음 턴 진입을 확인했다.

Native Compatibility의 실제 MainBoard에서 첫 빈 약실(+3) → 다음 발사(누적 3 소멸)를 재생·녹화했다. 자발적 멈추기에서는 추가 발사 없이 3칸 확정되는 것도 별도로 확인했다. 결과 팝업의 누적 6칸 발사도 캡처했다. 실제 발사 뷰포트는 **40 draw calls / 49,120 primitives**, 깃발·종이가 없는 본체는 **19 draw calls / 17,120 primitives**였다. 실제 Movie Writer 영상·오디오로 미리보기를 만든다.

기존 Windows headless 인증서·WebRTC 진단과 종료 자원 경고는 남아 있으며 새 스크립트·셰이더 오류는 없다. 로컬 Native 캡처와 최종 배포 브라우저의 직접 시각 검증은 구분한다.
