# 플레이어 사출 컷신의 그림 강조 효과

실제 `CaptureCutin` 덮개는 이제 화면 가장자리의 마른 붓 움직임 칠, 화살·창의 섬유질 빛 찌르기 잔상, 접촉 순간의 부드럽게 끊긴 마법 안개를 쓴다. 대각선 평면 다각형 배경, 삼각형 속도선 22개, 다각형 찌르기 줄 3개, 마름모 마법 입자, 그려 넣은 접촉 호를 대신한다. 기존 타격 그림에 이미 찢긴 조각이 들어 있어 따로 붙던 삼각형 조각 9개는 뺐다.

8명 캐릭터의 공격·피격 그림, 무기별 강조 종류, 색, 0.96초 연출, 타격음, 글자, 대기열 동작은 그대로다. 그림 잔상은 인물의 타격 정지를 함께 하고 그 뒤 천천히 이어진다. 가운데를 비우고 가장자리 칠을 차분하게 해 얼굴과 무기가 잘 보인다. 평면 어둡게 하기와 위아래 검은 띠는 영화 같은 틀로 남겼다.

새 PNG 원본은 내장 이미지 생성 도구에서 바이트 그대로 복사했다. 프롬프트·실제 원본 경로·투명도 검수·크기·일치하는 SHA-256 해시는 `capture-fx-v08.json`에 있다. 가장자리 덮개는 1024px, 접촉·잔상 텍스처 두 장은 512px로 밉맵과 함께 임포트한다.

## 검증

- `TEST_ONLY=test_capture_cutin godot --headless --path . -s res://tests/run_tests.gd`
- `godot --headless --path . -s res://tests/ui_capture_fx_test.gd`
- `godot --headless --path . -s res://tests/ui_capture_test.gd`

`CAPTURE_FX_DIR`를 주면 실제 렌더러의 둔기·찌르기·베기·마법 장면을 저장한다. 덮개 검사는 아바타 8명 전체, 멈춘 잔상, 타격 1회, 정리, 입력 통과, 좁은·넓은 화면을 다룬다. 기존 실제 보드 잡기 검사는 사건 순서·사출·스냅샷 초기화를 다룬다. CI 표식 `[check:capture-fx]`는 전체 테스트 없이 이 잡기 검사만 돌린다.
