# 조립식 직선 레일 조각

기존 파스텔 장난감 기관차를 위한 직선 레일 모듈 하나. Godot 4.7.1 Compatibility에서 만들고 렌더했다. 기본 자산: `assets/models/runaway_train/straight_track_v01.tscn`, 다른 도구용: 같은 폴더의 `straight_track_v01.glb`, 고칠 수 있는 생성 스크립트: `scenes/runaway_track_3d.gd`.

조각은 X 방향 길이 3.2, Z 방향 폭 2.75, 높이 0.40 단위다. 레일 중심은 Z ±0.96으로 기차 바퀴 중심과 같다. 기존 기차를 레일 원점 위 0.365 단위에 두면 바퀴 접지면이 레일 머리에 닿는다. 기차는 지역 -X 방향으로 달린다.

`Sleepers/Sleeper01`~`Sleeper05`는 따로 다룰 수 있는 묶음이다. 각각 둥근 침목, 받침판 2개, 고정쇠 4개를 담는다. `RailLeft`·`RailRight`는 넓은 바닥, 오목한 몸통, 둥근 머리로 되어 있다. 나중에 레일을 차례로 까는 연출에서 따로 보이거나 움직일 수 있다. 이 자산에는 아직 애니메이션이나 게임 동작이 없다.

`Start`(+1.6, 0.4, 0)와 `End`(-1.6, 0.4, 0)는 이어 붙이기 표식이다. 복사본은 X 방향으로 정확히 3.2 단위마다 반복된다. 레일 끝은 평평하게 잘렸고 0.64 단위 침목 간격이 모든 이음매를 지나 이어진다. 튀어나온 끝 완충기·자갈 바닥·이음매의 중복 침목·레일 주행면을 가로지르는 장식 덮개는 없다.

검증: 저장된 기본 장면과 GLB를 다시 열어 변환·법선이 유한하고 퇴화 삼각형이 0개인지, 레일 부품 6개가 모두 ±1.6에서 끝나는지, 모듈 이음매를 지나는 침목 간격, 실제 기관차 바퀴 축과의 궤간을 비교했다. 모든 버전이 메시 인스턴스 41개·삼각형 7,516개를 유지한다. 스튜디오 화면으로 조각 1개, 이은 조각 3개, 위에서 본 모습, 7개 위에 선 전체 기차를 확인했다. 보고서와 미리보기는 작업 공간 `outputs/runaway-track-v01/final`에 있다.
