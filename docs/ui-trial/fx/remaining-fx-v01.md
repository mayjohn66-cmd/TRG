# 나머지 연출 강조 — 2026-10-27

공통·높은·중간 우선순위 작업 뒤 남은 보조 강조를 마무리했다.

- 캐슬링 출발·도착 표시는 끊긴 그림 물결을 쓰고, 말이 하나씩 내려앉을 때 얕은 먼지가 일어난다. 가운데 룰렛 테두리·칸·고정 바늘은 잘 보이게 유지한다.
- 도적단 습격의 짧은 곡선 빼앗기 휘두름은 끝이 가는 겹친 그림 잔상과 작은 앞쪽 반짝임을 쓰고, 기존 피해자 → 카드 흐름을 따른다.
- 빵집 도착 강조는 그림 바닥 물결을 쓴다. 가게·에르핀·밀가루·빵 세 개·어둡게 하기·보상 순서는 그대로다.
- D6와 윷의 바닥 접촉은 그림 물결·얕은 먼지·질감 조각을 쓴다. D6 그림자는 부드러운 불규칙 자국이다. 기존 바닥 접촉 시계·고정 접촉 위치·놓는 시간·취소가 강조를 그대로 관리한다. 친치로는 3D 그릇을 유지한다.
- 할리갈리 종은 시차를 둔 끊긴 소리 물결 두 개와 얕은 부드러운 그림자를 낸다. 키보드 초점 고리는 분명한 UI 외곽선으로 남긴다.
- 가위바위보는 부드러운 손 그림자, 듬성한 그림 빛, 공개 뒤 사라지는 고르지 않은 승자 반짝임 6개를 쓴다. 선택·결과 외곽선은 자리 구분을 위해 남긴다.
- E카드 승자는 실제 공개된 카드 뒤에 차분한 그림 후광을 받는다. 숨긴 선택·시민 버리기·엔진 기준 결과의 시간은 같다.
- 난이도 라면은 면 위에서 퍼지는 증기 세 줄기를 내어 위로 흐르다 사라진다. 3단계 얼굴의 숨결 두 번은 얼굴의 흔들림·크기·회전 변환을 그대로 따른다. 아이콘 얼굴과 기존 그릇 모델은 그대로다.

모든 그림은 `assets/fx/common`, `assets/fx/priority`, `assets/fx/atmosphere`에서 다시 쓴다. 새 원본 그림·이미지 생성·텍스처 임포트는 없다. 원본 출처는 그 폴더들의 `source.json`에 있다.

실제 OpenGL로 `ui_castling`, `ui_raid`, `ui_bakery`, `ui_remaining_fx`, `ui_rps`, `ui_halli`, `ui_ecard`, `ui_ramen_bowl`이 통과했다. 실제 단계별 스크린샷을 확인했다. `ui_remaining_fx`는 큰 UI 테스트 묶음에서 기존 D6 착지·결과·취소와 윷 착지·낙·결과·취소 검사만 부른다. CI의 `remaining-fx` 범위는 웹 내보내기·배포 전에 정확히 이 8개만 돌리고 게임 전체 테스트는 고르지 않는다.
