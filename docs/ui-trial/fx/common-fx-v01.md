# 공통 그림 타격 효과 — 2026-10-27

착지·타격·카드·프로필 공통 터짐 효과를, 외곽선 원과 텍스처 없는 네모 입자 대신 투명한 그림 스프라이트 두 장으로 바꿨다. 가운데가 빈 충격파는 말 아래 보드 위로 퍼지고, 작은 불규칙 조각은 돌면서 떨어지고 사라진다. 기존 호출부의 색·타격 반경·시간·개수 상한은 그대로다.

움직이는 말의 공통 잔상은 실제 `PawnToken` 그림과 겹친 변환을 그대로 따라 그린다. 점프·회전을 그대로 담아 말 뒤에서 색깔 실루엣으로 사라진다. 멈춰 있는 말은 같은 자리에 잔상을 반복해 찍지 않는다. 원본이 숨거나 지워졌을 때, 효과 끄기, 연출 초기화 때는 생성을 멈추고, 풀에 든 스프라이트와 1회용 정리가 끊긴 트윈도 처리한다.

원본 그림은 실제 투명도를 가진 채 바이트 그대로 보관했다. 충격파는 512px, 입자는 128px로 밉맵과 함께 임포트한다. 프롬프트·원본 경로·해시·투명도 검수는 [자산 기록](https://github.com/mayjohn66-cmd/TRG/blob/dev/assets/fx/common/source.json)에 있다.

검증은 `tests/ui_common_fx_test.gd`로 한다: 실제 제작 함수, 실제 렌더, 텍스처·입자 크기 상한, 투명한 가운데, 색·사라짐, 변환된 실루엣 위치와 겹침 순서, 정상 만료, 풀 재사용, 초기화, 원본 해제, 효과 끄기, 게임 난수·시뮬레이션 시계 불변. 워크플로의 `common-fx` 범위는 이 테스트만 돌린 뒤 평소처럼 웹 내보내기·배포를 한다.
