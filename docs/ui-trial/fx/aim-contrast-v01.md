# 저격수·BANG! 조준 표시 대비 — 2026-10-28

두 조준 연출 모두 짙은 자두색(`#35152b`) 외곽선 위에 선명한 진홍색(`#ff365c`)을 쓴다. 연한 타일·풀밭·색깔 있는 말 위에서도 조준 표시가 묻히지 않게 하기 위해서다. 저격수는 조준을 고정할 때 빨간 고리가 금색으로 바래지 않고, 안쪽 눈금과 고정 진행 표시는 밝은 크림색 강조를 쓴다. 주 조준선 굵기는 2~2.2에서 3 논리 픽셀로 늘렸고, 6px 바탕선을 깔아 폰 크기에서도 가는 외곽선이 남는다.

원래 조준선 모양·비어 있는 가운데·움직임·목표 좌표·카메라·발사 시점·명중 효과·게임 규칙은 그대로다. 새 그림이나 화면 효과는 추가하지 않았다.

터치 배치를 켠 채 844×390, 740×360, 1366×768에서 실제 렌더를 비교했다. 조준 중심 6곳 모두 실제 목표에 붙어 있었다. 기존 `ui_sniper_test.gd`·`ui_bang_test.gd`가 조준·발사·실제 사출·초기화 검사를 통과했다. CI의 `bang` 범위는 이 두 연출만 검사한다. 사용자의 소리 선호에 따라 로컬 테스트 실행은 `--audio-driver Dummy`로 소리 없이 돌린다.
