# 무기별 잡기 강조 효과

셰이디의 낫은 칼날을 따라가는 하늘색 초승달 그림을 쓰고, 빠르게 다가가는 동안 위에서 아래로 드러난다. 0.12초 타격 정지 동안 인물과 함께 멈췄다가 느린 반동 동안 사라진다. 가운데가 비어 있고 칼날 옆에 놓여 두 얼굴이 모두 보인다.

버터의 새총, 실라의 활, 다야의 직검 찌르기는 오른쪽으로 가는 가는 잔상을 쓴다. 이 네 무기 공격에는 더 이상 큰 원형 주먹 터짐이 붙지 않는다. 주먹·손바닥은 원형 충격을 그대로 쓰고, 벨리타는 마법 터짐을 그대로 쓴다.

승인된 캐릭터 그림 16장, 잡기 사건 규칙, 0.96초 연출 길이는 바뀌지 않았다. 효과는 정해진 시각 표본만 쓰고, 시뮬레이션 난수를 쓰거나 전체 시간 배율을 바꾸지 않는다.

`capture-fx-v06.png`는 실제 게임 렌더러에서 셰이디가 다야를 공격하는 장면이다. `capture-fx-v06.mp4`는 실제 대기열을 거친 보드 잡기를 60fps로 찍은 것이다. 소리는 시스템 녹음이 아니라 기존 효과음을 미리보기용으로 따로 맞춘 것이다. 프롬프트·생성 도구 기록·원본 해시·투명도 검수는 `capture-fx-v06.json`에 있다. 원본 PNG는 바이트 그대로 두고, 게임에서는 1024px 밉맵 텍스처로 임포트한다.

검증: 단위 테스트, 실제 잡기 UI 수명·입력 정리, 연출 대기열 검사, 아바타 8쌍 전체 실제 렌더, 묶음 안 텍스처·의존성 검사를 포함한 웹 내보내기.

배포 검사에서 원래 있던 AI 프로필 갱신 누락도 드러났다. 봇의 첫 걸음이 `has_left_start`를 켠 뒤에도 프로필 칸이 '대기'에서 '출전'으로 바뀌지 않았다. 이제 걸음 처리에서 그 주인의 네 칸만 다시 그린다 (차례 표시등·이동 대기열은 건드리지 않음). 첫 걸음 검사가 수정 전에는 실패하고 수정 뒤에는 통과한다.
