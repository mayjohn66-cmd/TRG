# 높은 우선순위 연출 그림 — 2026-10-27

가장 우선순위가 높은 연출 묶음 4개를 투명한 그림 강조로 바꿨다.

- **아우토반 니트로:** 불꽃 다각형·삼각 기류·채운 별·마름모 조각 대신 파란 겹 불길, 질감 있는 바닥 물결·격자, 가벼운 접촉, 도는 작은 조각을 쓴다. 기존 근접 카메라·타격 정지·피해자 동시 풀기는 원래 시계를 쓴다.
- **리벤지 부스터:** 프로필·벤치 불꽃은 같은 그림 불길을 주황색으로 쓴다. 움직일 때 배기는 진행 반대 방향을 따르고, 크기가 정해진 스프라이트 풀로 돌아간다. 퍼지는 원형 연기는 없다.
- **판 뒤집기:** 성공은 속이 빈 그림 압력파, 말 모양 공통 잔상, 금색 불꽃 배기를 쓴다. 실패는 규칙적인 지그재그와 채운 원 대신, 끝점을 잰 실제 갈래 번개 스프라이트와 작은 질감 접촉을 쓴다. 동전 던지기·결과·발사 시간은 그대로다.
- **저격수의 표적:** 의도된 조준선은 남긴다. 총알은 기존 끝이 가는 BANG! 탄도 셰이더를, 명중은 작은 그림 불꽃을 쓴다. 무대가 말 층의 변환을 따르고, 그 층이 움직이거나 커져도 초점 가림막이 화면을 계속 덮는다.

새 원본 3장(불꽃·번개·접촉)은 직접 이미지 생성에서 바이트 그대로 복사했고, 투명도를 보존하고 임포트 UID를 기록했다. 게임 내 제한은 불꽃·접촉 256px, 번개 512px. 기존 공통 물결·조각과 잡기 잔상 텍스처를 다시 쓴다. [프롬프트·경로·투명도 검사·원본/최종 해시](https://github.com/mayjohn66-cmd/TRG/blob/dev/assets/fx/priority/source.json).

검증 범위는 `ui_priority_paint_test.gd`, `ui_nitro_test.gd`, `ui_sniper_test.gd`, `ui_flip_test.gd`. 실제 OpenGL 실행이 통과했고, 게임 안의 점화·질주·타격·동시 비행·부스터 프로필·배기·저격 명중·동전 두 결과를 캡처했다. 엔진 기준 이동·결과, 단계 순서, 게임 난수·시간 배율 불변, 끝점 정렬, 카메라 복원, 취소, 임포트 크기 상한, 배기 풀 재사용을 확인한다. CI의 `priority-fx` 범위는 평소 웹 내보내기·배포 전에 이 4개만 돌린다.
