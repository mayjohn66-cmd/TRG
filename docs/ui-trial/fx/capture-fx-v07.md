# 잡기 글자 연출 "A SINGULAR STRIKE!"

적 말을 잡으면 두 캐릭터 그림과 함께 **A SINGULAR STRIKE!** 문구가 정확히 이 철자로 나온다. 이 문구는 직접 생성한 투명 그림이다: 좁은 고딕 장식 글자, 거친 검은 잉크 가장자리, 금색에서 주황빨강으로 이어지는 획, 절제된 버건디 그림자.

글자는 0.14초 접촉 박자에 탁 나타나고, 0.26초 타격 정지 동안 두 인물과 함께 멈췄다가, 반동 동안 살짝 내려앉고, 0.96초 전에 컷인과 함께 사라진다. 보이는 영역은 표준·4:3·초광폭 화면 모두에서 얼굴 위 빈 자리에 들어간다. 잡기 취소·중복 억제·이어지는 다음 상대는 기존 시각 수명 처리를 따른다.

원본: `assets/fx/capture/singular_strike.png` (2172×724 RGBA PNG, 바이트 그대로 보관). 게임에서는 2048px 밉맵 텍스처로 임포트한다. 전체 생성 프롬프트·생성 도구 기록·해시·투명도 검사는 `capture-fx-v07.json`에 있다.

`capture-fx-v07.png`는 실제 렌더러의 셰이디/다야 접촉 장면이다. `capture-fx-v07.mp4`는 실제 대기열을 거친 보드 잡기를 60fps로 찍은 것이다. 미리보기 소리는 시스템 녹음이 아니라 같은 기존 효과음을 따로 맞춘 것이다.

검증: 시간·정지·화면 경계 단위 검사, 실제 잡기 UI 수명과 난수·상태 안전성, 아바타 8쌍 전체 실제 렌더 검수, 웹 내보내기와 묶음 안 글자 그림·의존성 검사. 기존 캐릭터 그림과 무기별 효과는 그대로 쓴다.
