# 폭주 장난감 기차 모델

제공된 파스텔 장난감 기관차 참고 그림을 바탕으로 한 정적 모델: 둥근 파란 보일러, 크림색 띠, 산호색 차대와 배장기, 둥근 금색 지붕, 갈색 기관실 창, 돋을새김 숫자 3, 큰 동륜 6개. 그 뒤로 파랑·버터 노랑·민트·라일락 색 무개 화물칸 4개가 크림색 난간과 보이는 널빤지 바닥을 가지고 따라온다. 화물칸마다 바퀴 4개.

최종 자산은 `assets/models/runaway_train/runaway_train_v02.tscn`이고 옆에 다른 도구용 `runaway_train_v02.glb`가 있다. `scenes/runaway_train_3d.gd`가 고칠 수 있는 모델 생성 스크립트다. 실제 메시와 PBR 재질이며 참고 그림을 판으로 붙인 것이 아니다. 모델은 지역 -X를 향하고, Y가 위, Z가 바퀴축 방향이다. 기관차, 화물칸 루트 4개, 바퀴 축 22개, 앞뒤 연결 표식, 연결봉 4개를 나중 애니메이션을 위해 따로 둔다. 아직 게임이나 기차 공격 애니메이션에는 연결하지 않았다.

`scenes/runaway_train_preview.tscn`은 따로 살펴보는 장면이다: 왼쪽 끌기로 카메라 회전, 휠로 확대, 1은 기관차, 2는 기차 전체를 화면에 맞춘다.

Godot 4.7.1 Compatibility에서 만들고 렌더했다. 저장된 기본 장면과 GLB를 다시 읽어도 메시 인스턴스 270개, 삼각형 86,912개, 바퀴 22개, 화물칸 4개가 같다. 위치·법선이 유한하고, 면적 0 삼각형은 지웠고, 연결 4쌍의 높이·좌우 정렬이 맞는다. 전체 크기는 약 19.02 × 3.39 × 2.50 모델 단위, GLB는 약 0.8MB. 스튜디오 미리보기와 자세한 검증 보고서는 작업 공간 `outputs/runaway-train-v02/soft-studio/`에 있다.
