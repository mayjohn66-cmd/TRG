# 단색 심볼과 타일별 방향 v0.2

2026-10-21. 이전 v0.1의 입체감과 광택을 줄여 달라는 요청에 따라 보드 그림 여섯 종을 단순한 픽토그램으로 다시 생성했다. 빵은 타원과 세 개의 홈, 옷장은 문틀과 손잡이, 깃발은 막대와 체크 또는 삼각형, 진행 표시는 화살표와 삼중 꺾쇠만 남겼다.

빵·옷장의 방향은 보드 전체의 고정 X축이 아니라 각 타일의 축을 따른다. 가로축은 해당 변의 진행 방향(타일의 짧은 변), 윗방향은 보드 중심, 아랫방향은 판 바깥쪽이다. 각 타일을 같은 방향으로 돌려 정면에서 보면 같은 배치가 된다. 코너·부스터는 다음 칸을 가리키는 방향을 사용한다. 깃발이 있는 두 코너의 작은 진행 화살표와 코랄 부스터 발판은 유지했다.

PNG는 native image_gen.imagegen으로 만든 1254×1254 투명 원본이다. 빵 초안의 거친 가장자리와 홈은 도구에서 한 번 보정했다. 원본을 재가공하지 않고 복사하며, 런타임 flat_ink.gdshader가 알파 윤곽을 사용해 단색으로 칠한다. 원본의 미세한 색 변화와 광택이 화면에 남지 않는다. 빵 갈색·옷장 청록·진행 초록·부스터 크림색의 색상 구분을 사용한다. 기존 256px 임포트·품질 0.85·밉맵을 유지했다.

실제 MainBoard, 확대 보드, 빵집 네 곳·옷장 두 곳·코너 두 곳의 단일 타일, 부스터 위 함정을 캡처해 확인했다. 24/32칸에서 방향·보드 기울기·아이콘 윗방향 검사를 포함한 전체 495개 테스트가 통과했다. 기존 Godot 종료 시 자원 경고는 남아 있다.

assets/board/decals/manifest.json에 원본·전체 프롬프트·보정 이유·SHA-256·알파 윤곽 영역을 기록했다. 워크스페이스 outputs/board-symbols-v02/에는 PNG 원본, tiles.png, board.png, game.png, trap_override.png, 교체 전 그림, 거절 초안, 생성 프롬프트, 배포 검증 기록을 보관한다.
