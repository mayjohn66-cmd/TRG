# 신규 즉발 카드 삽화 1차

ACT_10~15의 이모지 임시 그림을 전용 캐릭터 삽화로 교체했다. 기존 CardSkin이 읽는 정확한 ID 파일을 바꿨으며 게임 규칙과 카드 효과는 변경하지 않았다.

| ID | 카드 | 캐릭터 | 효과 표현 |
| --- | --- | --- | --- |
| ACT_10 | 빠루 | 에르핀 | 빠루 휘두르기·적 말과 함정 제거 |
| ACT_11 | 밑장빼기 | 셰이디 | 덱 아래에서 카드 빼기·주사위 |
| ACT_12 | 더 월드 | 다야 | 시계·말을 감싸는 추가 턴 화살표 |
| ACT_13 | 어디로든 문 | 실라 | 문을 통과해 빈 칸으로 이동 |
| ACT_14 | 알고리즘 밴 | 엘레나 | 카드·필살기·리롤 금지 표시 |
| ACT_15 | 우노 스킵 | 버터 | 상대 말을 건너뛰는 턴 화살표 |

내장 이미지 생성 도구로 개별 생성했다. 1448×1086 원본 PNG를 그대로 저장했으며 UID와 1024px 런타임 압축 설정은 유지했다. SHA256과 치수는 assets/cards/illustrations.json에 기록했다. 카드명·설명은 게임 데이터에서 표시한다.

실제 CardSkin의 확대/손패 크기 6종, MainBoard의 손패와 확대 화면을 렌더해 자산 연결과 전체 그림 비율을 확인한다. 검수 이미지·프롬프트·교체 전 백업은 작업 산출물 outputs/cards-actions-v01에 보관한다.
