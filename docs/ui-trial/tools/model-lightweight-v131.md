# 3D 게임용 리소스 경량화

2026-11-27. 사용자 요청에 따라 작은 화면에서 드러나지 않는 지오메트리를 줄이고 게임용 파일을 경량본으로 연결했다. 원본은 덮어쓰지 않았다.

- `assets/models/optimized/v4/`의 압축 네이티브 리소스로 42개 연결을 교체했다. 쿠키·접시·캡슐 기계와 키링·물약·해적 룰렛·리볼버·다트·핀볼·자판기·기차·라면 등이 포함된다.
- 엔진 메시 단순화, 중복 정점 인덱싱, 사용하지 않는 정점 제거, 공통 메시·재질·텍스처 공유를 적용했다. 텍스처는 최대 512px이며 알파와 문양을 유지했다.
- 게임용 모델 파일 묶음은 **16.45MB → 2.64MB(약 84% 감소)**, 처리한 고유 메시의 삼각형은 **612,541 → 107,247(약 82% 감소)**, 정점은 **755,329 → 92,295(약 88% 감소)**다. 전체 게임 다운로드 크기와는 구분한다.
- 실루엣을 크게 바꾸는 LOD는 자동으로 거부한다. 노드 경로·부품 위치·회전축·표면 순서·UV·재질은 보존했다. 42개 파일, 1,402개 노드와 실제 저장한 텍스처를 다시 읽어 검사했다.
- 기존 모델과 시제품·중간 경량화본은 웹 내보내기에서 제외했다. 원본 파일은 그대로 남아 있으며 검증과 재제작에 사용할 수 있다.
- 실행 중 만드는 주사위·마작 몸체와 라면 그릇의 과도한 곡면 분할도 낮췄다. 판정·물리·확률·애니메이션 타이밍은 변경하지 않았다.

검증: `lowpoly_models_test.gd`, `test_dice_roll_3d`, `test_mahjong_slam`, `test_pinball_3d`, `test_toy_flag_gun`, `ui_hand_tools_test.gd`, `ui_ramen_bowl_test.gd`, `ui_vending_3d_test.gd` 통과. 모든 테스트는 Dummy 오디오 드라이버로 무음 실행했다. 원본/경량본을 같은 카메라와 조명에서 렌더하여 비교했다.
