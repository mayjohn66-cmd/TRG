# 1.3.1 직접 조작 연출 연속성 보강

2026-11-26 사용자 피드백: 고르기 화면 뒤 기존 결과 연출을 다시 재생하면 같은 물건을 다룬다는 느낌이 끊긴다. 선택한 소품과 카드가 그 자리에서 결과까지 이어지도록 수정했다.

- **포춘쿠키:** 접시에서 꺼낸 3D 쿠키의 위치·방향을 이어받아 두 조각과 종이를 펼친다. 같은 SubViewport와 접시가 유지되며 종이 문구는 화면에도 크게 표시한다. 기존 낙하·흔들림 연출을 다시 재생하지 않는다.
- **아이스크림:** 선택한 포장지를 위로 꺼내고 윗부분과 몸통을 나누어 벗긴다. 그 아래의 같은 맛 아이스크림을 같은 위치에서 먹고 막대의 결과를 공개한다. 기존 먹기·막대 쌓기 동작을 IceboxPickArt 내부에 유지한다.
- **오미쿠지:** 흔들기 한 번에 3회 왕복한다. 뽑기는 기존 화면의 통에서 곧바로 막대가 나오며 자동 흔들기를 다시 넣지 않는다. 대길 종이 묶기와 누적 줄은 유지한다.
- **캡슐 뽑기:** 동전 투입 후 카메라가 레버에 접근한다. 사용자 회전 동안 확대를 유지하고 회전 완료 후 줌 아웃과 함께 캡슐 배출·개봉을 이어 간다.
- **마작:** 기존 MahjongSlam3D의 실제 입체 패와 문양·후면 재질을 재사용한다. 뒷면 패 13개를 붙여 놓고 3개를 하나씩 뒷면으로 꺼낸 뒤, 모두 같은 시각에 뒤집는다. 선택 중 결과를 미리 노출하지 않는다.
- **홀덤:** 첫 결과부터 HoldemExchangePanel 테이블을 유지한다. 딜러 덱에서 5장을 차례로 지급하고, 선택한 패는 딜러 쪽으로 회수한 뒤 같은 슬롯에 새 패를 지급한다. 유지한 카드의 노드와 좌표는 바뀌지 않는다. 최종 족보를 함께 공개한다.
- **화투:** 세 패 중 고른 두 패를 기존 홀더에서 뒤집는다. 고르지 않은 패는 뒷면으로 남기며 다른 결과 화면을 새로 만들지 않는다. 시간 초과에 의한 미완료 선택은 기존 자동 판정 흐름을 유지한다.

결과 확률·이동 값은 엔진을 유지한다. 직접 조작 연출이 완료된 뒤에만 MainBoard의 결과 공개와 다음 행동으로 이어진다. 새 게임에서는 진행 중 테이블과 고르기 창을 정리한다.

검증: `ui_seamless_tools_test.gd`는 결과 전 노출 방지, 동일 소품·카드 인스턴스 및 위치 유지, 공동 뒤집기, 최종 패 일치를 검사한다. `ui_hand_tools_test.gd`, `ui_connected_props_test.gd`, `ui_tool_pick_test.gd`도 관련 동작을 확인한다. 영상은 `capture_connected_tools.gd`로 실제 MainBoard 입력을 재현하고 Movie Maker에서 30fps, 효과음만 출력한다.
