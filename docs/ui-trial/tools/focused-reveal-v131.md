# 선택 후 중앙 공개와 공통 테이블 UI

2026-11-26. 사용자 후속 피드백을 `seamless-tools-v131.md` 위에 반영했다.

- 포춘쿠키를 고르면 남은 쿠키와 접시를 치운다. 선택한 인스턴스를 연출 중앙으로 옮기고 같은 위치에서 두 조각과 종이를 펼친다. 종이는 카메라 중심을 따라가며 별도 소품으로 다시 등장하지 않는다.
- 아이스크림을 고르면 나머지 포장지·얼음·아이스박스를 치운다. 선택한 포장지를 중앙으로 꺼내 160×225 표시 크기로 키운다. 내부 아이스크림 몸통과 막대의 전체 범위를 감쌀 수 있는 크기다. 윗부분과 몸통을 벗긴 뒤 같은 위치에서 먹고 막대 결과를 공개한다.
- 오미쿠지통에서 나오는 물체를 나무 막대 대신 흰색 말린 종이로 바꿨다. 뽑기 → 말린 종이 이동 → 펼치기 → 글씨 공개 → 대길이면 줄에 묶기 순서다. 글씨는 완전히 펼친 뒤에만 보인다.
- `JudgmentTableStyle`이 마작·홀덤·화투의 녹색 바탕, 테두리 색과 두께, 둥근 모서리, 여백, 화면 어둡기, 표시 레이어를 공유한다. 화투의 별도 밝은 안쪽 판과 제목 띠는 제거했다. UI 문구는 코드로 그리고 검은 외곽선을 유지한다.

검증: `ui_seamless_tools_test.gd` 41개 항목(선택하지 않은 소품 제거, 실제 공개 중심, 포장지의 전체 아이스크림 포함, 공통 테이블 색/테두리, 말린 종이 공개 시점 포함), `ui_connected_props_test.gd` 55개 항목, 기존 직접 조작 및 선택 UI 검사. 실제 MainBoard에서 입력을 재현해 효과음만 넣은 영상을 다시 출력한다.
