# 직접 선택형 판정 도구 연출 — 1.3.1

- 기준: `docs/visual/Visual_Asset_Guide_Draft.md` v1.0, COMMON-02/04/05/07/08/09.
- 대상: 타로·화투·홀덤·마작·오미쿠지·포츈쿠키·아이스크림·캡슐 8종.
- 선택창은 공통 녹색 제목 띠, 밝은 본체, 연두색 선택 면을 사용한다. 제목·진행 문구는 번역 가능한 실제 텍스트이고 밝은 제목은 검은 외곽선을 둔다.
- 항목은 0.035초 간격으로 차례로 놓인다. 호버 시 8px, 선택 시 16px 들리고 선택 순서 배지가 붙는다. 하단 진행 칩은 색상과 체크 표식을 함께 쓴다. 상태 전환은 고정된 홀더 안에서 그림만 움직이므로 클릭 영역과 행 배치는 변하지 않는다.
- 카드: 기존 판정 카드 뒷면 재사용. 마작: 초록 뒷면·상아색 층·아래 두께. 오미쿠지: 가는 나무 막대·붉은 끝.
- 쿠키·캡슐: 기존 `fortune-cookie-whole.glb`·`capsule.glb`를 재사용. 선택 미리보기는 결과·내용물 없이 닫힌 모델만 표시한다. 320×320 독립 뷰포트를 4프레임 준비 후 정지해 대기 중 3D를 계속 렌더링하지 않는다.
- 아이스크림: 도구 아이콘 대신 실제 `IceCreamView`의 먹기 전 모습을 재사용한다.
- 완료 후 0.38초 동안 선택 대상을 강조하고 기존 굴림으로 이어진다. 후보 수, 선택 수, 취소·시간 초과 처리, 확률과 결과 계산은 변경하지 않는다.
- 실제 보드의 굴리기 버튼·카드 더미 위에 암전·선택창을 표시한다(`z_index=80`). 터치 직후 에뮬레이션 마우스를 무시해 한 번의 터치로 선택과 취소가 동시에 일어나지 않게 한다. Tab 포커스와 Enter/Space 선택도 지원한다.
- 구현: `scenes/tool_pick_modal.gd`, `scenes/tool_pick_prop.gd`. 공통 면은 `UiSkin.surface`를 사용한다.
- 검증: `ui_tool_pick_test.gd`(실제 보드 연결), `ui_tool_pick_presentation_test.gd`(8종 × 3언어 × 2화면 크기, 중복 완료 방지·선택 순서·영역 검사), `test_tool_pick.gd`(결과·난수 불변). 실제 렌더 이미지는 작업 출력 폴더에 보관한다.
- 로컬 결과: UI 276개 검사 통과, 실제 보드 연결 검사 통과, 규칙 3개 테스트·198개 단언 통과. 선택 연출 검사는 전체 배포 CI에도 연결한다.
