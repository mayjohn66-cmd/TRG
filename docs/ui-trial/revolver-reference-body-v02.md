# 사진 비율 기준 리볼버 본체 v0.2

사용자가 다시 제공한 400×240 은색 리볼버 사진의 측면 실루엣을 기준으로 본체 비율을 수정했다. 실린더를 제외한 독립 3D 모델이다. 게임 표시 크기에 맞춰 부품을 짧게 만들지 않고, 완성 모델의 전체 배율로 축소한다.

비율 기준: 사진의 `(244, 71)`을 실린더 중심 `(0, 0.30)`으로 두고 1px를 0.04 모델 단위로 환산했다. 외곽을 따라 잡은 제어점으로 프레임·손잡이·해머·방아쇠울을 만들었다. 작은 모서리의 곡선이 과하게 튀어나오지 않도록 곡선 핸들 길이를 제한했다.

변경 사항:

- 총열 길이 4.10 → 6.92. 둥근 주 총열 아래에 끝까지 이어지는 하부 커버를 추가했다.
- 검은 손잡이를 사진의 길이·기울기·아랫부분 형태에 맞췄다. 이전의 굵은 은색 손잡이 테두리를 줄였다.
- 짧은 해머 돌출부, 방아쇠울, 측면판, 실린더 해제 레버와 작은 나사를 사진 위치에 맞췄다.
- 빈 실린더 창: X `-1.08~1.32`, Y `-0.82~1.42`. 기존 실린더 연결 기준점 `(0, 0.30, 0)`과 Y축 +90° 방향은 유지한다.
- 정면 비교에는 기울이지 않은 측면 시점을 사용하고, 사선 영상으로 두께를 확인한다.

파일: `assets/models/revolver/body_v02.scn`, `body_v02.glb`. v0.1 파일도 보존한다. 미리보기는 `scenes/revolver_body_preview.tscn`이다.

검증: 저장된 씬의 빈 실린더 공간·방아쇠울, 프레임·손잡이의 실제 면, 연결 기준점을 광선으로 확인했다. GLB 저장·재읽기 및 측면·양쪽 사선 렌더링 확인 완료. 인게임 판정·UI 로직 변경은 없다.
