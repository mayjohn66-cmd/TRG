# 결투 게임 고르기 슬롯

ACT_09는 이제 미니게임 6종이 모두 든 넓은 카지노 릴 하나로 시작한다. 표마다 게임 이름과 상징이 있고, 램프가 돌고 레버가 당겨진 뒤 드럼이 느려지며 엔진이 정한 게임에 멈춘다. 잠긴 표를 짧게 보여 준 뒤 큰 설명 화면이 따로 뜨고, 그다음 기존 게임 조작이 열린다. 릴 아래 설명 줄은 없다.

- 릴: 2.6초, 이어서 잠긴 표 0.55초. 700px 폭 설명 화면에 게임마다 큰 목표·조작·주의를 적는다. [시작]/[보기] 버튼으로 바로 넘어가고, 아무도 누르지 않거나 구경꾼 화면이면 실제 시간 6.05초 뒤 자동으로 넘어간다. 게임 속도 설정으로 읽는 시간을 줄이지 않는다.
- 새 추첨이나 게임 난수를 쓰지 않는다. 게임은 여전히 엔진이 고른다. 처음 기록이 화면에서 멈추기 전에 결과를 미리 알려 주지 않는다.
- 봇과 내 입력은 소개가 끝날 때까지 기다린다. 이미 받은 네트워크 결과는 대기열에 남는다. 입력 제한 시간에 6종 모두 소개 시간을 더한다.
- 기존 종·리볼버·카드 그림과 단순한 가위·병뚜껑·통 상징을 다시 쓴다. 그림 용량은 늘지 않는다.
- 도는 중에 닫으면 릴을 취소하고 입력 잠금을 푼다. 창은 쓸 수 있는 화면 크기에 맞춘다.

검증: 단위 테스트 516개·단언 596,466개·실패 0, 결투 6판을 끝까지 하는 기존 UI 연출 전체 테스트, 6종 고르기·대기열·취소 테스트, 데스크톱과 짧은 모바일 화면 렌더 캡처.

큰 소개 화면 후속: 기존 UI 연출 전체 테스트와 6종 고르기 테스트가 [시작] 버튼으로 넘어가기, 자동 넘어가기, 입력 시계 잠금, 데스크톱·모바일 렌더 캡처를 포함해 통과한다. 캡처 산출물: 작업 공간의 `outputs/duel-intro-v02`.

경기 중 무대 아래의 고정 설명도 뺐다. 한 화면 대전 차례는 위쪽 참가자 줄을 쓰고, 실시간 피드백과 결과는 그대로 보인다.

미뤄 둔 카드 미리보기는 이제 숨겨진 대기 알림 노드가 바로 소유한다. 연출을 취소하면 대기 중인 자식도 해제한다. 테스트가 소유와 취소를 확인하고, 기존 결투 6판 고아 노드 수 회귀 검사도 유지한다.
