# 기물 보호막 표시 (2026-10-27)

백돌의 고유 `shield`와 관심사도 지정의 `ward`를 공통 유리 보호막으로 표시한다.
말 뒤의 옅은 푸른 면과 말 앞의 투명한 반사·테두리를 나누어 기물이 보호막 안에
들어 있는 느낌을 준다. 보호막은 실제 기물 그림 높이와 업은 받침 높이에 맞춘다.
PawnToken을 공유하는 보드와 프로필 슬롯에도 같은 표시가 붙는다.

획득·재충전 시 0.32초 동안 차오르고, 마지막 방어가 소모되면 0.32초 동안
갈라져 사라진다. 백돌과 증강 보호막이 함께 있으면 하나가 소모될 때는 빛만 반응하고
남은 보호막을 유지한다. 완주한 말은 표시하지 않는다. 재충전으로 파괴 연출을
취소할 때 이전 콜백이 새 보호막을 숨기지 않도록 기존 트윈을 종료한다.

보호막은 토큰의 자식이라 이동·점프·확대에 함께 움직인다. 유휴 상태의 반짝임은
셰이더에서 처리하고 CPU의 `_process`를 추가하지 않는다. 보호막 사각형은 마우스
입력을 받지 않으며, 말 그림·플레이어 받침색·잡기 및 함정 방어 규칙은 유지한다.
모션을 생략할 때도 보호 중이라는 정적 표시는 유지한다.

검증: `tests/ui_shield_test.gd`만 실행했다. 실제 방어 소모·중첩·재충전,
진화 후 유지·상태 복원·연출 도중 재충전·이동 추적·완주·모션 생략·입력 통과,
보호막 상태 툴팁과 영·일 번역을 확인했다. 네이티브 OpenGL 렌더링에서
43개 확인 항목 실패 0건이며, 생성·유지·파괴 장면을 보드 크기로 확인했다.
CI의 `[check:shield]`도 해당 확인 스크립트만 실행한다. 전체 게임 검사는 실행하지 않았다.
