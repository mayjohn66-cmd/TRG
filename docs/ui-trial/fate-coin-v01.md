# 판 뒤집기: 양면 코인 판정

SUPER_01의 규칙은 유지한다. 엔진이 내 말 하나를 고르고, 이미 결정한 즉시 완주/출발선 추방 결과를 코인으로 보여 준다.

선택된 말에 빛을 모은 뒤, 보드 중앙에서 실제 3D 코인이 튀어 올라 4회전한다. 가장자리 두께와 금색 별/붉은 X의 양면을 구분하고, 내려오며 회전이 느려진다. 결과를 0.28초 읽을 수 있게 멈춘 뒤 해당 말의 완주 비행 또는 추방 연출을 진행한다. 코인은 페이드 아웃하며 제거되고, 3D 렌더링은 코인 포즈가 바뀌는 프레임에만 실행한다.

- `scenes/fate_coin_3d.gd`: 결과가 고정된 코인과 로컬 투명 3D 뷰포트. 게임 RNG를 사용하지 않는다.
- `scenes/super_fx.gd`: 기존 드래프트 공개 이후 순서에 연결. 결과가 보이기 전에 말 이동을 시작하지 않는다. 초기화 시 대기를 중단하고 코인을 제거한다.
- `tests/ui_flip_test.gd`: 판뒤집기만 실제 드래프트/엔진 경로로 적용해 성공·실패 두 결과, 판정 전 위치 유지, 판정 일치, RNG 보존과 정리를 확인한다. 다른 초증강은 실행하지 않는다.

배포 커밋 `[check:flip]`은 위 전용 검사만 선택한다.
