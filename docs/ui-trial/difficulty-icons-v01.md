# Difficulty expressions and status icons — 2026-10-27

The five difficulty faces now use one native-generated transparent expression atlas. Columns progress from buttery heart eyes to a red dizzy spicy face; the second row supplies registered blink/smile/gasp alternates. Cached per-cell alpha bounds hold both rows at a fixed 52px size and centre. Selection pop, idle bob and the hottest level's slight wobble retain one animation clock. The hottest face's three small flames also use the approved flame artwork. No procedural face, heart, sweat-drop or flame silhouette remains in the selector.

The previously delivered flame, crown and padlock PNGs are now connected to the actual selector and record row. Lit flames retain their orange/gold colours; future cells use a shared lavender grayscale shader. A completion crown depends on the saved completion record, independently of which difficulty is selected. Uncompleted levels retain their padlock. Existing button dimensions, selection colours, records and bowl timing remain.

Sources are copied byte-for-byte into `assets/ui/trickcal/difficulty/`. Flame/crown/lock originals are 1254×1254 RGBA with 128px runtime limits; the new face atlas is 1983×793 RGBA with a 1024px runtime limit. Transparent gutters and tiny rendering were checked. Generated frame offsets are corrected through runtime regions; no PNG repaint, masking, rescaling or compositing was used. [Exact prompts, original/final paths, hashes and QA](../../assets/ui/trickcal/difficulty/source.json).

Native OpenGL `ui_difficulty_icons_test.gd` passed actual pointer input across all five cells, one selection signal per click, matching face/bowl state, saved completion badges, muted flame state, all ten frame regions, and hidden animation stop/resume. The same test opens the production training menu and confirms that its button input persists difficulty through `GameSession`. The existing focused bowl check also passed. The removed legacy polygon helper's assertion was removed from `ui_menu_test.gd`; that file passes a parse-only check. CI scope `difficulty-icons` executes these two focused cases and the menu parse check before export/publication; it does not run the full menu/game suite.
