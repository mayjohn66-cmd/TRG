# 나머지 7명 로비 아바타 고해상도 대기 동작

트릭컬 스파인 뷰어(https://viewer.dclnslde.com/)의 공개 기본 사도 모델에서 Normal 스킨, Idle_1을 원본 PNG 프레임 전체 내보내기로 추출했다. 카메라 1536px, 16fps, 상호작용 끔, ZIP + 전체 PNG 프레임, 스파인 크기 맞춤 끔 설정이다. 기존 저해상도 프레임 확대나 생성형 재작화, 화면 스크린샷을 쓰지 않았다.

프레임 PNG는 원본 ZIP에서 복사한 바이트 그대로이며, 각 idle_hq/manifest.json에 SHA256·원본 경로·타임스탬프·공통 실루엣 영역을 기록했다. 캐릭터마다 하나의 AtlasTexture 영역을 모든 프레임에 공유해 중심과 크기가 흔들리지 않게 했다. 초기 적용은 1024px 무손실·밉맵이었으며, 용량 경량화 요청에 따라 과거 에르핀 경량화 커밋 fd0053d의 640px·WebP 품질 0.85·밉맵 제거 설정으로 변경했다. 런타임 해상도·압축 품질을 낮춘 대신 1536px 원본은 그대로 보관하며, 기존 에르핀의 현재 1024px 무손실 설정은 유지한다.

HubKit.avatar_full은 기존 경로에 따라 idle_hq.tres를 우선 사용한다. 애니메이션은 캐릭터별 PCK로 분리되어 본체 첫 로딩 용량에 들어가지 않는다. 묶음을 받기 전의 정지 그림 대체와 감정 반응은 기존 경로를 유지한다. 선택한 로비 노드가 대기 프레임을 참조하고 로비 노드가 해제될 때 참조가 내려간다.

원본 스켈레톤(.skel), 아틀라스(.atlas), 텍스처 PNG는 작업 결과 outputs/avatars-hq-20261025/source/<Name>/에 별도로 보관했다. 원본 ZIP도 같은 결과 폴더에 남겼다. 게임에는 전처리된 프레임 리소스를 넣으므로 별도의 Spine 런타임을 추가하지 않는다.

검증 범위는 아바타다. 새 7명 원본 해시·알파·프레임 수·잘림·공통 크롭을 확인하고, 에르핀을 포함한 8명의 실제 HubKit 대기 루프 선택·재생 전환·노드 해제 및 임포트 크기를 검사한다. 그래픽 실행의 첫·중간·마지막 프레임을 캡처해 확인하며, 웹 내보내기 후 아바타별 PCK 연결을 별도 검사한다. CI의 [check:avatar-hq]는 이 범위만 선택한다.
