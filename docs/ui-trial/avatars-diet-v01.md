# 나머지 7명 아바타 대기 프레임 경량화

사용자가 지정한 에르핀의 과거 경량화 방식은 커밋 fd0053d의 640px·WebP 품질 0.85·밉맵 제거다. 당시 에르핀의 임포트 프레임은 약 29.5→2.9MiB로 줄었고, 이후 5a7c64c에서 에르핀은 1024px 무손실·밉맵으로 복원됐다. 이번에는 새로 추가한 7명에 요청된 과거 경량화 설정을 적용했다.

1536px PNG 원본 310장, 16fps, 프레임 수, 루프 길이와 공통 실루엣은 보존했다. 게임 임포트만 1024px 무손실·밉맵에서 640px WebP 0.85·밉맵 없음으로 변경했다. 해상도와 압축 품질을 낮추는 방식이므로 무손실 최적화로 표기하지 않는다. AtlasTexture 영역은 원본 영역×640/1536으로 같이 바꿔 로비 표시 크기와 위치를 유지했다. 에르핀의 현재 설정은 변경하지 않았다.

## 검증

원본 310장 SHA256이 기존 추출 기록과 일치한다. 실제 로비 높이(StartMenu.HUB_AVATAR_HEIGHT, 520px)에서 변경 전후를 캡처하고 비교했다. 8명의 실제 HubKit 루프 선택·프레임 전환·공통 크롭·영역 경계·노드 해제 검사를 통과했다. 웹은 기존 avatar-hq 범위로 대기 루프와 내보낸 아바타 PCK 로드만 검사하며 전체 게임 검사를 돌리지 않는다.

비교 이미지와 상세 바이트 측정은 작업 결과 outputs/avatars-diet-20261025/에 있다. 원본 PNG, 이미지 안의 캐릭터 그림, 감정 반응 리소스, 재생 코드는 변경하지 않았다.
