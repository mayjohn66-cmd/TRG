# 병뚜껑 절벽 컬링

기존 자동 충전 게이지를 제거했다. 탑뷰 테이블에서 병뚜껑을 누르고 뒤로 당겼다가 놓으면 반대 방향으로 즉시 튕긴다. 세기는 당긴 거리에 비례한 속도로 연결되며, 숫자 게이지 대신 노랑→주황→빨강으로 커지는 가는 화살표를 표시한다. 큰 규칙 안내는 대결 시작 전에만 나온다. 방향키로 조준·세기를 조정하고 Space 또는 아래 버튼으로 쏘는 조작도 같은 입력 경로를 사용한다.

두 사람이 같은 판에서 신청자부터 한 번씩 쏜다. 첫 병뚜껑이 멈춘 뒤 두 번째 사람이 조준할 수 있고, 충돌로 먼저 놓인 병뚜껑을 밀거나 절벽 밖으로 떨어뜨릴 수 있다. 움직임이 모두 끝난 뒤 살아남은 쪽, 둘 다 남았다면 절벽에 더 가까운 쪽이 이긴다. 같은 거리·둘 다 추락은 기존 신청자 판정승을 유지한다. 기존 기물 사출·승자 전진은 그대로 연결된다.

## 물리와 동기화

`core_engine/bottle_cap_physics.gd`가 입력·정수 고정소수점 위치와 속도·정수 제곱근으로 120Hz 시뮬레이션을 계산한다. 일정한 미끄럼 마찰, 동일 질량 원형 충돌, 반발계수 0.82, 측면 레일 반사, 회전 감쇠, 절벽 이탈을 처리한다. 엔진 판정과 화면은 이 계산기를 함께 사용한다. 프레임 보간이나 미리 정한 도착점으로 충돌을 흉내 내지 않는다. `Engine.time_scale`이나 게임 RNG를 바꾸지 않는다.

첫 투구가 차지한 위치를 다음 사람이 볼 수 있도록 컬링은 엔진에서도 순차 입력을 받는다. 세기·방향은 정수 하나로 묶여 기존 `duel_pick` 명령과 동기화 페이로드를 통과한다. 봇은 자기 차례에만 쏘고, 시간 초과는 그 자리의 최대 직선 투구를 진행한다. 네트워크에서 두 입력과 결과가 먼저 와도 첫 투구→두 번째 투구→결과 순서로 끝까지 재생한다.

화면은 충돌 때 짧은 금속성 소리·섬광·45ms의 로컬 멈춤, 회전·짧은 잔상, 절벽 밖에서 작아지며 떨어지는 모션을 더한다. 창 크기 변경·포커스 이탈·취소된 OS 터치는 잡고 있던 제스처를 취소한다. 비활성 자리·빈 곳 클릭·아주 작은 드래그·중복 릴리즈는 투구를 만들지 않는다. 닫기·보드 리셋은 대기 중 정착 신호도 풀고 노드를 제거한다.

## 병뚜껑 그림

내장 `image_gen.imagegen` 도구로 생성했다. 크림색 에나멜 상판·초록 네잎클로버·톱니 금속 테두리를 가진 정면 탑뷰 스프라이트이며 원본 투명 알파를 유지한다. 플레이어 색은 외곽 링과 옅은 색조로 구분한다. Godot 가져오기는 최대 256px, WebP 0.85, 밉맵으로 설정했다.

## 검증

`tests/test_bottle_cap_physics.gd`는 입력 코딩, 마찰 정지, 충돌에 의한 운동량 전달·상대 추락, 빗맞힘·측면 반사, 정수 재생 결정성·엔진 승자 일치를 검사한다. `tests/test_duel.gd`는 두 번째 자리의 선입력 거부와 투구 동기화·시간 초과·봇 진행을 검사한다.

`tests/ui_curling_test.gd`는 실제 ACT_09 사용→마우스 투구→터치 투구→밀어내기·추락→기물 사출→정리를 실행하며, 30·60·144 FPS에서 같은 물리 결과인지 검증한다. 조준 위치, 미세 드래그·중복 릴리즈·OS 취소·리사이즈 취소, 먼저 도착한 원격 결과 대기와 닫기 취소도 검사한다. 네이티브 PC·844×390 모바일 캡처와 시연 영상은 작업 폴더 `outputs/duel-curling-v01/`에 저장한다.
