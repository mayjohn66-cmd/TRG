# 웹 로딩 화면: 쁘띠 스핔이

로딩 화면의 영문 부제를 삭제하고 기본말 마커를 트릭컬 스파인 뷰어의 **펫 → 쁘띠 스핔이** 원본 동작으로 교체했다. 이전 로딩바 디자인은 `loading-bar-v01.md`에 기록되어 있다.

- 출처: <https://viewer.dclnslde.com/>, 뷰어 ID `Pet_MiniSpeaki`.
- 동작: `Move`, 스킨 `Shadow_Off`. 뷰어의 일시정지·타임라인·현재 프레임 PNG 저장 UI로 투명한 512×512 프레임 12장을 내보냈다. 원본을 새로 그리지 않았다.
- 전체 프레임에 동일한 정사각형 영역을 적용해 자르고 128×128로 축소한 뒤 가로 스프라이트 시트로 묶었다. 프레임마다 개별 크롭하지 않아 원래 동작의 상하 움직임을 보존한다. 원본 파일 해시는 `web/loading-petit-speaki.source.json`에 있다.
- 표시 크기 64×64, 12프레임/0.4초 반복. 이미지 하나만 요청하며 별도 Spine 런타임이나 Godot PCK가 필요 없다. 배포 워크플로가 `web/loading-petit-speaki.webp`를 웹 빌드에 복사한다.
- 표시 컨테이너를 좌우 반전하고 최초 배치보다 2px 아래(`top: -59px`)로 조정했다. 프레임 시트의 재생 순서는 유지한다.
- 실제 진행률을 따라 이동하며 양 끝에서는 전체 펫이 프레임 안에 남도록 제한한다. 총량 미상·오류 상태에는 숨기고 동작을 일시정지한다. `prefers-reduced-motion`은 첫 프레임으로 고정한다.
- 기존 기본말 PNG와 코드로 만든 초록 받침대·추가 상하 움직임은 제거했다. 게임 안의 기본말 에셋은 이 변경과 별개다.

`tests/e2e/loading_splash.mjs` 통과: 1366×768, 664×526, 844×390, 667×375. 실제 부팅 콜백의 총량 미상/0·1·61·99·100%, 펫 이미지 로드와 프레임 변화, 레일 양 끝 범위, 영문 부제 삭제, 움직임 줄이기, 완료·오류·미지원 환경을 확인했다. 테스트 캡처의 61%는 미리보기 상태다.
