# 연속 성공 표시 — 2026-10-29

- 러시안 룰렛: 탄피 없이 현재 보너스 하나만 +3 → +6 → +9 → +12 → +15로 갱신한다. 새 숫자는 짧게 튀어 오른 후 정착한다. 실패 시 +0과 턴 종료를 표시한다. 진행 중 성공 횟수·누적 문구·탄피 스택은 표시하지 않는다.
- 리치 역만: 실제 3D 점수봉을 하나씩 포갠다.
- 블랙잭 21: 실제 3D 배팅 칩을 하나씩 포갠다.
- 룰렛 7, 타로 운명의 수레바퀴, 확정 야추: 별·달·엄지척 잉크 도장을 한 번씩 찍는다.
- 윷·모: 글자 도장이 나온 순서대로 남는다. 기타 눈금과 턴 종료 표시는 유지한다.

성공 판정은 결과 공개 완료 이벤트만 사용한다. 실패, 일반 히트, 야추 중간 재굴림, 단순 확정은 성공을 추가하지 않는다. 턴/플레이어/도구가 바뀌면 비운다. 도장·3D 물건은 최대 최근 6개만 보이지만 총 성공 횟수는 유지한다. 정착하면 프레임 처리와 연속 3D 렌더를 중단한다.

보드 본체 main_board.gd는 수정하지 않는다. 작은 main_board_roll_success.gd 확장이 트로피의 옆 배치와 중앙 결과 문구의 접미어 제거를 담당하고, main_board.tscn이 이 스크립트를 사용한다. 이는 원래 큰 보드 파일 전체를 업로드하지 않고 UI 변경만 배포하는 구조다.

생성 도장: 내장 image_gen.imagegen 1회. assets/ui/trickcal/roll_success_v01/*.webp, 각 288×288 RGBA 무손실. 별·달·엄지척 원본의 알파 경계 자르기·균일 축소·투명 여백만 적용했다. 프롬프트, 원본 경로, SHA256, QA는 art.source.json. 윷·모는 기존 게임 폰트와 작은 잉크 마모 셰이더를 사용한다.
