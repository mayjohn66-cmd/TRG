# 피격 방향 및 두 인물 간격 수정

8명의 피격 PNG를 내장 image_gen.imagegen으로 다시 생성했다. 공격 PNG는 유지한다.
새 포즈는 왼쪽을 보는 얼굴과 오른쪽으로 젖혀진 머리·어깨를 함께 보여 준다.
왼쪽에서 오른쪽으로 오는 공격을 받는 방향이며, 팔과 머리카락도 뒤로 날린다.
원본 캐릭터와 기존 포즈를 참조해 의상·장식·색상·굵은 외곽선을 유지했다.
PNG 원본 바이트와 투명 알파를 보존하고 기존 hit.png 경로를 교체한다.
실제 프롬프트·출력 경로·해시·이전 버전 기록은 avatar-capture-poses.json에 있다.

화면 배치는 공격 지점과 피격 지점 사이에 화면 너비의 10% 여백을 둔다.
타격 높이만 맞추고 상대 얼굴에 주먹·무기를 직접 겹치도록 강제하던 배치를 제거했다.
등장 크기도 약간 줄였으며, 반동은 일관되게 화면 오른쪽으로 이동한다.
보드 암전, 짧은 정지, 0.5초 재생, 실제 선택 아바타 매핑은 유지한다.

에셋: content_trickcal/avatars/avatar_01~08/hit.png (8장).
실제 게임 캡처: avatar-capture-v02.png.

검증: 실제 잡기·선택 아바타·역할 역전·일반 복귀 제외·스냅샷 정리 UI_CAPTURE_OK.
네이티브 렌더러에서 8개 조합과 실제 잡기 화면을 확인했다. 웹 내보내기 성공,
약 98.3 MiB로 게시 제한 이내다. 모든 PNG는 1254×1254 RGBA다.
