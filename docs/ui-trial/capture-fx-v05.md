# 잡기 타격감: 진입·정지·슬로모션·복귀

기존 0.5초 연출을 0.96초로 조정했다. 판정이나 온라인 시뮬레이션은 건드리지 않는다.
CaptureCutin의 시각 좌표만 별도 시간 곡선으로 재생하며 Engine.time_scale은 유지한다.

- 0–0.14초: 공격자의 빠른 진입과 짧은 잔상, 카메라 줌 인.
- 0.14–0.26초: 두 인물과 줌의 좌표를 고정하는 0.12초 히트 스톱.
- 0.26–0.72초: 피격자가 오른쪽으로 천천히 밀려나고 줌이 조금 더 다가온다.
- 0.72–0.96초: 반동을 빠르게 풀며 원래 보드로 돌아온다.

투명 붓 터치 충격 에셋(assets/fx/capture/ink_impact.png)은 내장 image_gen.imagegen으로
생성하고 원본 PNG 바이트를 보존했다. 생성 프롬프트·원본 경로·해시는 capture-fx-v05.json.
소스는 1254×1254 RGBA, 런타임은 최대 1024px/품질 0.85/알파 경계 보정·밉맵이다.
속도선·작은 파편·짧은 섬광·어두운 비네트와 상하 레터박스는 별도 레이어로 움직인다.
주먹/손바닥은 충격파, 새총/활/수정검은 날카로운 궤적, 낫은 곡선 참격,
벨리타의 마법은 붉은 파편으로 구분한다. 기존 캐릭터 그림 16장은 변경하지 않았다.

빠른 진입음은 기존 dash 효과음을 -9dB로, 타격은 slam을 -1dB로 정확히 맞춘다.
프리뷰 영상은 실제 게임의 60fps 프레임이며, 동일 효과음을 이벤트 시간에 맞춰 별도 동기화했다.

검증: 425 tests / 207045 assertions / 0 failures. UI_CAPTURE_OK 및 UI_FX_OK.
히트 스톱 중 두 좌표·줌이 동일하고 진입 속도가 느린 반동보다 4배 이상 빠른지,
종료·취소·재시작·스냅샷 복원·대기열과 게임 상태/RNG 불변 여부를 검사했다.
8개 조합을 네이티브 렌더러로 확인했고 큰 망토·날개가 화면에서 잘리지 않게 크기를 맞췄다.
웹 내보내기 성공, 패키지 약 98.7 MiB.

재생 예시: capture-fx-v05.mp4. 타격 정지 화면: capture-fx-v05.png.

원격의 단일 FIFO 연출 큐와 통합해 말 도착 뒤에 컷인이 시작되게 했다.
FIFO에서 이미 기다린 컷인 시간을 사출 힌트에서 한 번 더 기다리지 않도록 제거했고,
스냅샷 복원은 큐도 취소한다. 통합 후 UI_CAPTURE_OK / PRESENTATION_QUEUE_OK / UI_FX_OK.
프리뷰의 포즈 시작은 20프레임, 사출 시작은 77프레임(60fps)으로 빈 대기 없이 이어진다.
