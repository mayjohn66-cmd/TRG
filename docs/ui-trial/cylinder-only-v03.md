# 실린더 길이 조정 v0.3

납작한 인상을 줄이기 위해 앞뒤 길이를 **1.20 → 1.50 (+25%)**로 늘렸다. 정면 지름 2.06과 약실 배치·반지름은 유지했다.

옆면 홈과 관통 약실도 길어진 본체에 맞췄다. 추출기·약실 테두리·탄피 밑면은 뒤쪽 면에 맞춰 이동했고, 축과 탄피 몸통은 길이를 연장했다. 모따기와 추출기 자체 두께는 유지했다.

저장: `assets/models/revolver/cylinder_v03.tscn`, `cylinder_v03.glb`, `cylinder_body_v03.res`. v0.1·v0.2 모델도 보존한다.

검증: 저장된 메시의 지름 2.06 / 길이 1.50, 탄피 밑면 위치, 본체 연결 이상 모서리 0개, 약실 6곳 관통, GLB 저장·재읽기 및 실제 회전 렌더링 확인.
