# 두툼한 빵과 블록 화살표 v0.3

2026-10-21. 빵이 가늘고 코너 화살표가 얇다는 피드백에 따라 두 그림을 native image_gen.imagegen으로 다시 출력했다. 빵은 세로 비율을 키운 통통한 타원과 짧은 홈 세 개, 코너는 넓은 직사각형 몸통과 꽉 찬 삼각형 머리가 붙은 블록 화살표로 바꿨다.

두 원본은 1254×1254 RGBA PNG이며 재가공 없이 기존 경로에 복사했다. AtlasTexture의 피사체 영역만 새 원본의 알파 경계에 맞춰 갱신했다. 단색 갈색·초록 표시와 256px 임포트, 빵의 타일별 회전, 다음 칸을 가리키는 코너 방향은 유지했다. 출발·반환점의 작은 화살표도 같은 새 화살표를 공유한다.

실제 게임·전체 보드·빵집 네 곳·옷장 두 곳·코너 두 곳의 단일 타일·부스터 위 함정을 네이티브 Godot에서 렌더링하고 BOARD_DECALS_OK를 확인했다. 원본·프롬프트·SHA-256·교체 전 그림은 워크스페이스 outputs/board-symbols-v03/에 보관하며, 프로젝트 manifest.json도 갱신했다. 이미지 모델 식별자는 도구가 공개하지 않는다.
