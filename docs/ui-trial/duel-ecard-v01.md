# 엘리아스 E카드

왕관(여왕), 농기구(시민), 칼(반란군)을 작은 SVG 심볼로 직접 만들었다. 복잡한 캐릭터나 배경 그림은 사용하지 않는다. 남은 카드·버린 시민 수와 현재 승부 차수를 보여 주며, 입력 선택은 뒷면으로 놓이고 양쪽이 고른 뒤 함께 뒤집힌다.

양쪽 패는 특수 카드 1장 + 시민 4장이다. 여왕 > 시민 > 반란군 > 여왕 관계를 유지하고, 시민 대 시민은 승패 없이 두 카드를 버린 뒤 남은 패로 재대결한다. 네 번 비기면 시민이 소진되어 여왕 대 반란군으로 결판난다. 반란군의 기존 하극상 +5칸 보너스도 유지한다.

남은 수량은 TurnManager의 결투 setup.hands에 저장하고 전체 상태 동기화와 공개 이벤트에 포함한다. 비공개 선택을 제출했을 때는 수량을 바꾸지 않는다. 양쪽 카드가 공개될 때만 엔진이 한 장씩 소비하고, 화면은 버리는 동작 뒤 그 수량을 적용한다. 소모된 카드 입력은 card_spent로 거부하며, 봇과 로컬·엔진 시간 초과도 남은 카드만 고른다. 카드 공개와 재선택 시간을 엔진 제한 시간에 예약했다.

시민은 1.25초부터 아래로 밀려나며 사라지고 1.72초에 남은 패가 줄어든다. 2.25초에 다음 선택이 열린다. 승부가 나면 두 심볼과 승자를 보여 준 후 기존 실제 보드 말 사출·승자 전진으로 이어진다. RNG와 전역 시간 배율은 연출에서 바꾸지 않는다.

## 검증

- 단위 테스트: 승패 세 관계, 네 번 무승부 뒤 마지막 특수 카드, 소모된 카드 거부, 공개 전 수량 비공개, 동기화 수량, 봇·엔진 시간 초과.
- 실제 ACT_09 UI: 일반 GUI 버튼으로 시민 네 쌍 소모 → 특수 카드만 남음 → 반란군 승리 → 실제 패자 기물 사출.
- 양쪽 동시 뒤집기, 원격 이벤트가 미리 도착해도 순서대로 재생, 중간 취소, 로컬 시간 초과, PC·844×390 모바일 화면.
- 작업 폴더 outputs/duel-ecard-v01/에 화면 캡처와 시연 영상 저장.
