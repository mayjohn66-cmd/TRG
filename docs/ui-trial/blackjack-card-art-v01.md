# 블랙잭 기존 카드 리소스 연결

`stage_blackjack.gd`의 숫자·유니코드 무늬만 그리던 카드를 홀덤의 `JudgmentCard`로 교체했다. 기존 문양 이미지 네 종류와 `POKER_BACK`을 그대로 재사용한다. 숫자·A·J·Q·K는 엔진 결과에서 표시하므로 그림에 적힌 문자에 의존하지 않는다.

블랙잭 랭크는 A=1, J=11, Q=12, K=13이며, 홀덤 리소스 ID는 2부터 A까지의 순서다. 표시용 변환만 적용하고 엔진 카드·합계·에이스 처리·히트·스탠드 규칙은 유지한다. 무늬도 기존과 같은 결정적 장식으로 처리한다.

패널과 버튼은 D6·친치로·야추와 같은 공통 `UiSkin`을 사용한다. 기존 카드 배부 타이밍과 새 카드만 추가하는 동작을 유지한다.

Native Compatibility 실제 보드 검사 `BLACKJACK_NATIVE_OK`: 카드 받기 → 히트 → 스탠드, 기존 카드 노드 유지, 13개 랭크 변환, 기존 앞·뒷면 리소스 연결, 21/버스트 화면 및 초기화 확인. 실제 캡처의 일반 카드·J·A·K 표시를 확인했다. 신규 스크립트/셰이더 오류 없음. 기존 인증서·종료 시 자원 정리 진단은 남아 있다.

이번 변경은 로컬 코드에 반영했으며 웹 배포는 하지 않았다.
