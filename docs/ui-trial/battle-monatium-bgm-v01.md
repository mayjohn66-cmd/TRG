# 대전 BGM: 모나티엄의 밤

사용자가 지정한 [EPIDGames 공식 영상 — 트릭컬 BGM 맛보기 8탄 - 모나티엄의 밤](https://www.youtube.com/watch?v=8Y-wY2kZmZ0)을 대전 음악으로 추가했다. 공식 영상 설명은 `Trickcal Soundtrack - Monatium Night`, 작곡자 Warak로 표기한다.

- 파일: `assets/bgm/battle_monatium_night.ogg`, 572,990 bytes. 44.1kHz 스테레오 Ogg Vorbis quality 4.
- 원본은 3,600초 반복 영상이다. 파형 비교로 약 36.6667초의 반복을 확인했고 첫 한 주기를 사용했다. 5초 단위로 비교한 110초 범위의 평균 상관계수는 0.967, 최저 0.935였다. 세 주기(110초) 간격에서는 평균 0.988이었다.
- 양 끝 6ms만 페이드해 반복 접합 시 클릭음을 줄였다. 영상과 1시간 전체 음원은 저장소에 포함하지 않는다.
- SHA-256: `e3ccb3e8020bf123852ff1227cef9d178d866d1c8f9ef34fa5099efdd8e6310a`.
- MainBoard 진입 시 로비 음악을 멈추고 오디오 풀 준비 후 `Sfx.BATTLE_TRACK`을 재생한다. 자동으로 반복하며, 로비 복귀 때 기존 `Sfx.LOBBY_TRACK`으로 교체된다. 음악 플레이어 하나를 공유한다.
- 설정의 배경음악 크기와 전체 음소거를 두 곡에 동일하게 적용한다. 로비 곡 자체는 변경하지 않았다.

웹 오디오 회귀 테스트는 실제 두 OGG와 실제 Sfx.gd를 내보낸 뒤 Chrome 출력 파형을 검사한다. 로비→대전 곡 교체, 대전 음악 출력과 음소거/해제, 곡 길이를 넘긴 반복 재생, 로비 곡 복귀가 통과했다 (`WEB_BATTLE_BGM_OK`). 전체 게임도 웹 내보내기 후 이름 입력→놀이터→대전까지 실행했고, 36.66696초짜리 대전 음악 소스가 실제로 시작되는 것을 확인했다. 기존 UI 연출 테스트도 통과했다 (`UI_FX_OK`).
