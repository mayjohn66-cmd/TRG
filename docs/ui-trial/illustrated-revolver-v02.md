# 폭죽 리볼버 v0.2

은색 리볼버 실루엣이 보이도록 기존 초록색 상자 형태의 임시 총몸을 교체한다. 총열·프레임·검은 손잡이·실린더·해머·방아쇠가 구분되는 이미지 에셋을 사용한다.

## 구현 방식

- 후면 장전 확인 / 후방 사선 / 좌측면: 투명 RGBA PNG 3장, 각각 1536×1024. native image_gen으로 생성하고 원본 바이트를 보존했다.
- 완전한 3D 총기 모델이 아닌 **2.5D 이미지 애니메이션**이다. 여러 시점의 그림을 전환하며 대응점 메시를 변형한다. 실린더·해머·방아쇠는 런타임 마스크로 분리한다.
- 후면에는 6개 약실과 황동색 한 발만 표시한다. 장전 그림의 위치는 연출용이다. 엔진의 숨겨진 약실 번호나 게임 RNG를 읽거나 변경하지 않는다.
- 사선 ↔ 측면의 대응점 28개를 사용한다. 중간 메시의 삼각형이 접히지 않는지 21단계로 검사한다. 전환 시 아래 그림을 불투명하게 유지해 초록색 배경이 비치는 현상을 막는다.

## 시간과 크기

| 구간 | 동작 |
| --- | --- |
| 0.00–0.85초 | 열린 실린더에서 한 발 확인 |
| 0.85–1.30초 | 실린더를 총몸 안쪽으로 결합 |
| 1.30–2.35초 | 실린더 회전, 후면에서 사선으로 전환 |
| 2.05–2.80초 | 총열·실린더·손잡이를 맞추며 측면으로 전환 |
| 2.85초 | 준비 완료, 발사 버튼 활성화 |
| 발사 입력 +0.32초 | 실린더·해머·방아쇠 동작 후 찰칵 / 폭죽 판정 |
| 빈 약실 +0.85초 | 다음 발사·정지 선택 가능 |
| 폭죽 +1.65초 | 부착된 깃발·색종이 연출 종료 |

- 준비 연출은 게임 상태·라운드·플레이어·도구 인스턴스별 1회다. 빈 약실마다 다시 장전하지 않는다.
- 로컬 표시 영역 280×168, 기존 중앙 패드 배율 1.9. 내부 뷰포트 1000×600.
- 깃발: 연분홍 / 크림색 테두리 / 별 문양. 총구에 연결된 막대가 0.26초 동안 늘어나고 천이 펼쳐진다. 18개 색종이만 생성한다.
- 효과음: 빈 약실은 짧은 찰칵, 폭죽은 0.66초의 임시 합성 팡파르다. 음소거·볼륨 설정을 따른다.

## 조작·취소·판정

- 준비 및 발사 연출 중 발사·정지 버튼을 잠근다. 준비 중에는 직접 패드 클릭과 우회 굴림 호출도 차단한다.
- 첫 빈 약실 이후 정지하면 누적 칸만 확정한다. 추가 방아쇠나 깃발을 재생하지 않는다.
- 도구 교체와 새 게임은 준비·발사 연출을 취소하고 뷰포트를 정지한다. 결과 연출 중 다음 플레이어로 엔진이 넘어가도 현재 깃발이 지워지지 않는다.
- 원격 플레이어 첫 방아쇠에는 동일 준비 연출을 붙인다. 이후 방아쇠는 측면에서 이어진다. instant 테스트 모드는 준비도 건너뛴다.
- +3칸 누적 / 최대 15칸 / 폭죽 시 누적 소멸 / 정지 시 이동 확정 규칙은 변경하지 않았다.

## 생성용 공통 지시와 에셋

공통: 은색 강철 리볼버, 길고 둥근 총열과 상단 리브, 6발 실린더의 홈, 노출된 해머, 열린 곡선형 방아쇠울, 검은 곡선 손잡이. 정돈된 짙은 윤곽선과 은청색 하이라이트를 가진 게임 아이템 일러스트. 실제 투명 배경, 글자·손·총구 섬광·날아가는 총알 없음.

- `revolver_side_v02.png`: 총구가 왼쪽인 정확한 좌측면. 총열·손잡이 전체를 보존한다.
- `revolver_open_v02.png`: 후면에서 열린 실린더가 왼쪽, 총몸과 손잡이가 오른쪽. 약실 6개 중 좌상단 1개에만 황동색 탄피 밑면, 나머지 5개는 빈 구멍.
- `revolver_quarter_v02.png`: 같은 총의 후방 사선, 실린더는 결합된 상태. 후면과 측면 전환의 중간 시점.

원본/최종 파일 SHA-256과 크기·알파 검사는 `assets/ui/trickcal/revolver/art_v02_provenance.json`에 기록한다. 기존 v0.1 문서는 이 버전이 대체한다.
