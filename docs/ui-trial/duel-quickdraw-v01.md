# 석양의 무법자

기존 리볼버 조립 모델 두 자루가 서로를 향한다. 두 실린더의 장전 상태 확인 → 실린더 닫기 → 회전 → 측면으로 시점 이동을 2.85초간 함께 재생하고, 그 다음에 순발력 시계를 시작한다. 다른 결투 종목에는 3D 뷰포트를 만들지 않는다. 기존 조립 파일의 상속된 부품과 저장된 덮어쓰기 부품이 중복 생성되던 구조를 평탄화했다. 실제 40개 메시의 정점·재질·변환과 부품 경로는 유지하며, 생성·제거 시 고아 노드가 늘지 않는다. 정지한 총은 한 프레임만 갱신하고 발사 완료·취소 시 렌더링을 중지한다.

가짜 ‘트림!’과 진짜 ‘뽑아라!’ 신호는 기존 엔진의 시각을 사용한다. 발사 버튼·Space·핫시트 A/L은 누르는 즉시 밀리초를 제출한다. 신호 전 발사는 반칙, 정시 이후에는 더 빠른 쪽이 승리하며 아무도 누르지 않은 경우의 기존 판정도 유지한다. 총알 대신 기존 장난감 리볼버의 방아쇠·해머 동작, 뿅 소리, 깃발과 색종이를 재사용한다.

원격·봇 입력이 먼저 도착해도 기록된 시각까지 기다려 발사한다. 로컬 발사는 즉시 시작하며 중복 재생하지 않는다. 두 발사 연출이 끝난 뒤 승패를 보여 주고 기존 패자 사출·승자 전진으로 이어진다. 장전 중 입력, 대기 중 취소, 시간 초과와 결과 대기는 기존 이벤트 큐와 연결되어 있다. 게임 RNG나 전역 시간 배율은 변경하지 않는다.

병뚜껑은 드래그의 반대 방향으로 360도 자유 조준할 수 있다. 발사 직후에도 실제 초기 속도와 같은 방향의 가는 화살표가 짧게 남는다. 새 방향은 정수 입력으로 전송하고 정수 사인 테이블로 계산한다. 기존 직선·제한각 입력도 계속 재생된다.

## 확인

- 정수 물리 입력의 360개 방향 왕복·재생 일치, 네 방향 벡터, 기존 입력 호환.
- 실제 ACT_09 → 장전 → A/L 입력 → 양쪽 깃발 → 승패 → 실제 기물 사출.
- 장전 중 입력 차단, 마우스 누름 시각, 가짜 신호 반칙, 원격 입력 지연 표시, 미입력 시간 초과, 취소 시 렌더링 해제.
- PC 1366×768 및 모바일 844×390 화면 캡처. 작업 폴더 outputs/duel-quickdraw-v01/에 시연 영상과 캡처 저장.
