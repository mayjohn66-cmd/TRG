# 증강 아이콘 표시 일관성 점검

93개 증강과 보드별 법전 변형을 실제 110px 선택지 엠블럼으로 비교했다. 해상도는 모두 256px로 맞춰져 있었지만 일부 신규 그림의 윤곽·채도·하이라이트가 기존 그림보다 강했고, 6개 파일은 축소용 밉맵도 빠져 있었다.

## 조정 대상

- 도구 6종: 주식 차트, 다트, 오미쿠지, 아이스크림, 포춘쿠키, 캡슐 뽑기.
- 범용 증강 2종: 관성 드리프트, 현상금 수배서.
- 기물 4종: TRPG 전사·마법사·궁수·도적.
- 법전 1종: Bad Carrot.
- 초증강 1종: 저격수의 표적.

원본 PNG를 다시 압축하거나 축소하지 않고, 위 14종에만 공통 셰이더의 표시 보정을 적용했다. 첫 8종은 대비 0.95, 채도 0.94, 밝은 부분 압축 0.10, 가장자리 보정 0.12를 사용한다. 나머지 6종은 0.97 / 0.97 / 0.08 / 0.06으로 가볍게 맞췄다. 어두운 원형 배경은 유지한다.

선택지·보유 증강·도구 HUD·도감 확대 그림이 같은 보정값을 사용한다. 도구를 바꿀 때 기본 보정으로 복귀하며, 일반 그림과 기물 스프라이트에는 색 보정을 적용하지 않는다. 축소 필터를 선형 밉맵으로 통일하고 빠져 있던 주식·다트·오미쿠지·아이스크림·드리프트·현상금의 밉맵을 켰다.

전체 점검 중 Bad Carrot의 도감 미리보기가 실제 보드 상태를 우선하던 문제도 발견했다. `witch_variant_active()`를 사용해 도감에서 선택한 보드와 아이콘이 일치하도록 고쳤다.

## 검증

- 전체 증강 93개 이미지 연결, 보드 전환과 도감 미리보기: 305 assertions / 0 failures.
- 실제 HUD에서 주식 → 기본 주사위 → 캡슐 → 윷으로 전환하고 도감 확대 그림을 점검: 0 failures.
- Compatibility 렌더러로 전체 카테고리와 110px 전후 비교를 확인했다. 자동 실행에는 Dummy 오디오를 사용했다.
