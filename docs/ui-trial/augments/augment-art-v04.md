# 증강 그림 갱신: 아우토반·저격수

지금 규칙에 맞게 기존 증강 그림 두 장을 바꿨다.

- **LAW_06 — 아우토반 무제한 과속:** 은퇴한 과속 카메라 그림을, 금색·상아색 고속도로를 달리는 빨강·금색 장난감 자동차와 앞쪽 부스트 화살표 3개로 바꿨다. 지금 규칙은 눈금 5 이상이면 +3칸이다.
- **SUPER_09 — 저격수의 표적:** 평면 조준선과 옛 `-5` 표시를, 스프링 대포에서 튀어 나가는 조준된 빨간 말과 작은 앞쪽 화살표로 바꿨다. 지금 효과는 앞선 적 말 하나를 출발선으로 사출하고, 내 말을 4칸 전진시키고, 목표 자리에 스프링 대포를 놓는다.

두 그림은 기존의 두툼한 금색·상아색 셀 셰이딩, 어두운 배경, 원형 메달 구도를 따른다. 수치 규칙은 카드 설명 글에만 있다. 게임 규칙과 그림 찾기 ID는 바뀌지 않았다.

직접 생성한 1254×1254 PNG 원본을 기존 경로에 바이트 그대로 보관했다. 둘 다 512px·밉맵·손실 압축 90%로 임포트한다. 개별 설정은 `content_trickcal/illustrations/manifest.json`에, 전체 프롬프트·원본 기록·이전/현재 해시·시각 검수는 `augment-art-v04.json`에 있다.

`augment-art-v04.png`는 새 메달 두 개가 들어간 실제 증강 선택 화면이다. 증강 그림 찾기 50건 전체, 실제 110px 원형 크기에서의 육안 검수, 단위 테스트, 웹 내보내기·묶음 검사로 확인했다.
