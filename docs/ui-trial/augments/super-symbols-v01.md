# 초증강 심볼

초증강 12종을 점검해 보니 8종(`SUPER_01`~`SUPER_08`)이 코드로 만든 평면 원본 PNG였다. 기존 금색·상아색 두툼한 셀 셰이딩 그림에 맞춘 직접 생성 그림 엠블럼으로 바꿨다. `SUPER_09`~`SUPER_12`는 기존 그림을 유지한다. 같은 리소스 경로를 증강 선택지·규칙 도감·증강 이력 등 기존 `AugmentArt` 사용처가 모두 쓰며, 규칙·이름·수치·렌더러 로직은 바뀌지 않았다.

| ID | 효과 | 바꾼 그림 |
| --- | --- | --- |
| SUPER_01 | 판 뒤집기 (모 아니면 도) | 결승 깃발 동전, 되돌리는 화살표, 말과 칸 |
| SUPER_02 | 공산주의 재분배 | 같은 높이의 플레이어 색 4개, 카드, 재분배 화살표 |
| SUPER_03 | 악마의 계약 (영구 가속) | 뿔 달린 밀랍 봉인 계약서와 날개 달린 신발 |
| SUPER_04 | 광란의 지뢰밭 | 칸 위의 장난감 지뢰 두 개 (기본 설치 수 2와 같음) |
| SUPER_05 | 도적단 대습격 | 두건 쓴 도적과 훔친 카드 자루 |
| SUPER_06 | 주사위 도박사의 영혼 | 주사위, 금빛 영혼, 두 겹 화살표, 과열 불꽃 |
| SUPER_07 | 강제 캐슬링 룰렛 | 룩과 색깔 말, 교환 화살표 |
| SUPER_08 | 에르핀의 빵집 털이 | 통통한 빵, 보상 카드 세 장, 배치 화살표 |

앞으로의 심볼도 두꺼운 어두운 외곽선과 단순한 어두운 배경 위에 작게 모인 한 묶음으로 만든다. 표 수치를 조정해도 그림에 옛 값이 남지 않도록 글자와 숫자는 넣지 않는다. 자세한 배경도 넣지 않는다. 원본은 내장 `image_gen`으로 만든 1254×1254 RGB PNG 그대로이며, 512px 손실 텍스처(품질 0.9, 밉맵)로 임포트하고 기존 리소스 UID를 유지한다. 외부에서 픽셀을 다시 칠하거나 크기를 바꾸지 않았다.

프롬프트·원본 경로·해시·이전 해시·검수 기록은 `super-symbols-v01.json`과 중앙 그림 기록에 있다. 작업 공간 `outputs/super-symbols-v01`에는 옛 그림·새 그림·임포트 스냅샷·실제 렌더러 미리보기도 남겼다. 12종 비교, 40px 가독성, 원형 잘림, 실제 증강 선택지 8개, 기존 증강 그림 연결 테스트로 확인했다.
