# 보드 평면 심볼과 부스터 존 v0.1

2026-10-21. 타일은 보드 면으로 투영되지만 기존 심볼은 화면 정면의 등방 배율로 그려져, 칸의 기울기와 맞지 않았다. 또한 점프 코너 규칙을 제거한 뒤에도 기본 코너 화살표가 화면 오른쪽을 가리켰다.

`BoardSkin`의 임시 도형 심볼을 native image_gen으로 만든 투명 PNG 여섯 종으로 교체했다. 빵집·옷장 포탈·출발 체크 깃발·반환점 주황 깃발·코너 화살표·부스터 삼중 화살표다. `assets/board/decals/`의 원본은 1254×1254 RGBA이며, 재가공 없이 복사했다. 기존 초안의 부스터 외곽 번짐만 이미지 생성 도구로 한 번 제거했다.

그림의 X·Y축은 타일과 같은 보드 평면 변환을 사용한다. 회전만 하는 화면 아이콘과 달리 마름모의 두 축과 세로 압축이 모두 일치한다. 코너·부스터는 다음 칸의 보드 좌표로 방향을 계산하므로 24칸과 32칸 배치에 모두 대응한다. 출발·반환점에는 깃발 옆 작은 진행 화살표를 추가했다. 주 코너 두 곳은 오른쪽→위, 왼쪽→아래 진행을 가리킨다.

부스터 발판 전체를 코랄(#F7785B)과 주황 계열로 바꾸고 밝은 삼중 화살표를 올렸다. 기존 청록 포탈·노란 빵집과 구분되며 밝기 펄스를 유지한다. 부스터 위 함정·당겨진 결승선은 해당 표시가 우선하고, 함정 그림도 같은 보드 평면에 투영한다. 말의 위치와 게임 규칙은 바꾸지 않았다.

소스의 투명 여백은 원본 좌표로 기록한 AtlasTexture 영역에서 제외한다. 원본 픽셀·알파는 유지하며 런타임 임포트는 최대 256px, 손실 품질 0.85, 밉맵을 사용한다.

검수는 실제 게임 화면, 확대 보드, 부스터 위 함정 설치를 네이티브 Godot에서 캡처하고 24/32칸의 진행 방향과 투영 축을 자동 검증한다. 원본·초안·이전 코드·전체 프롬프트·해시는 워크스페이스 `outputs/board-decals-v01/`에 보관했다. 자산 경로와 프롬프트는 `assets/board/decals/manifest.json`에도 기록했다.
