# 특수 승리 교칙 심볼 v0.1

2026-10-21. LAW_01~08을 현재 `VictoryLaw.DEFS`와 `augments_table.csv`의 특수 승리 조건에 맞춰 native `image_gen.imagegen`으로 다시 그렸다. 장난감 같은 입체감·굵은 외곽선·금빛 조명·어두운 배경을 공유한다.

| ID | 교칙 | 심볼 |
|---|---|---|
| LAW_01 | 투기장의 지배자 | 교차 검이 새겨진 트로피와 쓰러진 적 말 |
| LAW_02 | 봉인된 에르핀의 식권 | 빵 그림 식권 5장과 붉은 봉인 |
| LAW_03 | 엘리아스 부동산 재벌 | 호텔·소유권 열쇠·함정 |
| LAW_04 | 카이지의 한방 역전법 | 긴 보드 경로와 전진하는 말 |
| LAW_05 | 사도 포위망 | 트랙에 분산된 초록 말 4개 |
| LAW_06 | 해탈한 동네북의 역습 | 보드 밖으로 튕겨 나가는 후광 말 |
| LAW_07 | 초전도체 무한 동력 | 순환하는 주사위 4개와 무한 기호 |
| LAW_08 | 다크호스의 하극상 | 왕관 쓴 선두를 쓰러뜨리는 흑마 |

게임 승리 조건의 수치는 설명 UI에서 그대로 보여 주며 아이콘 안에 작은 글씨를 넣지 않았다. 포위망은 분산 배치의 개념 심볼이며 3칸 간격을 축척대로 그린 보드 규칙도가 아니다. 다크호스의 말 모양은 교칙 이름의 비유로, 체스 전용 조건을 뜻하지 않는다.

기존 `content_trickcal/illustrations/laws/LAW_01.png`~`LAW_08.png`를 교체했다. 원본 PNG 1254×1254를 재가공 없이 복사했고 SHA-256 일치를 확인했다. 기존 UID·512px 제한·손실 품질 0.7·밉맵·로더 우선순위는 유지했다. 규칙이나 UI 코드는 바꾸지 않았다.

식권 초안의 여섯 번째 카드를 제거하고, 장외 사출 초안의 타일과 후광 여백을 넓혔다. 각 자산당 보정 1회. 기존 파일과 거절 초안은 작업 폴더에 보존했다. 생성 모델 식별자는 도구가 공개하지 않으며 에이전트 모델과 혼동해 기재하지 않았다.

검수: 실제 `MainBoard.make_augment_card`, 110px 원형 메달, 48px 축소 심볼, `Rulebook` 법전 장을 네이티브 Godot에서 렌더링했다. 8종의 로더 경로·512px 크기 제한·증강 카드와 도감의 텍스처 연결 검사는 `LAW_SYMBOLS_OK`로 통과했다. 전체 490개 테스트·591,966개 assertion 실패 0건, 증강 그림 연결 57/57을 확인했다. 웹 내보내기 성공, PCK 103,930,356바이트로 100MiB 단일 파일 제한 이내다. 기존 Godot 종료 시 자원 경고는 남아 있다.

작업 산출물은 워크스페이스 `outputs/law-symbols-v01/`에 있다. `gallery.png`, `draft_1.png`, `draft_2.png`, `rulebook.png`, `rulebook_chain.png`, `manifest.json`, `prompts.json`, `previous/`, `initial-drafts/`를 함께 보관한다. 프로젝트에 포함한 전체 생성 프롬프트와 원본 해시는 `content_trickcal/illustrations/manifest.json`에서 확인할 수 있다.
