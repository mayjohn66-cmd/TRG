# 리볼버 조립본 v0.1

본체 v0.2와 6구 실린더 v0.3을 결합한 독립 3D 미리보기다. 기존 부품 파일은 그대로 보존한다.

- 본체: `assets/models/revolver/body_v02.scn`
- 실린더: `assets/models/revolver/cylinder_v03.tscn`
- 장착 중심: 본체의 `(0, 0.30, 0)`, Y축 +90°. 실린더의 뒤쪽 면이 손잡이 방향(+X)을 향한다.
- 조립 보정: 실린더 로컬 Z 배율 `1.44`, 로컬 Z 위치 `0.04`. 직경은 `2.06` 그대로이며 몸통 길이는 `1.50 → 2.16`이다. 사진 비율로 늘어난 본체의 창에 맞춰 앞뒤의 과도한 빈 공간을 줄였다.
- 몸통 앞끝 X `-1.04`, 뒤쪽 허브 끝 약 `1.281`로 본체 창 X `-1.08~1.32` 안에 위치한다. 반지름 방향은 Y `-0.73~1.33`으로 창 `-0.82~1.42` 안에 들어간다.
- `Body/CylinderMount/Cylinder` 계층을 유지해 실린더를 개별 회전하거나 분리할 수 있다.

저장본: `assets/models/revolver/revolver_assembled_v01.scn`, `revolver_assembled_v01.glb`.
미리보기: `scenes/revolver_assembled_preview.tscn`. 마우스 드래그로 각도를 바꾸고 회전 버튼으로 전체를 돌린다.

검증: 저장된 씬을 다시 읽어 단일 실린더, 장착 방향·배율·간격을 검사했다. 실린더가 장착 공간을 채우는지와 방아쇠울이 열린 상태인지를 삼각형 광선 교차로 확인했다. GLB 내보내기·재읽기 성공. Godot의 측면·양쪽 사선 렌더링을 확인했다. 이번 변경은 조립 모델과 미리보기이며 인게임 발사/정지 연출 연결은 포함하지 않는다.
