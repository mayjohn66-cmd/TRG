# 카드 캐릭터와 동작 수정

요청에 따라 네 장의 캐릭터와 장면을 새로 생성했다. 전용 참조로 외형을 확인한 뒤 기존 카드와 동일한 4:3 일러스트로 제작했다.

| 카드 | 캐릭터 | 장면 |
| --- | --- | --- |
| 빠루 ACT_10 | 헤일리 | 양손으로 빠루를 잡고 온 힘을 실어 아래로 내려찍기 |
| 더 월드 ACT_12 | 리뉴아 | 손을 뻗어 주사위와 말을 공중에 정지시키기 |
| 알고리즘 밴 ACT_14 | 아멜리아 | 비서 복장으로 금지 도장을 찍기 |
| 우노 스킵 ACT_15 | 앨리스 | 얼굴 옆에 금지 표시 카드를 들고 보여주기 |

기존 ACT_11 밑장빼기와 ACT_13 어디로든 문은 유지했다. 게임 효과·카드명·카드 데이터는 바꾸지 않았다. 특히 더 월드의 시간 정지는 삽화 표현이며 실제 효과는 기존의 추가 한 턴이다.

리뉴아 v3 수정: ACT_12의 길어진 신체 비율을 큰 머리와 작은 몸통·짧은 팔다리의 치비 비율로 되돌리고, 손을 엄지 포함 4개 손가락으로 바로잡았다. 다리는 짧게 모으고 손의 과한 원근감을 줄였다. 기존 시간 정지와 복장을 유지하며 다른 카드는 수정하지 않았다. 원본·프롬프트·백업과 실제 카드 검수는 outputs/cards-renewa-chibi-v03에 보관한다.

리뉴아 v4(현재 적용본): 사용자가 완전 2등신이 아닌 3등신 치비라고 정정해, v3를 대체했다. 기존 리뉴아 카드 이미지를 입력하지 않고 원작 기본 복장 참조와 ACT_10·ACT_15의 카드 스타일 참조로 새로 생성했다. 무릎을 굽힌 3등신 치비, 단순한 외곽선과 평면 채색, 엄지 1개 + 나머지 손가락 3개의 손을 반영했다. 산출물은 outputs/cards-renewa-fresh-v04에 보관한다.

내장 이미지 생성 도구를 사용했다. 원본 1448×1086 PNG를 바이트 변경 없이 저장하고 기존 1024px 임포트 설정과 UID를 유지했다. 최신 파일 해시는 assets/cards/illustrations.json의 character-v2 항목에 기록했다. 원본·교체 전 백업·참조 출처·프롬프트·실제 CardSkin 및 MainBoard 검수 화면은 outputs/cards-actions-v02에 보관했다.
