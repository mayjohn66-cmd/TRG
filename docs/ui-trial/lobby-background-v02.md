# 로비 풍경 배경 v0.2

사용자가 제공한 풍경 4장을 시작 메뉴·모드 선택·훈련·아바타 설정·멀티플레이 대기방의 공통 배경으로 적용했다. v0.1의 연두색 곡선·잎사귀와 별도 햇살 도형은 이번 배경에 겹치지 않는다.

원본 WebP 바이트를 그대로 복사했다. 추가 압축·재생성·블러 저장본은 없으며 네 파일 합계 약 330KiB다.

## 표시 규칙

- 로비 씬에 들어올 때 네 장 중 한 장을 같은 확률(25%)로 선택한다. 연속으로 같은 이미지가 나올 수 있다.
- 별도 `RandomNumberGenerator`로 선택해 게임 판정·온라인 시드와 분리한다.
- 같은 화면에서 훈련·아바타·규칙·설정을 여닫거나 크기를 바꿀 때는 선택한 배경을 유지한다. 새 로비 씬에 들어오면 다시 고른다.
- `TextureRect.STRETCH_KEEP_ASPECT_COVERED`로 등비 확대해 전체 화면을 채우고 중앙에서 넘치는 부분만 자른다. 좌우/상하를 따로 늘리지 않는다.
- 배경의 전용 CanvasItem 셰이더에만 블러를 적용한다. 원본 기준 오프셋 반경 `2.0px`, 3×3 샘플 가중치 `[[1,2,1],[2,4,2],[1,2,1]] / 16`이다.
- 샘플 좌표를 원본 가장자리 반 픽셀 안으로 제한해 가장자리 검은 띠나 반복 무늬를 방지한다.
- 캐릭터·버튼·글자·팝업에는 블러가 적용되지 않는다. 이미지와 배경 컨테이너는 입력을 가로채지 않는다.
- 하단 팬게임 안내에 3px 크림색 외곽선을 추가해 배경이 어두운 장면에서도 읽히게 했다.

구현: `scenes/lobby_background.gd`, `scenes/lobby_background_blur.gdshader`. 배경만 지연 로드하며 화면 내 주기적인 이미지 교체는 하지 않는다.

## 검증

Godot 실제 렌더로 1366×768과 844×390에서 네 장과 멀티플레이 대기방을 캡처했다. 셰이더 오류 없음. 메뉴 변경 중 선택 유지·이미지 등비 채움·입력 통과를 확인했고 기존 `ui_menu_test`, `ui_lobby_test`로 메뉴 흐름을 검사했다. Windows 인증서 및 테스트 환경 WebRTC 경고는 기존 환경 제한이다.
