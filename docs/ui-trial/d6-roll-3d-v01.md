# 기본 D6 굴림 연출 v0.1

숫자를 바꾸는 사각 패널 대신 실제 여섯 면과 눈금이 붙은 3D 주사위를 2D UI 안에 표시한다. 기본 D6만 적용하며 다른 판정 도구의 연출은 유지한다.

## 시각 규격

| 항목 | 값 |
|---|---|
| 본체 | 한 변 2.0 단위, 모서리 반경 0.22의 둥근 정육면체 |
| 본체 메시 | 6면 × 16 × 16 분할, 3072 삼각형 |
| 눈금 | 1~6개 실제 면 부착, 총 21개, 원 반경 0.125, 중심 간격 0.38 |
| 대향면 | 1/6, 2/5, 3/4 — 합계 7 |
| 색 | 크림 #FFF5D7, 눈금 #36543C, 1 눈금 #E77970 |
| 음영 | 고정 방향 조명에 대응하는 3단계 셀 명암, 얇은 외곽선 |
| 화면 | 논리 280 × 232 영역, 실제 투명 렌더 타깃 560 × 464, MSAA 2배 |
| 카메라 | 직교, 크기 5.4, 위치 (6,7.25,6), 주시점 (0,1.25,0) |
| 패널 | 기존 연두·크림 공통 UI 이미지 스킨 |

## 재생 및 결과 보장

- 회전·던지기·작은 튀어오름을 합쳐 1.0초, 최종 눈금 0.35초 유지.
- 0.48초, 0.78초, 1.0초에 접촉. 파워 게이지는 회전량과 첫 두 튀어오름 높이에만 적용.
- 마지막에 선택된 면의 법선을 정확히 위로 정렬한다. 큐브 전체를 균일하게 유지하여 납작하게 누르는 효과를 쓰지 않는다.
- 회전 중에도 둥근 큐브의 지지 높이를 계산하여 모서리가 바닥을 뚫지 않는다. 공중에서는 높이를 보간해 모서리마다 중심이 덜컥거리지 않게 한다.
- 엔진의 `details.face`가 실제 윗면, `steps`가 이동 칸수다. 게임 RNG나 결과를 다시 추첨하지 않는다.
- 자연 종료·취소·다른 도구 전환 시 렌더 업데이트 중지. 다음 D6에서 같은 뷰포트와 메시 재사용.
- 착지에 기존 thud 효과음 사용. 기존 입력 잠금·즉시 테스트 모드는 유지.

## 구현과 검증

- `scenes/dice_roll_3d.gd`: 메시, 눈금 배치, 결과 자세, 이동 경로, 독립 투명 뷰포트.
- `scenes/roll_presenter.gd`: D6만 새 표시기에 연결, 다른 도구 전환·취소 처리.
- `assets/ui/trickcal/dice/*.gdshader`: 명암, 외곽선, 접촉 그림자. AI 생성 래스터 이미지를 사용하지 않는 실제 3D 모델이다.
- 단위 검사: 모든 눈금과 파워 0/0.5/1의 최종 윗면, 반대면, 눈금 겹침, 120개 경로 표본의 바닥 관통·스케일 변화, 접촉 경계의 연속성.
- 실제 UI 검사: 결과 일치, 동일 뷰포트 재사용, 취소, 대기 중 렌더 중지 및 기존 굴림 입력 잠금.
- 로컬 전체 326 tests / 28479 assertions / 0 failures. `UI_FX_OK`.
- Native Compatibility 렌더로 여섯 최종 면, 실제 인게임 연속 39프레임 확인. 주사위 뷰포트: 4 draw calls / 6566 primitives (외곽선 포함).
- Windows / RTX 4060 / Native Compatibility / 1366 × 768 / 60fps 제한에서 3회 연속 재생. 첫 회 준비 이후 162프레임의 실제 프레임 간격 평균 16.666ms, p95 16.695ms, process CPU 평균 9.636ms. 같은 조건의 대기 화면 평균 간격 16.666ms. 브라우저·모바일 측정치는 아니다.

기존 Windows 인증서·WebRTC 테스트 진단 및 종료 시 자원 정리 경고가 있다. 신규 스크립트·셰이더 오류 없음. 로컬 캡처와 최종 배포 브라우저 확인은 구분한다. 전 기기의 성능을 보증하는 수치로 로컬 프로파일을 사용하지 않는다.

API 근거: [Godot 4.7 Viewport](https://docs.godotengine.org/en/4.7/classes/class_viewport.html), [ArrayMesh](https://docs.godotengine.org/en/4.7/classes/class_arraymesh.html), [Spatial shader](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html).
