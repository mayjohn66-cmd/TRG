# 타이틀 로고 v0.1 적용

사용자가 확인한 「초증강 엘리아스 마블」 투명 로고를 이름 입력 화면, 로비, 웹 부팅 화면에 적용한다.

- 공용 원본: `res://web/title-logo.png` (1774 × 887, RGBA PNG, 2:1)
- SHA-256: `a6d6a13885fc12a3d1cca8348e106425740b643b900def99346087086e9bfa35`
- 이름 입력: 로고 영역 520 × 260, 영문 부제 20px
- 로비 왼쪽: 로고 영역 380 × 190, 영문 부제 15px
- Godot: 전체 이미지 비율 유지, 중앙 정렬, 알파 유지, 선형 필터 + 밉맵, 입력 통과
- 웹 부팅: 최대 너비 `min(560px, 82vw, 56vh)`, 높이 자동, 이미지 alt에 한글 제목 유지
- 배포: 같은 PNG를 Godot 리소스와 웹 정적 파일로 함께 사용

사용자가 첨부한 트릭컬 로고의 둥근 글자·분홍/노랑/하늘색·크림색 테두리를 참고하여 native `image_gen.imagegen`으로 생성했다. 이미지 모델 ID는 공개되지 않았다. 실제 원본 픽셀과 알파를 그대로 보존하며 추가 이미지 생성은 하지 않았다.
