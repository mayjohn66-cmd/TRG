# 난이도 선택: 3D 라면 그릇 v01

접시에 얹힌 음식처럼 보이던 2D 그릇을 실제 3D 메시로 교체했다. 검은 도자기 몸체, 크림색으로 두께를 준 입구, 붉은 띠를 유지한다. 안쪽 벽과 바닥을 이어 만든 깊은 그릇이며, 꼬불거리는 긴 면발은 입구보다 아래에 담겨 앞쪽 벽에 자연스럽게 가려진다.

- 모델: `scenes/ramen_bowl_model.gd` — 회전체 도자기와 26가닥 튜브 면발. 외부 모델·텍스처 다운로드 없이 생성한다.
- 표시: `scenes/ramen_bowl_view.gd` — 투명 SubViewport, 정사영 카메라, 두 조명. 정지한 1~4단계는 3D를 다시 그리지 않으며, 화면을 숨기면 처리와 렌더링을 멈춘다.
- 연결: `FireLevelPicker.RamenBowl`의 기존 난이도·소스 API를 유지한다. 소스 양끝은 아래로만 움직이며, 면 색은 기존 난이도 팔레트를 공유한다.

## 이번 확인 범위

라면 그릇만 검사했다. `tests/ui_ramen_bowl_test.gd`에서 그릇 깊이, 면의 높이, 소스 낙하, 연속 난이도 선택, 숨김·복귀를 확인한다. 실제 난이도 선택 화면은 데스크톱·모바일 크기로 캡처했다. 전체 메뉴·보드·대결 검사는 이번 작업에 포함하지 않았다.

```text
godot --headless --path . -s res://tests/ui_ramen_bowl_test.gd
```

배포 커밋의 `[check:ramen]` 또는 수동 배포의 `validation: ramen`은 이 검사만 실행한다. 전체 검사 경로는 별도로 유지한다.
