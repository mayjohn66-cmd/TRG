기존 카드와 같은 4:3 가로 삽화, 3등신 치비, 네 손가락 기준으로 내장 이미지 생성 도구에서 새로 제작했다.

| 카드 ID | 장면 |
| --- | --- |
| ACT_09 일기토 데스매치 | 티그와 에르핀이 서로 마주 보고 전투 준비 |
| ACT_08 X. 운명의 수레바퀴 | 앨리스가 점괘 덱에서 뽑은 수레바퀴 타로를 들어 보임 |

표시 이름 변경: ACT_04 `로켓` → `고출력 로켓 부스터`, ACT_10 `빠루` → `내 앞을 막지마!`, CNT_04 `빗나감!` → `감나빗!`. CSV와 코드 기본값을 함께 수정했고 ID·효과·스냅샷 형식은 유지했다. ACT_09에는 실제 카드 이미지를 새로 연결했다.

네 원본 PNG는 생성 결과 그대로 보관한다. 웹 런타임 임포트는 최대 768px, 손실 압축 품질 0.9, 밉맵 사용. 이미지 경로·크기·SHA-256은 `assets/cards/illustrations.json`의 `character-scenes-v3` 항목에 기록한다. 참조 출처·프롬프트·교체 전 백업·실제 CardSkin 검수는 작업 폴더 `outputs/cards-scenes-v03/`에 보관한다.
