# 아바타별 잡기 연출

에르핀·버터·엘레나·실라·셰이디·다야·벨리타·죠안 8명에게 공격/피격 포즈를 각각
하나씩 준비했다. 내장 `image_gen.imagegen`으로 기존 아바타 원본을 참조해 생성했고,
원본 PNG 16장의 바이트를 그대로 보존했다. 이전에 확인한 에르핀 공격·버터 피격
2장을 재사용하고 나머지 14장을 새로 생성했다. 배경·글자·타격 효과는 이미지에 없다.
모두 1254×1254 RGBA이며 원본 해시와 실제 프롬프트는 `avatar-capture-poses.json`에 있다.
셰이디 공격 그림 한 모서리의 알파 1/255 픽셀은 보이지 않는 수준의 생성 잔여물로
기록하고 원본을 변경하지 않았다. 그 외 모든 모서리는 완전 투명하다.

`GameState.pawn_captured`는 실제 잡기에서만 대표 말 기준 한 번 발생한다. 일반 이동,
백돌 면역, 자기 복귀, 함정·NPC의 출발선 추방과 구분한다. 흑돌의 알까기 필살기도
실제 잡기를 보고하므로 동일하게 표시한다. 기존 기물 복귀 신호·추가 턴·규칙 처리는 유지한다.

`MainBoard`는 두 플레이어의 선택 아바타를 읽어 `CaptureCutin`에 넘긴다. 로비에서
공유한 온라인 아바타와 기존 봇 아바타 선택 방식을 그대로 쓴다. 공격자/피격자가
뒤바뀌면 두 사람의 이미지 역할도 바뀐다. 같은 플레이어 쌍의 업기/연쇄 중복은
한 번만 표시하고, 서로 다른 상대를 잡으면 최대 3쌍을 차례로 보여 준다.

0–110ms 등장/전진, 110–200ms 접촉 포즈 정지와 작은 충격 표시, 200–360ms 피격 반동,
360–500ms 원래 화면 복귀. 보드는 암전만 하고 한 장짜리 삽화로 교체하지 않는다.
공격자의 무기/주먹을 피격자보다 앞에 그려 타격점이 머리카락에 가려지지 않게 했다.
고정 0.5초의 시각 효과이며 `Engine.time_scale`, 권위 상태, RNG를 변경하지 않는다.
입력과 다음 턴 강조만 짧게 기다린다. 재시작·스냅샷 복원은 대기열과 지연 콜백을 취소한다.

원본은 그대로 두고 Godot에서만 최대 1024픽셀, 품질 0.85 손실 압축, 밉맵과 알파
경계 보정을 적용했다. 이전의 전체 배경 컷인 시안은 런타임에서 제외한다. 이미 대체된
루트 효과음과 사용하지 않는 옛 모델 버전도 웹 패키지에서만 제외해 게시 용량을 확보한다.
실제 리볼버 조립 씬의 의존 모델은 유지한다.

검증: 단위 테스트 361개/200504 assertions 실패 0개. 실제 이동에서 잡기 이벤트→선택
아바타 연출, 역할 역전, 일반 복귀 제외, 권위 상태/RNG 불변, 종료/재시작 정리는
`ui_capture_test.gd`에서 검사한다. 기존 판정 도구 `ui_fx_test.gd`도 통과했다.
네이티브 렌더러에서 8개 조합과 실제 잡기 화면을 캡처해 크기·투명 경계·접촉점을 확인했다.
웹 패키지는 104,409,916 bytes(약 99.6 MiB)로 게시 제한 이내다. 내보낸 패키지에서
16장 전부와 실제 리볼버의 조립 씬/의존 모델을 로딩해 누락이 없는지 검사했다.
