# 야추·블랙잭·핀볼 심볼 교체

세 도구의 임시 평면 이미지를 기존 판정 도구와 같은 두툼한 윤곽선·광택·어두운 배경의 전용 심볼로 교체했다.

| 경로 | 표현 |
| --- | --- |
| illustrations/dice/DICE_YACHT.png | 구분되는 상아색 주사위 5개 |
| illustrations/dice/DICE_BLACKJACK.png | 스페이드 A·하트 K와 21 칩 |
| illustrations/dice/DICE_PINBALL.png | 쇠구슬·6개 핀·7개 포켓·스프링 발사대 |

핀볼은 실제 게임 도구가 핀 사이로 구슬을 내려 포켓에 넣는 구조인 점을 반영했다. 각 오브젝트를 원형 메달 안에 모아 배치했다. 게임 규칙·도구 이름·설명·매핑·애니메이션은 변경하지 않았다.

내장 이미지 생성 도구로 자산별로 생성하고 1254×1254 PNG 원본을 바이트 변경 없이 복사했다. UID를 유지하며 런타임 최대 512px, 손실 압축 품질 0.9, 밉맵을 적용했다. 원본·프롬프트·해시·이전 자산·실제 화면은 작업 산출물 outputs/tool-symbols-v02에 보관한다.

실제 MainBoard 3종, 110px 증강 메달, 48px HUD, 확대 원형 프리뷰와 증강 카드 3종을 렌더했다. TOOL_SYMBOLS_OK: 세 ID의 정확한 파일 로드, 512px 상한, 증강과 HUD의 텍스처 공유 확인. 육안 검수에서 주요 형태의 원형 잘림과 작은 크기 구분을 확인했다.
