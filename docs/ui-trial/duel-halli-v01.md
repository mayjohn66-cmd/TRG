# 할리갈리 디럭스

두 더미에 레몬 그림 카드를 번갈아 뒤집는다. 기존 판정대로 맨 위 두 카드의 그림 합이 5가 되는 순간 종을 먼저 치면 승리한다. 카드 뒷면·레몬·종은 기존 이미지 리소스를 재사용한다. 큰 규칙 설명은 시작 전 화면에만 둔다.

- 카드 공개 직전에 기존 카드가 접히고, 판정 시각에 새 그림이 공개되어 짧게 펼쳐진다. 합계는 결과가 나온 뒤에만 표시한다.
- 한 명이 조작할 때는 중앙 종을 직접 누르거나 아래 버튼·Space로 입력한다. 핫시트에서는 좌우 버튼 또는 A/L로 누른다. 마우스·터치를 놓는 시점이 아니라 누르는 시점을 기록한다.
- 종을 치면 즉시 눌림·흔들림·색상 파동과 짧은 종소리가 재생된다. 중복 입력은 무시한다.
- 너무 빨리 누르면 그때의 카드 상태에서 멈춘다. 이후 카드를 모두 드러내던 예전 표시를 제거했다. 먼저 도착한 봇·온라인 판정도 기록된 시각까지 기다린 뒤 재생한다.
- 승패·반칙·시간 초과 판정과 패자 기물 사출은 기존 엔진 결과를 사용한다. 연출은 게임 RNG를 사용하지 않는다.

## 종소리

Kenney Impact Sounds의 `impactBell_heavy_000.ogg`(CC0)를 작은 종에 맞춰 높이고 0.72초로 줄였다. `tools/audio/add_halli_bell.py`로 재현할 수 있으며 출처·처리·해시는 `assets/sfx/curated/manifest.json`에 기록한다.

## 검증

`tests/ui_halli_test.gd`는 실제 ACT_09 카드 사용부터 승패·기물 사출·정리까지 실행한다. 200개 카드 순서의 공개 전/정확한 공개 시각, 중복 입력, 로컬 자리 제한, 직접 종 누르기, 반칙 시 미래 카드 숨김, 관전자·봇 결과 대기, 양쪽 시간 초과, 연출 도중 닫기도 검사한다. PC 및 844×390 화면을 네이티브 렌더링으로 확인했다. 전체 UI FX, 종목 추첨/안내, 효과음 리소스 검사도 통과했다.

시연 영상과 화면 캡처: 작업 폴더 `outputs/duel-halli-v01/`.
