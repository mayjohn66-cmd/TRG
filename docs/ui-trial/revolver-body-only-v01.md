# 실린더를 제외한 리볼버 본체 v0.1

사용자가 앞서 제공한 은색 리볼버 측면 사진을 형태 기준으로 삼은 단독 3D 모델이다. 실린더는 포함하지 않는다.

구성: 속이 빈 둥근 총열과 총구 테두리, 총열 리브·가늠쇠·하부 하우징, 빈 실린더 프레임, 곡면 검은 손잡이와 나사, 노출된 해머, 곡선 방아쇠, 실제로 열린 방아쇠울. 각 부품은 별도 메시다.

실린더 v0.3 연결 기준:

- 실린더 중심: `(0, 0.30, 0)`.
- `EmptyCylinderMount` 회전: Y축 `+90°`. 기존 실린더의 Z축이 본체 X축과 나란해진다.
- 기준 실린더 지름 `2.06`, 길이 `1.50`.
- 프레임 안쪽 공간: X `-0.86~0.99`, Y `-0.80~1.36`. 모서리 반지름 `0.09`.
- 총열 길이 `4.10`, 루트 위치 `(-1.12, 0.92, 0)`에서 -X 방향.

파일:

- `assets/models/revolver/body_v01.scn`: 저장된 Godot 모델.
- `assets/models/revolver/body_v01.glb`: 재사용할 glTF 바이너리.
- `scenes/revolver_body_3d.gd`: 모델 생성 소스.
- `scenes/revolver_body_preview.tscn`: 독립 미리보기. 드래그로 시점을 바꾸고 회전 버튼으로 둘러볼 수 있다.

검증: 저장된 모델을 다시 읽어 실린더 공간 16지점과 방아쇠울 내부가 뚫려 있는지 광선으로 확인했다. 상단 프레임과 손잡이는 금속·그립 면에 충돌함을 확인했다. GLB 저장·재읽기와 측면·양쪽 사선의 실제 3D 렌더링을 확인했다.
