# 야추 주사위 5개 투척 연출 v0.1

주사위 5개가 함께 굴러간 뒤, 엔진이 정한 다섯 눈금을 카메라 정면으로 일렬 표시한다. 기본 D6의 둥근 메시·눈금·크림색 셀 명암을 재사용하며 하나의 투명 뷰포트에서 모두 렌더한다.

- 투척·작은 튕김·정면 정렬: 1.19초. 슬롯별 0.035초 차이로 착지한다.
- 실제 여섯 면이 회전하여 결과 면이 정면에 온다. 눈금을 다시 추첨하거나 결과를 바꾸지 않는다.
- 고정된 주사위는 재굴림 중에도 값·위치·회전이 유지되고 연두색 테두리와 고정 배지를 표시한다.
- 재생 중에는 고정·재굴림·확정 입력을 잠근다. 종료 후 기존 족보와 이동 칸수를 표시한다.
- 대기 화면은 변경 시 한 프레임만 요청한다. 숨김·초기화·씬 종료는 연출과 대기를 취소하고 렌더를 중단한다.
- 기존 즉시 검사 모드와 엔진의 고정/리롤 2회 규칙을 유지한다.

구현: `scenes/yacht_roll_3d.gd`, `scenes/stage_yacht.gd`.

검증: 전체 428 tests / 207155 assertions / 0 failures, 기존 `UI_FX_OK`.
Native Compatibility 실제 보드에서 최초 투척 → 주사위 클릭 고정 → 나머지 재굴림 → 결과 확정과 취소·초기화를 검사했다(`YACHT_NATIVE_OK`). 모든 1~6 결과의 다섯 슬롯 정면 법선과 정지 후 자세도 검사했다. 캡처 40프레임과 고정 재굴림 화면을 확인했다.

이번 변경은 로컬 구현과 검증이며 웹 배포는 하지 않았다. 기존 인증서·WebRTC 검사 진단과 테스트 종료 시 자원 정리 경고는 남아 있으나 신규 스크립트/셰이더 오류는 없다.

## 색상 통일 v0.2

야추에 남아 있던 남색 패널과 파랑·주황 버튼을 기존 D6/친치로의 공통 `UiSkin`으로 교체했다. 밝은 크림색 패널, 연두색 테두리·제목, 짙은 본문, 크림색 재굴림 버튼과 노란색 확정 버튼을 사용한다. 고정 표시는 같은 연두색이며 20px 배지에 맞는 얇은 둥근 테두리로 잘림을 방지했다. 주사위 메시·재질·연출·결과 계산은 동일하다.

Native Compatibility 실제 보드에서 밝은 패널과 고정/재굴림 화면을 캡처하고 `YACHT_NATIVE_OK`를 확인했다.
