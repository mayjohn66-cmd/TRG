# 핀볼 3D 베이스 v0.1

발사·구슬 이동·게임 판정 연결에 앞서 정적 베이스만 제작했다. 기존 `stage_pinball.gd`의 2D 연출은 그대로 두었다.

- 두께가 있는 아치형 목재 케이스, 크림색 상판과 연두색 플레이 필드.
- 상단 아치와 오른쪽 발사 레인으로 이어지는 입체 금속 레일.
- 6/5개를 번갈아 배치한 6줄, 총 33개의 금속 핀과 둥근 금색 캡.
- 하단 7개 포켓: 왼쪽부터 `2, 4, 6, 10, 5, 3, 1`. 중앙 10 포켓은 금색으로 강조.
- 실제 깊이가 있는 포켓 바닥·칸막이·전면 립, 숫자 판은 텍스처가 있는 별도 메시.
- 정적인 7회전 코일 스프링, 발사봉과 코랄색 손잡이. 구슬·애니메이션·충돌체는 포함하지 않았다.

수정 가능한 Godot 씬: `assets/models/pinball/pinball_base_v01.tscn`.
제작 소스: `scenes/pinball_base_3d.gd`. 순수 Godot 3D 메시이며 그림을 평면에 붙인 베이스가 아니다. 숫자만 UI 글꼴로 렌더한 텍스처를 사용하므로 GLB에도 동일하게 남는다.

검증 런타임: Godot 4.7.1-stable / Native Compatibility / RTX 4060. 저장한 native 씬과 GLB를 각각 재로딩해 175개 메시 구조와 유한한 좌표를 확인했다. GLB 크기 약 1.3MB. 네이티브 및 GLB의 메시 버텍스 합계 51,816개. 실제 정면·사선·위쪽 캡처로 필드, 33개 핀, 7개 포켓, 레일, 스프링과 손잡이를 확인했다.

모델의 위쪽은 +Y, 좌우는 X, 길이 방향은 Z다. 상단 아치가 -Z, 발사 손잡이가 +Z에 있다. 크기는 약 `6.8 × 1.48 × 9.93` Godot 단위이며 최저점은 `Y=-0.58`이다.

아직 게임 스테이지에 연결하거나 웹 배포하지 않았다.
