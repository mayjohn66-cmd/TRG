# 볶음라면 난이도 선택 v02

기존 Fire Level 1~5 선택 흐름과 AI 설정을 유지하면서, 난이도 패널을 간단한 표정 배지와 볶음라면으로 다듬었다.

| 단계 | 면과 양념 | 표정·모션 |
| --- | --- | --- |
| 크림 | 연한 크림색 | 하트눈, 작은 맥박, 눈깜빡임 |
| 로제 | 연한 주황색 | 웃는 눈, 부드러운 위아래 움직임 |
| 오리지널 | 붉은 양념 | 눈썹을 세우고 콧김 |
| 마라 | 짙은 적갈색 | 찡그린 눈, 헐떡임, 떨어지는 땀 |
| 핵불닭 | 진한 빨강 | X자 눈, 작은 불꽃, 그릇 떨림과 계속 흐르는 소스 |

깊은 검은 그릇 안에 가는 꼬불면을 담고, 김·깨 토핑을 소량 더했다. 표정은 64px 영역 안에 굵은 외곽선과 단색 면으로 그린다. 선택 반응은 0.42초, 소스가 면에 스며드는 시간은 선택 후 0.22~0.72초다. 최고 단계 외의 소스는 0.74초에 사라진다. 연속 선택은 현재 면 색에서 새 색으로 이어지며, 별도 Tween이 쌓이지 않는다.

숨긴 패널의 얼굴·불꽃·그릇은 처리와 재그리기를 멈추고 재료 파티클 방출도 멈춘다. 다시 열면 재개한다. 문구·선택 버튼·난이도 저장·AI 파라미터는 기존 것을 사용한다.

검증: `tests/ui_menu_test.gd`에서 전체 메뉴 흐름, 난이도 선택·저장, 연속 5→1→4→2 선택 후 안정화, 낮은 단계 모션, 화면 숨김·재개, 작은 불꽃 다각형 채우기를 확인했다. 실제 OpenGL 화면을 1366×768 및 844×390으로 렌더해 패널·아이콘·설명의 배치를 확인했다.

## 면발·소스 보강

면은 잔굴곡이 많은 28개의 긴 가닥으로 그린다. 각 가닥을 그릇 평면에서 서로 다른 방향으로 회전한 뒤 타원 원근을 적용해, 큰 파스타 고리나 동심원처럼 보이지 않도록 서로 겹친다. 둥근 끝과 얇은 윤기로 면의 연속성을 살렸다. 면 모양은 처음 한 번만 계산하므로 프레임마다 위치가 바뀌지 않는다.

소스 앞끝은 0~0.22초 동안 위에서 면으로 내려오고, 공급을 멈춘 뒤 뒷끝도 0.52~0.74초 동안 아래로 떨어진다. 기존처럼 아래 끝을 위로 끌어올리지 않는다. 소스 속 윤기는 아래로 흘러가며, 최고 단계는 계속 공급된다. 검사는 전 구간에서 앞끝과 뒷끝의 하강 방향을 확인한다.

## 깊은 그릇 안에 담기

얕은 접시 형태를 깊은 검은 라면 그릇으로 바꿨다. 안쪽 벽의 그림자 아래로 면을 낮추고, 앞쪽 외벽과 두꺼운 테두리를 면·토핑·소스보다 나중에 그려 음식의 아랫부분을 가린다. 붉은 띠와 작은 불꽃만 더해 매운 볶음라면 용기 느낌을 낸다. 그림 영역 높이는 116px에서 154px로 늘리고, 소스 착지 위치를 그릇 안의 면 높이에 맞췄다.

앞벽 다각형의 정상 채우기 검사를 메뉴 테스트에 추가했다. 전체 PC 화면과 작은 가로 화면에서 음식이 앞쪽 테두리를 뚫고 나오지 않는지 렌더로 확인한다.
