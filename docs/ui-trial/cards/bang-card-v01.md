# BANG! 카드 연출

ACT_02는 기존 조립된 은색 리볼버를 쓴다. 총이 쏜 사람 프로필 옆에서 솟아올라 공이치기를 당기고 실제 선두 적 말을 겨눈다. 조용한 조준 모서리 4개가 그 말 주위로 모인다. 한 발에 짧은 총구 불꽃, 빠른 금색 탄도, 부드럽게 흐르는 연기, 짧은 명중 자세가 나온다. 명중 정지 뒤 기존 사출 애니메이션이 실제 말을 보드 밖으로 날린다. 그동안 연기와 총은 사라진다.

- 발사 0.58초, 명중 0.65초, 사출 시작 0.74초, 총·연기 끝 1.12초.
- 기존 연출 속도를 따른다. 첫 모델 올리기가 느려도 박자를 건너뛰지 않는다.
- 좌표는 말 층의 변환을 포함한다. 탄도는 총 화면을 통해 투영한 3D 총구에서 시작한다 (좌우 반전·회전 포함).
- 대기 중인 사출 단계를 그 자리에서 바꾼다. 기존 방어 확인·알림·업힌 말·연대책임 결과는 대기열 순서를 유지한다.
- 방어·되감기가 성공하면 가짜 발사나 사출이 없다. 초기화하면 총·연기·어둡게 하기를 지우고 말을 엔진 상태로 되돌린다.
- 기존 총소리(-3dB)와 장난감 딸깍 소리(-8dB)를 쓴다. 새로 받는 파일은 없다.
- 게임 규칙·난수는 바뀌지 않는다. UDO +4는 기존의 별도 피드백을 유지한다.
- 한·영·일 기록에 남아 있던 옛 "2칸 뒤로 밀림" 문구를 고쳤다. 실제 BANG! 규칙은 이미 목표를 출발선으로 사출한다.

## 범위 검증

`godot --headless --path . -s res://tests/ui_bang_test.gd`

준비된 보드에서 실제 카드·명령을 실행한다: 선두 목표, 발사·명중·사출 순서, 방어 확인, 스냅샷 복원, 조준·비행 중 초기화, 반대 방향, 연출 속도, 반복된 화면 정리, 효과 끄기, 게임 난수 불변. `BANG_CAPTURE_DIR`를 주면 실제 프레임을 저장한다. CI 커밋 표식 `[check:bang]`은 게임 전체 테스트 대신 이 검사를 고른다.

## 그림 발사 효과

원래 다각형 불꽃과 같은 간격의 명중 바큇살을 `assets/fx/bang/`의 투명 그림 텍스처 두 장으로 바꿨다. 원본은 바이트 그대로 두고 512px·밉맵으로 임포트한다. 프롬프트·원본 위치·일치하는 SHA-256은 `assets/fx/bang/source.json`에 있다.

탄도는 같은 굵기의 두 줄 대신 움직이며 가늘어지는 뜨거운 심과 고르지 않게 퍼지는 감쇠로 바뀌었다. 총구 연기는 흐르는 노이즈와 부드러운 가장자리 감쇠를 쓴다. BANG!은 일반 원형 사출 고리를 끄고 자기 그림 명중만 보여 준다. 리볼버·조준 모서리·시간·음량·게임 규칙은 그대로다.
