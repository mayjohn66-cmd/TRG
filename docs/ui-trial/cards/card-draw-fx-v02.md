# 카드 얻기 연출: 테이블 덱 → 확인 → 손패

카드 더미는 보드 오른쪽 아래 가장자리 바깥에 놓인다. 제공된 참고 그림처럼 카드가 원근감 있게 가로로 누워 있고, 따뜻한 금색 테두리·남색 뒷면·단순한 금색 열쇠 문양·12px 두께로 겹친 흰 종이 가장자리를 가진다. `MainBoard`가 배치나 보드 카메라가 바뀔 때마다 더미 위치와 가운데 확인 지점을 다시 잡는다. 드래프트·소개 중과 게임이 끝난 뒤에는 더미를 숨긴다.

내 카드: 뒷면을 들어 올리고(0.14초), 가운데로 옮기고(0.28초), 뒤집고(0.22초), 210×295 미리보기를 보여 준 뒤(0.60초), 곡선을 따라 손패로 들어간다(0.36초). 카드 한 장에 1.60초이고 여러 장은 0.06초 간격으로 차례로 보여 준다. 마지막 위치와 회전은 지금 부채꼴 손패 자리(아래 축, 새 카드로 다시 펼쳐지는 것 포함)를 따른다. 도착할 때까지 손패에서는 그 카드를 숨겨 둔다.

떠나는 뒷면은 출발할 때 더미 맨 위 카드와 네 모서리가 같다. 누운 채로 들려 올라가다가 옮기는 동안 자연스럽게 세워진다. 종이 전체가 보드 바깥에 머물고, 덱 위에 세워진 카드가 따로 나타나지 않는다.

다른 사람의 카드는 뒷면인 채로 0.44초 동안 그 사람 프로필로 날아간다. 앞면은 아예 만들지 않는다. 빼앗긴 카드는 피해자의 프로필에서 출발한다. 엔진의 카드 지급·손패 한도·카드 정체·난수는 바뀌지 않는다.

카드 얻기가 진행되는 동안 보드 조작과 다음 연출은 기다린다. 이동으로 얻는 보상은 그 이동의 잡기 효과가 끝난 뒤에 처리한다. 새 게임을 시작하면 진행 중·대기 중 카드와 자리 예약을 지우고, 늦게 오는 도착 콜백도 없다. 기존 즉시 테스트·스모크 모드는 카드 얻기 입력 잠금을 건너뛴다.

검증: 옮긴 뒤 공개, 읽을 수 있게 고정된 정지, 보이는 내 카드 앞면 1장, 남의 카드 비공개, 손패 자리 숨김, 도착, 여러 배치에서 보드 밖 덱 위치, 빼앗기 출발점, 취소와 다음 연출 재개. 실제 OpenGL 캡처로 그림 카드 두 장을 연속으로 얻는 장면을 확인했다. 단위 테스트 592개·단언 588,426개 통과, 통합·전체 CI 기록은 작업 산출물에 남겼다.
