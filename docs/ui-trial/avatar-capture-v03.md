# 셰이디·다야 피격 팔다리 수정

내장 image_gen.imagegen으로 두 캐릭터의 hit.png만 다시 그렸다.
얼굴·헤어·의상·장식과 왼쪽을 보는 얼굴/오른쪽 반동은 유지하고 팔다리 자세를 정리했다.
셰이디: 어깨→팔꿈치→손의 연결이 드러나도록 팔을 위·아래로 나누고 두 다리를 분리했다.
다야: 날개와 팔을 분리하고 무릎이 꼬이지 않는 뒷걸음 자세, 발목과 맨발을 다시 그렸다.
PNG 원본 바이트를 그대로 복사했으며 1254×1254 RGBA다.

실제 프롬프트·원본 경로·해시·이전 리비전은 avatar-capture-poses.json에 보존했다.
나머지 여섯 피격 PNG는 변경 전후 해시가 같다. 공격 PNG 및 공통 배치 코드는 유지한다.

게임 적용 화면: avatar-capture-v03-shady.png / avatar-capture-v03-daya.png.

검증: 두 PNG의 RGBA/투명 모서리와 원본·대상 해시 확인, UI_CAPTURE_OK,
네이티브 게임에서 두 피격 포즈와 공격 방향·간격을 확인했다.
