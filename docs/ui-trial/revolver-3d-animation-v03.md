# 러시안 룰렛 실제 3D 연출 v0.3

`ToyFlagGun3D`가 조립 모델 `assets/models/revolver/revolver_assembled_v01.scn`을 사용하도록 교체했다. 본체·실린더는 승인된 조립본의 비율을 유지하고 전체를 0.245배로 축소한다. 로컬 발사/정지 패드와 다른 플레이어의 RollPresenter가 같은 모델과 타임라인을 사용한다.

## 준비 연출 (2.85초)

| 시간 | 연출 |
|---|---|
| 0~0.85초 | 열린 실린더의 뒤쪽을 가까이 보여준다. 6개 관통 약실과 장전된 1개를 확인한다. |
| 0.85~1.30초 | 실린더가 본체에 결합하며 카메라가 뒤로 빠진다. |
| 1.30~2.35초 | 결합된 실린더가 4회전 후 감속한다. 카메라는 측면으로 돌아간다. |
| 2.35~2.85초 | 측면 구도에 정착하고 발사/정지 선택을 활성화한다. |

장전된 탄피는 시각 설명용이다. 실제 판정 도구의 숨은 약실 인덱스나 RNG를 읽지 않으며, 회전 시작 이후에는 보이지 않는다. 같은 차례에 다시 누르면 준비 연출을 반복하지 않는다.

## 발사·정지

- 발사 입력 시 실제 실린더 메시가 60도 진행하고 해머·방아쇠 메시가 각자의 축을 중심으로 움직인다.
- 0.32초에 공개된 판정에 맞춰 찰칵 또는 폭죽 소리가 나고, 빈 약실은 누적 칸만 갱신한다.
- 폭죽 결과는 실제 총구 위치에서 막대와 별무늬 깃발이 펼쳐지고 종이 조각 18개가 퍼진다. 탄환 발사체는 없다. 깃발·종이 조각은 기존 파티 연출을 재사용했다.
- 정지는 추가 판정 없이 원래 누적 이동을 확정한다. 엔진의 +3 누적/15칸 자동 확정/폭죽 시 소멸 규칙은 그대로다.
- 도구 교체·취소 시 깃발과 진행 상태를 비우고, 연출 완료 후 SubViewport 렌더링을 멈춘다. 다른 차례로 넘어가도 진행 중인 폭죽 연출을 유지하는 기존 동작을 보존한다.

## 검증

- 저장된 실제 메시의 장착 구조, 게임 카메라 안의 모델·깃발·종이 조각 범위 검사.
- 전체 단위 테스트 356개 통과. 기존 2D 이미지 모핑 검사는 제거하고 실제 조립본 검사로 갱신.
- `ui_fx_test`: 준비 중 입력 잠금, 실제 실린더·해머·방아쇠 동작, 빈 약실/폭죽, 취소·도구 교체·재사용·원격 재생 검사.
- `ui_smoke`: 실제 게임 진행 및 승리까지 통과.
- 네이티브 게임 캡처: 약실 확인 → 결합/회전 → 빈 약실 3칸 → 다시 발사해 폭죽 및 정지로 3칸 확정하는 경로를 확인했다.
- 종료 시 기존 Godot RID/ObjectDB 정리 경고는 남아 있다. 스크립트/셰이더 오류 없이 실행했다.

재현: `godot --headless --path . -s res://tests/run_tests.gd`, `res://tests/ui_fx_test.gd`, `res://tests/ui_smoke.gd`.
