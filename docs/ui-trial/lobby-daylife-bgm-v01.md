# 로비 BGM: DayLife

사용자가 지정한 [EPIDGames 공식 영상](https://www.youtube.com/watch?v=pfsosJ1xPqk)의 **트릭컬 로비화면 테마 DayLife**를 사용한다. 영상 설명의 작곡자는 Warak다. 출처는 `CREDITS.md`에도 기록했다.

## 음원

- 원본 영상은 3,600초 반복본이다. 음성 트랙만 확보한 뒤 첫 반복 구간을 사용했다. 원본 영상·전체 오디오는 게임 저장소에 포함하지 않는다.
- 8kHz 분석용 모노 파형의 10초 구간을 비교했을 때 약 40.4333초 간격으로 같은 구간이 반복된다. 3주기 지연(121.3초)의 상관계수는 0.987이었다.
- 첫 40.433333초를 44.1kHz 스테레오 Ogg Vorbis quality 4로 변환했다. 접합 클릭을 줄이기 위해 양 끝 6ms에만 페이드를 적용했다.
- 파일: `assets/bgm/lobby_daylife.ogg`, 590,238 bytes. SHA-256: `09b73b77e1156420ed6bb5dd6351500ca13650942791bd5057e045598b8d93f9`.

## 재생 범위

시작 메뉴(이름 입력·모드 선택·아바타 설정·훈련 설정)와 친선/랜덤 매칭 로비에서 반복한다. 같은 곡이 이미 재생 중이면 재시작하지 않는다. 음악 플레이어는 루트의 SfxHost에 있어 메뉴와 방 로비 전환에도 이어진다. 대전 씬이 열리면 정지하고 로비로 돌아오면 다시 시작한다.

오디오 풀을 먼저 준비한 다음 deferred 호출로 음악을 시작한다. 웹의 자동 재생 정책에 따라 첫 클릭·터치 이후 들릴 수 있다. 전체 음소거와 저장된 `bgm_volume`을 따르며, 설정창에 **배경음악 크기** 슬라이더를 추가했다. 효과음 크기와 따로 조절한다.

## 검증

- 실제 Sfx.gd와 실제 DayLife OGG를 담은 웹 테스트 빌드에서 오디오 출력, 같은 곡 중복 호출 시 소스 재생 유지, 음소거/해제, 음악 전용 음량, 정지/재시작을 검사했다.
- 한 주기 전체가 지난 뒤에도 재생·출력이 유지되는 것을 확인했다 (`WEB_BGM_OK`).
- Web Sample의 재생 위치 보고값 대신 실제 AudioBufferSourceNode의 start 호출 횟수로 중복 재시작 여부를 판정한다.
- 전체 게임도 웹 내보내기 후 Chrome에서 로비 음악 출력 및 대전 진입을 확인했다. 기존 `ui_menu_test`, `ui_lobby_test`도 통과했다.
