# 마작 탁·탁·탁 착지 연출 v0.1

2026-10-18. `DICE_MAHJONG`의 기존 문자 패 세 개를 실제 두께가 있는 3D 패로 바꾸고, 확정된 세 장을 왼쪽부터 차례로 내려놓는다. 게임 규칙·추첨·이동량·추가 굴림은 기존 엔진을 따른다.

## 패와 그림

현재 엔진의 30종만 구현한다: 만수 1–9, 통수 1–9, 삭수 1–9, 백·발·중. 풍패·적도라·꽃패를 추가하지 않는다. 만수와 발·중의 한자는 작은 전용 글꼴로 정확히 표기한다. 통수·삭수는 실제 랭크만큼 문양을 배치하며 1삭은 새 그림, 백은 빈 앞면이다. 2·3·4·6·8삭은 녹색 문양만 사용한다.

문양의 일반적인 형태는 [World Riichi Championship 규정의 Tiles 항목](https://www.worldriichi.org/s/WRC_Rules_2022_20220708_site.pdf)을 참고했다. 실제 게임의 3장 조합과 보상은 이 팬게임의 간략한 규칙이며 정식 마작 한 판을 재현하는 것은 아니다.

`assets/ui/trickcal/mahjong/`의 개별 PNG 7개는 내장 `image_gen.imagegen`으로 생성했다. 세 색상의 통수 원형 문양, 두 색상의 대나무, 1삭 새, 뒷면 클로버다. 각 원본은 1254×1254 RGBA, 실제 알파 포함이며 원본 픽셀을 편집하지 않았다. Godot import는 무손실·256px 상한·mipmap을 사용한다. 런타임에서는 알파 0.08 이상인 내용의 범위에 2px 여백을 더해 비율을 유지하며 문양 칸에 맞춘다. 문양 개수는 생성 모델이 아닌 코드가 결정한다.

전문·원본 경로·저장 경로·SHA-256·QA: [manifest.json](../../assets/ui/trickcal/mahjong/manifest.json). 7회 생성, 추가 교정 0회. 색상별 통수 장식의 내부 꽃잎 형태 차이는 허용했으며 한 개의 원형 문양이라는 외곽과 실제 배치 개수는 유지했다. 모델 이름은 생성 도구가 공개하지 않는다.

글꼴은 Noto Sans JP의 굵기 700에서 한자 12자와 공백만 남긴 `TRG Mahjong Glyphs` 4,956바이트다. 원본 출처·해시·OFL 라이선스는 [글꼴 NOTICE](../../assets/fonts/mahjong/NOTICE.md)에 기록했다.

패는 회전과 이동만 하며 늘이거나 찌그러뜨리지 않는다. 실제 회전 자세의 지지 높이를 계산해 바닥을 뚫지 않게 한다. 프레임 범위 검사는 회전 중 여덟 모서리와 윤곽선 여유까지 포함한다. 카메라 반응은 이 마작 뷰포트에만 적용하고 `Engine.time_scale`이나 게임·네트워크 시계를 멈추지 않는다.

패 이름은 각각 닿을 때 공개한다. 족보·이동량·`last_display`는 세 번째 패의 정착 뒤에 공개한다. 역만은 실제 결과의 12칸과 추가 굴림을 표시한다. 그림 로드와 투명 여백 측정은 착지 타임라인 시작 전에 끝내고 재사용한다. 한 뷰포트·공통 패 메시·필요한 앞면 텍스처를 캐시하며 종료·취소·다른 도구 전환 시 3D 렌더링을 중지한다.

## 착지음

전용 `mahjong_tap` 이벤트를 각 물리 접촉 시점에 한 번만 호출한다. 앞선 패가 닿을 때 다음 패의 소리가 미리 나지 않는다. 이름이 일치하는 사용자 사운드가 있으면 기존 로더가 우선 사용하고, 없으면 22,050Hz/16bit PCM 합성음을 캐시한다.

합성음은 약 100ms이며 높은 단단한 클릭, 14ms 잡음, 짧은 620→270Hz 공명, 낮은 185→120Hz 잔향을 겹친다. 세 착지의 보정 음량은 -1.5/-1.0/-0.5dB, 음높이는 0.98/1.00/1.02, 무작위 피치 변동은 0이다. 0.24초 간격 사이에 소리가 끝난다. 기존 음소거·효과음 음량 설정을 따른다. 프레임을 크게 건너뛰면 지난 착지음을 한꺼번에 겹쳐 재생하지 않는다.

## 검증

로컬 Godot 4.7.1의 **335 tests / 32,078 assertions / 실패 0**, `MAHJONG_FACE_COVERAGE 30/30`, `MAHJONG_SLAM_FX_OK`, `UI_FX_OK`를 확인했다. ID/문양 개수/한자, 녹색 삭수, 접촉 시간과 35ms 정지, 바닥 관통 방지, 비변형, 프레임 여유, 단일 착지 이벤트, 결과 숨김, 취소·캐시 재사용·유휴 렌더 중지를 검사했다.

실제 Native Compatibility 게임 화면에서 일반 세 패와 백·발·중을 캡처하고 전체 30종 갤러리를 확인했다. Movie Writer가 기록한 실제 오디오에서 세 개의 분리된 트랜지언트를 확인했다. 예시 녹음 시작점은 0.620/0.855/1.090초로, 프레임 단위 0.24초 리듬과 맞는다. 소리가 포함된 MP4와 네이티브 PNG 프레임을 별도 산출물로 보관한다. 검수용 확정 결과를 주입한 캡처이며 실제 추첨을 바꾸지 않는다.

마작 3D 뷰포트의 실제 렌더는 16 draw calls / 12,114 primitives다. 기존 Windows headless WebRTC·인증서 진단과 종료 자원 경고는 남아 있으며 새 스크립트·셰이더 오류는 없었다. 로컬 녹화를 최종 배포 브라우저의 직접 시각 확인으로 취급하지 않는다.
