# 약실 실린더 디테일 v0.2

사용자가 제공한 실린더 사진 3장을 형태 참고로 사용했다. 단독 3D 모델의 기본 비율과 한 발 장전·회전 동작을 유지하면서 다음만 보강했다.

- 옆면 홈 6개: 깊이 0.105, 각도 반폭 0.24 rad. 길이 방향 양 끝을 둥글게 연결한 실제 메시 홈.
- 중앙 추출기: 약실 사이로 뻗은 6개 팔, 모따기, 중앙 육각 허브.
- 약실 입구: 입구 반지름 0.245로 모따기를 넓히고 폭 0.011의 얇은 금속 테두리를 추가.
- 표면: 은회색 금속, metallic 0.70 / roughness 0.34.

기존 본체 반지름 1.03, 전체 두께 1.20, 약실 중심 반경 0.62, 내부 반지름 0.215는 유지했다. 탄피는 1개다.

저장 모델: `assets/models/revolver/cylinder_v02.tscn`, `cylinder_v02.glb`, `cylinder_body_v02.res`. 기존 v0.1 파일도 보존했다. 미리보기 씬 `scenes/revolver_cylinder_preview.tscn`은 보강된 모델을 표시한다.

검증: 본체 7,928개 삼각형, 연결 이상 모서리 0개. 약실 6곳의 관통과 바깥 금속 면을 광선으로 확인했다. 메시 및 GLB 저장·재읽기, 실제 렌더링의 정면·사선·회전 확인 완료.
