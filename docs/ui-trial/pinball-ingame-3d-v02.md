# 핀볼 물리 낙하 연출 v0.2

v0.1의 A* 경로와 열별 등속 이동을 제거했다. 구슬은 고정 1/240초 간격으로 중력 가속, 핀·측벽·포켓 입구 반사, 포켓 내부 마찰과 바닥 반동을 계산한다. 이 궤적을 시간으로 샘플링하여 렌더 프레임률에 관계없이 같은 움직임을 재생한다.

- 구슬은 핀을 피해 방향을 꺾는 대신 실제 핀 표면에 접촉하고 반사된다. 이동 중 결과 포켓으로 유도하는 힘이나 좌표 보정은 사용하지 않는다.
- `ToolPinball`의 결과 확률과 이동값은 그대로 유지한다. 도착 포켓에 맞는 발사 초기 속도를 검증해 선택한다. 게임 RNG는 추가로 사용하지 않는다.
- 각 포켓의 세 가지 발사 후보를 사용한다. 현재 플랫폼의 부동소수점 계산으로 실제 도착 포켓을 다시 확인한 다음 캐시한다. 예외 시 같은 물리 계산으로 다른 발사 후보를 탐색한다.
- 포켓 안에서는 속도가 줄고 벽·바닥에 약하게 튕긴 뒤 자연스럽게 멈춘 위치를 유지한다. 마지막에 중앙으로 순간 이동하지 않는다.
- 발사 레인의 상승은 초반에 빠르고 이후 느려지게 조정했다. 핀 효과음도 일정한 간격 대신 계산된 접촉 시점에 맞춘다.
- 실제 검토 캡처는 발사 후보 17, 핀 접촉 4회, 낙하·정착 2.058초다. 발사/레일과 결과 유지 시간을 포함하면 약 3.8초다. UI 통합 검사의 대기 한도도 늘렸다.

## 검증

- 전체 단위 검사: 431 tests / 590015 assertions / 0 failures.
- 7개 포켓 × 3가지 궤적의 실제 모델 핀 간섭, 접촉 유무, 연속성, 포켓 폭·깊이·바닥 높이 및 정착 시간 확인.
- 첫 충돌 전 중력 가속과 접촉 후 진행 방향 변화 확인.
- UI 통합 검사 `UI_FX_OK`.
- 실제 MainBoard 발사 버튼과 native Compatibility 캡처 `PINBALL_GAME_OK`: 입력 잠금/해제, 취소·숨김, RNG 불변, 유휴 렌더 중지 확인.
- 실제 프레임으로 구슬의 반사·포켓 착지를 검토했다. 캡처와 GIF는 작업공간 `outputs/pinball-ingame-v02/`에 있다.

이번 변경은 로컬 적용이다. 웹 배포·브라우저 검증은 하지 않았다. 기존 프로젝트의 종료 시 리소스 정리 경고는 남아 있다.
