# 공산주의 재분배 연출

SUPER_02의 규칙과 난수 처리는 유지한다. 손패를 먼저 중앙으로 회수하고, 목적 칸을 표시한 뒤 실제 말들을 꼴찌와 같은 진도로 함께 이동시킨다. 모인 카드 묶음은 좌우로 나뉘어 섞이고 기존 테이블 옆 카드덱으로 돌아간다. 이어지는 새 카드 공개·손패 지급은 기존 예약된 카드 지급 큐가 한 번만 처리한다.

`redistribution_started` 신호는 변경 전 손패 수와 기준 플레이어만 전달한다. 카드 내용을 공개하지 않으며 게임 상태를 수정하거나 난수를 소비하지 않는다. UI는 선택 직후의 말 목적지와 표시 여부를 따로 기록하므로 뒤에 고른 다른 증강의 상태와 섞이지 않는다.

`scenes/redistribution_stage.gd`가 회수 → 진도 정렬 → 섞기 → 덱 복귀를 하나의 로컬 시계로 진행한다. 내 손패의 카드들은 실제 손패 위치에서 출발하고, 빈 손패에서는 회수 카드가 나오지 않는다. 새 손패는 예약 지급이 끝날 때까지 숨긴다. 이동한 말의 회전·확대·표시 순서는 종료 시 복구하고, 초기화 시 현재 엔진 상태로 정리한다.

검사는 `tests/ui_redistribution_test.gd`만 실행한다. 실제 증강 경로에서 빈 손패와 5장 손패, 단계 순서, 지급 대기, 카드 수, 말 도착·정리 및 RNG 보존을 확인한다. `[check:redistribution]`은 이 전용 검사만 배포에 실행한다. 전체 검사와 다른 초증강 검사는 이번 범위에 포함하지 않는다.
