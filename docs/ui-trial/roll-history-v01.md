# 연속 판정 결과 기록

현재 차례에서 실제로 공개된 결과를 판정 도구 옆에 순서대로 쌓는다. 윷은 이동 보너스가 붙은 칸수 대신 실제 나온 면(낙·도·개·걸·윷·모)을 기록하고, 러시안 룰렛은 안전한 방아쇠마다 성공을 기록한다. 실패 시 이전 성공과 실패를 함께 남기고 턴 종료를 표시한다.

- 결과 애니메이션이 끝나 공개되는 시점에 추가한다. 판정 이벤트가 먼저 도착해도 결과를 미리 보여 주지 않는다.
- 러시안 룰렛 멈추기, 블랙잭 스탠드, 야추 확정은 새로운 굴림으로 세지 않는다. 리볼버의 다섯 번째 성공에 따른 자동 확정은 실제 발사이므로 성공으로 센다.
- 같은 플레이어의 추가 차례도 새 차례로 분리한다. 새 차례의 굴림, 도구 교체, 새 게임·되감기는 이전 기록을 초기화한다. 즉시 턴 종료 판정은 엔진의 차례 변경에 앞서 잡아 둔 원래 차례에 붙여 실패 연출 중에도 보인다.
- 룰렛·화투·마작·타로·야추·블랙잭에도 적용한다. 일반 도구는 추가 도전·재굴림·턴 종료 판정이 있을 때부터 표시한다. 긴 연쇄는 최근 여섯 결과와 전체 횟수를 표시한다.
- 기존 크림색 패널과 녹색·황토색·붉은색 글자를 사용한다. 도구 왼쪽에 놓으며 카드 스테이지는 위에 가로로 배치한다. 입력을 가로채지 않는다.
- 엔진, RNG, 윷 재굴림 상한, 이동·템포 규칙은 변경하지 않는다.

검증: `tests/ui_roll_history_test.gd`. 실제 도구 결과와 MainBoard의 공개 경로로 순서·실패·확정 중복 방지·새 차례·오래된 이벤트·긴 연쇄·공개 시점·입력 통과·RNG 불변을 확인한다. 844×390, 740×360, 1366×768 배치 및 한·영·일 문구를 확인하며 Godot는 항상 `--audio-driver Dummy`로 실행한다. CI는 `[check:roll-history]`로 해당 기능만 검사한다.
