# 방어 카드 삽화 4종

방어 카드 CNT_04~07의 이모지 임시 그림을 지정한 캐릭터의 전용 장면으로 교체했다.

| ID | 카드 | 캐릭터 | 장면 |
| --- | --- | --- | --- |
| CNT_04 | 빗나감! | 모모 | 통나무에 공격이 맞는 동안 옆으로 피하는 바꿔치기 |
| CNT_05 | 싸이크론 | 실라 | 회오리로 적 말을 날리고 함정 파괴 |
| CNT_06 | 왕궁의 포고령 | 네르 | 왕궁의 칙령을 패러디해 성벽 발코니에서 선포 |
| CNT_07 | 도굴꾼 | 마요 | 함정카드를 들고 뒤를 돌아보며 도주 |

기존 카드 스타일에 맞춘 3등신 치비·따뜻한 외곽선·단순한 채색을 사용했다. 손은 엄지 포함 4개를 기준으로 검수했다. 네르 그림의 함정 소품 글자를 제거하고 마요 그림의 배경 말 손가락을 수정했다. 카드명·효과·규칙·사용 시점은 변경하지 않았다.

내장 이미지 생성 도구로 자산별 제작했다. 1448×1086 PNG 원본 바이트를 그대로 복사하고 기존 1024px 임포트·UID를 유지했다. 원본·프롬프트·참조 출처·해시·보정 전 시안·교체 전 자산은 outputs/cards-defense-v01에 보관한다. 최신 해시는 assets/cards/illustrations.json에 기록했다.

실제 CardSkin 확대·손패 크기 4종과 MainBoard 손패·확대 화면을 렌더해 CARD_ART_OK를 확인했다. 네 카드가 자기 ID의 PNG를 읽고 런타임 최대 크기가 1024px인 것을 검사했다. 육안으로 주요 동작과 전체 그림의 비율 유지·클리핑을 확인했다.
