## 규칙

- 대전 화면 진입 시 같은 확률(각 1/6)로 1장을 고른다. 게임 내 새 게임을 실행하면 다시 선택한다. 연속으로 같은 이미지가 나올 수 있다.
- 같은 대전의 턴·라운드·메뉴·판정 도구·보드 시점·창 크기 변경은 배경을 바꾸지 않는다.
- 별도 `RandomNumberGenerator`로 고른다. 게임 규칙의 RNG 및 온라인 동기화 데이터에 영향을 주지 않는 로컬 장식이다.
- `TextureRect.STRETCH_KEEP_ASPECT_COVERED`로 비율을 유지하며 화면 전체를 채운다. 넘치는 부분만 중앙에서 자른다.
- 로비와 같은 배경 전용 블러 셰이더를 사용한다. 원본 기준 반경 `2.0px`, 3×3 가중치 `[[1,2,1],[2,4,2],[1,2,1]] / 16`이다.
- 블러는 보드·기물·카드·텍스트에 적용하지 않는다. 배경 노드는 입력을 가로채지 않는다.
- 기존 기울인 시점의 펠트가 그림을 가리지 않도록 제거했다. 탑뷰/기울인 시점에서 같은 배경을 사용한다.

구현: `scenes/match_background.gd`, `scenes/main_board.gd`. 로비 배경 목록 4장은 별도로 유지한다.

검증: 실제 Godot 렌더에서 1366×768과 844×390의 6장 모두를 캡처했다. 선택 유지·입력 통과·등비 채움·시점 변경·새 게임 재선택을 확인했고, 그림 선택 전후 게임 RNG 상태가 동일함을 검사했다. 기존 `ui_fx_test`의 시점 검사도 새 배경 동작에 맞춰 갱신했다.
