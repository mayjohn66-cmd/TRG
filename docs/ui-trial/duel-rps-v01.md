# 묵찌빠 단두대 — 가위바위보 연출

손 그림 버튼에서 바위·가위·보 중 하나를 고르면 선택을 숨긴다. 둘 다 제출하면 주먹을 세 번 흔든 뒤 같은 프레임에 두 손을 공개하고 실제 승자를 금색으로 강조한다. 같은 손이면 두 사람 모두 다시 고른다. 연속 무승부로 신청자에게 승리를 주던 예외는 제거했다. 승리 이후의 기물 사출·전진 규칙은 유지한다.

입력은 중복 클릭을 차단하며, 핫시트에서는 앞 사람이 고른 손을 뒷사람에게 노출하지 않는다. 빠르게 도착한 봇·온라인 결과도 공개 모션을 거친다. 공개 도중 닫으면 지연된 손 공개를 취소한다. 종목 안내는 기존의 큰 시작 전 화면에만 표시한다.

검증: 516개 단위 테스트 / 596474 assertions / 0 failures, 전체 UI FX 6종 대결 통과, 실제 카드 사용 → 두 번 무승부 → 바위 대 가위 승리 → 정리 과정 검사 통과. PC·모바일 네이티브 렌더링 확인.
