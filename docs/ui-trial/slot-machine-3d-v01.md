# 777 슬롯머신 연출 v0.1

2026-10-18. 글자를 무작위로 바꾸던 임시 슬롯을 녹색·크림색 장난감 본체와 실제 3D 원통 릴 세 개로 교체했다. 개별 생성한 체리·레몬·종·다이아 아이콘과 정확한 글꼴의 BAR·7을 하나의 그림 띠로 감아 회전시킨다. 레버가 당겨지고 세 릴이 가속·감속해 왼쪽부터 잠기며, 일치한 릴의 표시등과 창 테두리만 금색으로 강조한다.

## 기존 판정 유지

`ToolSlot777`이 여섯 심볼 중 하나를 세 번 독립 추첨한다. `details.reels`의 실제 값을 받아 움직이며 추첨·이동·확률·재굴림 규칙은 바꾸지 않는다. 파워는 회전수에만 영향을 준다. 216개 조합을 모두 검사했다.

| 심볼 ID | 그림 |
| --- | --- |
| 0 / 1 / 2 | 체리 / 레몬 / 종 |
| 3 / 4 / 5 | BAR / 다이아 / 7 |

| 일치 | 이동 | 강조 |
| --- | --- | --- |
| 없음 | 1칸 | 금색 강조 없음, `일치 없음` |
| 두 개 | 4칸 | 실제 같은 두 릴만 강조, 떨어진 두 릴도 포함 |
| 세 개 | 8칸 | 세 릴 강조 |
| 777 | 20칸 | 세 릴 강조, `777 잭팟!` |

릴은 정지할 때 실제 중앙 심볼이 읽힌다. 전체 결과·이동 문구와 `last_display`는 세 릴의 반동이 끝난 뒤에만 공개한다. 임의의 가짜 7이나 추가 근접 실패 연출은 넣지 않았다. 기존 큰 굴리기 버튼 → 엔진 이벤트 → `RollPresenter` 경로를 사용한다.

## 고정 수치

| 항목 | 값 |
| --- | --- |
| 표시 / 렌더 | 500×330 / 1000×660px, MSAA 2× |
| 카메라 | 직교 size 4.6, (0,1.6,12) → (0.18,0,0) |
| 원통 | 반지름 1.0, 폭 1.02, 192개 원주 구간, X축 회전 |
| 릴 중심 | X = -1.35 / 0 / 1.35, Y = 0, Z = -0.35 |
| 그림 띠 | 256×1536px, 256px 셀 6개, 한 번 렌더해 캐시 |
| 시작 각도 | 0 / 120 / 240°; 결과와 독립 |
| 준비 / 가속 | 0.10 / 0.12초 |
| 각 릴 감속 | 정지 직전 0.55초 |
| 세 릴의 정지 | 1.10 / 1.48 / 1.86초 |
| 릴 반동 | 0.14초, 각도 계수 최대 0.035rad |
| 결과 공개 / 유지 / 전체 | 2.00 / 0.65 / 2.65초 |
| 본체 반응 | 릴 정지 후 0.14초, 위치 계수 최대 0.025 |
| 레버 | 처음 0.30초 동안 -0.75rad 사인 왕복 |
| 회전수 | 2+round(power×2)+릴 번호(0~2)회 + 목표 그림까지 각도 |

가속 → 일정 속도 → 세제곱 속도 감쇠의 적분을 사용해 각도와 각속도를 연속으로 유지한다. 모든 릴이 중앙 그림에 맞춰 정지하고 반동 중에도 다른 심볼 구간으로 넘어가지 않는다. `Engine.time_scale`과 네트워크 시계는 건드리지 않는다.

원통의 실제 UV는 `v=0.5/6-θ/TAU`, 심볼 s의 띠 행은 `(-s) mod 6`이다. 그림 위아래가 뒤집히지 않고 0/5 경계에서도 띠가 연속이다. 회전 중에만 속도에 비례하는 5샘플 세로 블러를 적용하며 정지하면 선명해진다. 본체가 원통의 상하를 실제 깊이로 가린다. 창 안쪽 높이는 약 1.12이다. 둥근 상자 모서리 반지름을 가장 얇은 반두께 이하로 제한해 얇은 장식의 면이 겹치지 않는다.

## 그림과 색상

내장 `image_gen__imagegen`으로 심볼 네 개를 각각 생성했다. 모두 1254×1254 RGBA PNG이며 원본 픽셀과 알파는 수정하지 않았다. 원본·저장 경로·전문 프롬프트·SHA-256·알파 범위·검수 기록은 [manifest.json](../../assets/ui/trickcal/slot/manifest.json)에 있다. 네 번 생성, 이미지 교정 0회. 이미지 모델 이름은 도구가 공개하지 않는다.

생성 원본에는 아주 낮은 알파의 외곽 잡음이 일부 있어 원본에 그대로 보존했다. 실제 게임의 크림색 릴 합성에서 잘림·검은 배경·누끼 띠가 없는 것을 Native 캡처로 확인했다. 투명 여백 차이는 Godot의 TextureRect 크기(체리 240, 레몬 216, 종 224, 다이아 208px)로 맞춰 실제 심볼 크기를 비슷하게 했다. BAR와 7은 ONE Mobile POP으로 직접 렌더한다. import는 무손실·mipmap·최대 256px이다.

본체 `#46734D / #A1D77B`, 크림 `#FFF0C9`, 릴 종이 `#FFF8DF`, 장식 녹색 `#649F48`, 7 `#DE5076`, 손잡이 `#EB83A7`, 정지등 `#A1DB64`, 일치등 `#FFD45F`, 일치 테두리 `#EAB03F`. 3단 셀 명암과 원통 곡면의 감쇠를 적용한다.

## 소리와 수명

외부 음원 선정은 보류하고 교체 가능한 임시 합성음으로 연결했다. `slot_spin`은 약 170ms의 작은 모터음(-17dB)을 회전 중 0.16초 간격으로 재생한다. `slot_stop`은 약 77ms의 잠금음(-3dB)이며 세 릴에서 피치 0.94/1.02/1.10을 쓴다. 일치 결과는 기존 `good` 임시 알림음을 사용한다. 기존 파일 로더·음량·음소거 설정을 따른다. 버튼의 일반 주사위 소리는 슬롯에서 중복 재생하지 않는다. 지연된 프레임의 과거 정지음을 몰아서 내지 않는다.

본체·릴·그림 띠·재질을 재사용한다. 완료·취소·새 게임·다른 도구 전환 시 뷰포트를 중지하고 대기 중인 게임 처리를 풀어 준다. 릴 정지 이벤트는 각 릴마다 한 번만 발생한다.

## 검증

Godot 4.7.1 로컬: **350 tests / 73,517 assertions / 실패 0**, `SLOT_COMBINATION_COVERAGE 216/216`, `SLOT_MACHINE_FX_OK`, `UI_FX_OK`. 전체 조합·최소/중간/최대 파워의 실제 면, 회전 연속성, 반동 결과 유지, 원통 UV·앞면, 일치등, 결과 숨김, 세 정지 이벤트, 재사용·완료·중도 취소·도구 전환을 확인했다.

Native Compatibility MainBoard에서 고정 시드로 실제 엔진 추첨 → 버튼 → 결과 이벤트 → 슬롯 팝업을 녹화했다. 777과 레몬 페어를 확인하고 실제 3D 갤러리에서 심볼 6종과 1/4/8/20칸 표시를 검수했다. 실제 뷰포트는 약 **30 draw calls / 31.4K primitives**. 실제 Movie Writer 영상과 오디오로 MP4 미리보기를 만든다.

기존 Windows headless 인증서·WebRTC 진단과 종료 자원 경고는 남아 있다. 새 스크립트·셰이더 오류는 없다. 로컬 Native 캡처와 최종 배포 브라우저의 직접 시각 검증은 구분한다.
