# 함정 카드 캐릭터 일러스트 6종

현재 배경 기준은 [카드 일러스트 공통 제작 기준](card-art-direction.md)을 따른다. 여섯 카드는 `simple-background-v5`에서 캐릭터와 핵심 소품을 유지하며 단순한 배경으로 교체했다.

기존 카드와 같은 4:3 가로 삽화와 3등신 치비 비율, 단순한 네 손가락/주먹 손 형태로 내장 이미지 생성 도구에서 제작했다.

| ID | 카드명 | 캐릭터와 장면 |
| --- | --- | --- |
| TRP_06 | 바나나 껍질 | 시온 더 다크불릿이 앞을 보며 걷다가 바나나 껍질을 밟기 직전 |
| TRP_07 | 스파이크 | 프리클 앞에서 가시덩굴이 솟아오르는 소환 장면 |
| TRP_08 | 강제 환승 포탈 | 에스피가 포탈에 발부터 끌려가며 당황하는 장면 |
| TRP_C02 | 우이의 소원빌기 | 우이가 든 네잎클로버에 초록·금빛 마법이 모여 발동하려는 순간 |
| TRP_C03 | 지나가는 상인 | 시스트가 권총을 들고 통행 대가를 요구하는 장면 |
| TRP_C04 | 물의 세례를 받아라 | 호수 속 나이아가 물가의 실피르를 잡아당기고 실피르가 버티는 장면 |

TRP_C02/03/04는 기존 피아식별 점프대/톨게이트/타르의 표시 이름을 교체했다. CSV, 카드 기본값, 설치물 이름의 로그 대체값, 규칙 도감 목록을 맞췄다. ID, 클래스, 효과, 파라미터와 스냅샷 형식은 유지한다. 이번 산출물은 카드 삽화이며 보드 설치 아이콘은 별도 리소스로 유지한다.

원본은 이미지 생성 결과 그대로 저장했다. 임포트는 최대 640px, 손실 품질 0.85, 밉맵 사용. `assets/cards/illustrations.json`의 `trap-character-scenes-v4` 항목에 원본 크기와 SHA-256을 기록한다. 작업 폴더 `outputs/cards-traps-v04/`에는 참조 출처, 최종 프롬프트, 보정 전 버전, 교체 전 백업, 실제 카드/손패/상세 검수를 보관한다.

보정은 시온의 펼친 손을 주먹으로 정리한 1회와 우이의 클로버를 정확히 네 잎으로 정리한 1회다. 다른 네 삽화는 첫 생성본을 사용했다.
