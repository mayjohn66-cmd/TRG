# 인생게임 룰렛 연출 v0.1

2026-10-18. 임시 2D 부채꼴 원판을 녹색 받침·크림/금색 테두리·파스텔 10칸·고정 포인터가 있는 3D 장난감 원판으로 교체했다. 내 턴의 드래그 패드(`RollPad`)와 다른 플레이어의 결과 팝업(`RollPresenter`)이 같은 `RouletteSpin3D`를 사용한다. 게임 전체 화면을 이미지로 덮는 방식이 아니다.

## 판정과 조작

기존 `ToolLifeRoulette`의 1~10 균등 추첨과 7의 재굴림 규칙을 유지한다. 숫자는 정확한 10개 섹터와 ONE Mobile POP 글꼴의 실제 3D 라벨이다. 생성 이미지에 숫자나 눈금의 정확성을 맡기지 않는다. 새로운 이미지·외부 음원을 다운로드하지 않았다.

원판을 톡 치거나 드래그해 놓으면 기존 명령 → 엔진 추첨 → 결과 이벤트 → 직접 조작 패드의 흐름으로 재생한다. 파워는 추가 회전수만 바꾸며 결과에는 영향을 주지 않는다. 드래그한 시점의 각도에서 이어지고, 시계/반시계 양쪽에서 지정된 칸의 중앙에 멈춘다. 정지 후 짧은 탄성 반응은 같은 칸 안에 머문다. 결과 문구·이동 칸수·재굴림은 정착 뒤에만 공개한다.

## 색상과 3D 구성

고정 받침 `#46734D`, 크림 테두리 `#FFF0BC`, 금색 안쪽 림 `#D9AA45`. 1~10 칸은 순서대로 `#C6E89B`, `#8FD7CF`, `#F5AEC7`, `#9CD4ED`, `#C6E89B`, `#9CD4ED`, `#FFCF57`, `#F5AEC7`, `#8FD7CF`, `#E8D299`. 7만 금색 바탕이다. 숫자 잉크는 녹색 `#376245`, 7은 갈색 `#784723`, 외곽은 `#FFF7DC`다. 섹터 경계 간격은 0.020rad이다.

몸체는 회전 단면 메시, 섹터는 정확한 원호 메시, 포인터는 두께가 있는 오각형이다. 셀 명암 3단(1.0/0.86/0.67)을 사용한다. 삼각형은 Godot의 시계방향 앞면 규칙으로 생성한다. 실제 링의 위쪽 면과 안쪽 벽 방향도 Native 캡처에서 확인했다. 라벨은 원판에 부착돼 함께 회전한다. 결과 강조면은 숫자 아래에 있어 글자를 가리지 않는다.

메시를 공유하고 각 패드/팝업에 뷰포트 하나를 캐시한다. 직접 조작이 있을 때만 새 프레임을 그리고, 회전 중에는 연속 갱신한다. 완료·취소·새 게임·도구 교체 시 렌더링을 정지한다. 취소는 대기 중인 보드 처리에도 완료 신호를 보내 입력이 잠긴 채 남지 않게 한다.

## 임시 사운드

외부 음원 선정은 후속 작업으로 둔다. `roulette_tick`(약 33ms)과 `roulette_stop`(약 93ms)은 현재 합성 임시음이다. 기존 `content_trickcal/audio/sfx/` 로더로 교체할 수 있다.

섹터 경계가 고정 포인터를 통과하는 정확한 시간을 회전 곡선에서 역산한다. 경계 이벤트는 한 번씩 발생하며, 소리는 고속에서 최대 약 30회/초로 제한한다. 같은 경계가 두 번 소리 나거나 프레임 지연 후 지난 소리가 몰리지 않게 한다. 감속 시 경계 통과 간격과 소리 간격이 함께 길어진다. 포인터 클릭 -7dB, 정착음 -3dB, 7 재굴림의 짧은 알림 -8dB. 사용자 음량과 음소거를 따른다.
