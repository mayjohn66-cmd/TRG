# 셰이디 피격 왼쪽 눈 수정

내장 image_gen.imagegen 편집으로 셰이디 hit.png의 감긴 눈과 눈썹만 수정했다.
왼쪽을 보는 얼굴에서 코 쪽(화면 왼쪽)에 눈꺼풀의 안쪽 꼭짓점이 오고,
눈꼬리의 두 선은 귀 쪽(화면 오른쪽)으로 벌어지도록 다시 그렸다.
반대편 눈은 가려진다. 몸·팔다리 자세와 얼굴 방향은 유지했다.
다른 15개 공격/피격 PNG가 바뀌지 않은 것을 해시로 확인했다.
1254×1254 RGBA 원본 바이트를 그대로 복사했고, 모서리 투명 알파도 확인했다.
실제 프롬프트·출력 경로·원본 해시·직전 편집 입력 해시는 avatar-capture-poses.json에 있다.

게임 적용 화면: avatar-capture-v04-shady.png.

검증: UI_CAPTURE_OK 및 실제 게임 캡처 확인. 32칸 보드의 8번 칸은 점프 발판이므로
잡기 UI 검사의 배치를 1→2번 일반 칸으로 옮겼다. 런타임 규칙·연출 코드는 변경하지 않았다.
