# 웹 시작 화면 로딩바 v0.1

웹 부팅 화면의 금색 가는 게이지를 게임 UI 팔레트에 맞춘 크림색 프레임과 초록 게이지로 교체했다. 기존 로고·팁·팬게임 문구와 실제 Godot 다운로드/실행 완료 연결은 유지한다.

## 디자인 수치

- 너비: `min(440px, 78vw)`. 기본 높이 30px, 크림색 `#FFF4D6` 프레임, 녹색 `#769D48` 2px 테두리, 내부 여백 4px.
- 안쪽 트랙: `#DBE6BA`. 채움은 `#CBF493 → #8BDB50 → #61B83B` 세로 그라데이션이며 윗면 반사광과 아래 음영을 둔다.
- 진행 끝에 기존 기본말 원본(`PAWN_DEFAULT.png`)을 재사용한다. `web/loading-pawn.png`는 원본의 바이트 복사본이며 38px 영역에 표시한다. 말은 프레임 양 끝 밖으로 빠지지 않게 제한한다.
- 말의 상하 움직임: 최대 2px/0.9초. 게이지 반사광은 2.8초 주기. 진행률 변경 시 너비·말 위치 전환은 0.25초다.
- 높이 540px 이하 화면: 게이지 26px, 내부 여백 3px. 로고·상하 여백을 조절해 휴대폰 가로 화면에서 잘리지 않도록 한다.
- 퍼센트는 크림색 작은 배지로 표시하고, 문구는 게이지 아래에 둔다. 로딩 이미지에는 낮은 요청 우선순위를 지정한다.

## 실제 진행 상태

- `onProgress(current,total)`의 실제 값만 0~100%로 표시한다. 기존 최소 4% 채움은 제거했다. 시간에 따라 수치를 임의로 올리지 않는다.
- 총량을 알 수 없으면 짧은 게이지가 움직이고 `준비 중…`으로 표시한다. 말 마커와 숫자 퍼센트는 숨긴다.
- 100%는 `곧 시작해요!`로 표시하며, 게임 시작 Promise가 완료되면 기존 스플래시 종료 동작을 실행한다. 별도의 강제 대기 시간을 추가하지 않는다.
- 실패/미지원 브라우저에서는 장식 움직임을 멈추고 원래 오류 안내와 `확인 필요`를 표시한다. 실패 후 도착한 진행 콜백은 무시한다.
- `role=progressbar`와 실제 `aria-valuenow`를 제공한다. 총량이 없거나 실패했을 때는 숫자를 제거하고 상태 설명을 제공한다.
- `prefers-reduced-motion: reduce`에서는 말/반사광/왕복 게이지 애니메이션과 위치 전환을 끈다.

## 연결과 검증

소스: `web/shell.html`, `web/loading-pawn.png`. 배포 워크플로가 말 PNG도 웹 빌드 폴더에 복사한다. Godot PCK 로딩 전부터 사용할 수 있는 독립 웹 에셋이다.

`tests/e2e/loading_splash.mjs`는 실제 HTML 셸을 테스트 서버에서 읽고 엔진만 대역으로 교체해 실제 부팅 콜백을 호출한다. 1366×768, 664×526, 844×390, 667×375에서 총량 미상/0·1·61·99·100%, 말 범위, 이미지 로드, 움직임 줄이기, 정상 종료, 실패 및 미지원 브라우저를 확인했다. 캡처의 61%는 이 미리보기용 상태이며 실제 다운로드를 녹화한 것은 아니다.

실행: `node tests/e2e/loading_splash.mjs <playwright 모듈 경로> <Chromium 실행 파일> <캡처 폴더>`.
