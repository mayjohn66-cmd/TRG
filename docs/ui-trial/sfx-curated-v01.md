# 효과음 파일 도입

임시 합성음과 폭넓은 파일명 검색 대신 34개 이벤트에 맞춘 CC0 음원 39개를 연결했다.
총 약 285 KiB이며 기존 BGM 설정·곡 전환·사용자 음원 우선순위를 유지한다.

- 버튼·말 이동: 짧고 작은 클릭·칩 놓기. 이동마다 과도한 고음을 피하도록 고역을 줄였다.
- 카드: 종이 밀기·펼치기·놓기. 카드 공개 시점의 기존 콜백을 유지한다.
- 마작: 단단한 칩 충돌 녹음을 짧게 다듬어 각 패의 착지 시점에 재생한다.
- 윷: 나무 타격 녹음 3종으로 착지·재충돌을 구분한다. 던지기는 짧은 카드 펼침 소리를 사용한다.
- 룰렛·슬롯: 포인터 클릭·기계 스위치·스프링 소리. 빠른 반복 이벤트만 최소 재생 간격을 둔다.
- 장난감 총: 빈 약실은 스위치 찰칵, 깃발은 실제 플라스틱 경적 녹음.
- 교칙·함정·승급·결과: 나무 도장·짧은 알림·차임·피치카토 징글.

윷·마작·카드·슬롯·룰렛·장난감 총의 전용 연출 위에 공통 굴림음이 겹치던 호출을 제거했다.
주사위·친치로는 주사위 충돌음을 유지한다. 같은 프레임의 중복 클릭음은 막되 마작 3연타와
윷의 개별 착지음에는 이 제한을 적용하지 않는다. 여러 녹음이 있는 이벤트는 직전 파일을 연속 선택하지 않는다.

`assets/sfx/curated/catalog.gd`가 기존 무작위 후보보다 우선하며, 사용자 폴더에서 이벤트명 또는
별칭으로 넣은 파일이 있으면 그 이벤트 전체를 교체한다. 파일별 출처·가공·해시는 같은 폴더의
`manifest.json`, CC0 출처와 고지는 `CREDITS.md`와 `licenses/`에 기록했다.

검증: 전체 단위 테스트 356개/200454 assertions, `sfx_assets_test`, `ui_fx_test`, 전체 웹 내보내기 통과.
Chrome에서 실제 34개 음원의 목적지 파형 출력, 중복 클릭 억제, 음소거와 개별 음량을 검사했다.
전체 게임의 로비→대전 진입에서도 BGM과 새 클릭음·시작음을 확인했다.
원본 청음과 최종 취향 판단은 별개이며, 브라우저 검증은 재생·음량·타이밍의 기술 검사다.
