# 블랙잭 손패와 합계 중심 화면

블랙잭만 상단의 누적 결과 표찰을 숨기고, 560×240 고정 무대 안에 최근 카드 세 장을 겹친 손패·전체 장수·큰 합계·예상 이동 칸수·히트/스탠드를 함께 표시한다. 기존 홀덤 카드 그림을 재사용한다. 내부 손패 전체는 유지하며, 화면에 보이는 카드 수만 제한한다. 카드 수가 늘어나도 무대나 위쪽 기록이 커지지 않는다.

처음 여러 장을 받을 때도 0.08초 준비 후 보이는 카드가 동시에 들어오는 0.2초 연출을 사용한다. 배부 중에는 합계를 미리 공개하지 않고 버튼을 잠근다. 새 게임·차례 초기화 시 이전 배부 작업이 다시 화면을 덮지 않도록 취소한다. 스탠드는 카드를 다시 배부하지 않는다.

21·버스트·스탠드는 짧은 제목과 합계/이동 요약을 보여 준다. 종료 후 중앙 알림에서도 카드 전체 나열을 제외한다. 버스트의 프로필 반응과 0.9초 결과 확인 시간은 유지한다. 에이스 합산·판정·재굴림·이동·RNG 및 다른 도구의 결과 표찰은 변경하지 않는다.

검증은 `tests/ui_blackjack_compact_test.gd`만 실행한다. 한·영·일과 844×390, 740×360, 1366×768에서 무대·카드·합계·버튼 경계를 확인한다. 6장 시작 배부, 20장 손패, 21, 버스트, 스탠드, 버튼 이벤트, 배부 중 중복 입력, 취소 및 RNG 불변을 검사한다. Native Compatibility 렌더 캡처와 헤드리스 모두 `--audio-driver Dummy`를 사용한다. CI의 `[check:blackjack-compact]`는 해당 기능만 검사한다.
