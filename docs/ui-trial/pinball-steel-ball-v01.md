# 핀볼 쇠구슬 3D 모델 v0.1

별도로 재사용할 수 있는 매끈한 구형 메시와 금속 PBR 재질을 제작했다. 지름 0.23, 반지름 0.115 Godot 단위다. 기존 베이스의 두 레일 사이 유효 폭 0.26에 맞춰 전체 좌우 여유 0.03을 둔다. 원점은 구슬 중심이며 축별 스케일은 모두 1이다.

- `assets/models/pinball/steel_ball_v01.tscn`: 독립된 모델 씬.
- `scenes/pinball_ball_3d.gd`: 메시·재질 제작 소스.
- `assets/models/pinball/steel_ball_preview_environment_v01.tres`: 반사 확인용 스튜디오 환경. 구슬 모델 자체에는 환경을 포함하지 않는다.
- 금속성 1.0, 거칠기 0.12, 원형 단면·부드러운 노멀, 2,145개 버텍스. 흰 하이라이트는 메시 표면에 그린 무늬가 아니라 조명과 환경 반사다.

Godot 4.7.1-stable Native Compatibility에서 저장한 native 씬과 GLB를 각각 재로딩했다. 전체 버텍스의 반지름, 유한한 좌표, 단위 노멀 및 3축 지름을 확인했고, 실제 베이스의 발사 레인에 정적으로 놓아 크기와 위치를 확인했다(`PINBALL_STEEL_BALL_OK`). 베이스 원본 파일은 변경 전후 SHA-256이 동일하다.

이 모델링 단계에는 이동·발사 연출이나 물리 시뮬레이션을 연결하지 않았다. 레인 위 배치는 검토용 캡처에만 적용했다.
