# 난이도 표정과 상태 아이콘 — 2026-10-27

난이도 얼굴 5개는 직접 생성한 투명 표정 아틀라스 한 장을 쓴다. 열은 버터 같은 하트 눈에서 빨갛게 어지러운 매운 얼굴로 넘어가고, 둘째 줄은 깜빡임·미소·헉 하는 표정을 제공한다. 칸마다 미리 계산한 투명 경계로 두 줄 모두 52px 크기와 같은 가운데에 맞춘다. 고를 때 튀어 오름, 가만히 있을 때 흔들림, 가장 매운 단계의 살짝 떨림은 애니메이션 시계 하나를 함께 쓴다. 가장 매운 얼굴의 작은 불꽃 3개도 승인된 불꽃 그림을 쓴다. 난이도 선택기에 코드로 그린 얼굴·하트·땀방울·불꽃은 더 이상 없다.

먼저 받아 둔 불꽃·왕관·자물쇠 PNG를 실제 선택기와 기록 줄에 연결했다. 켜진 불꽃은 주황·금색을 유지하고, 아직 안 켜진 칸은 공통 라벤더 흑백 셰이더를 쓴다. 완료 왕관은 어떤 난이도를 골랐는지와 상관없이 저장된 완료 기록에 따른다. 완료하지 않은 단계는 자물쇠를 유지한다. 기존 버튼 크기·선택 색·기록·라면 그릇 타이밍은 그대로다.

원본은 `assets/ui/trickcal/difficulty/`에 바이트 그대로 복사했다. 불꽃·왕관·자물쇠 원본은 1254×1254 RGBA에 게임 내 128px 제한, 새 얼굴 아틀라스는 1983×793 RGBA에 1024px 제한이다. 투명 여백과 작은 크기에서의 표시를 확인했다. 생성된 칸 어긋남은 게임에서 영역 좌표로 바로잡았고, PNG를 다시 칠하거나 가리거나 크기를 바꾸거나 합성하지 않았다. [정확한 프롬프트·원본/최종 경로·해시·검수](../../../assets/ui/trickcal/difficulty/source.json).

실제 OpenGL로 `ui_difficulty_icons_test.gd`가 통과했다: 5칸 전체에 실제 포인터 입력, 클릭당 선택 신호 1회, 얼굴·그릇 상태 일치, 저장된 완료 배지, 꺼진 불꽃 상태, 프레임 영역 10개 전체, 숨겼을 때 애니메이션 멈춤·재개. 같은 테스트가 실제 훈련 메뉴를 열어 버튼 입력이 `GameSession`으로 난이도를 저장하는지 확인한다. 기존 그릇 검사도 통과했다. 지운 옛 다각형 함수의 단언은 `ui_menu_test.gd`에서 뺐고, 그 파일은 구문 검사를 통과한다. CI 범위 `difficulty-icons`는 내보내기·배포 전에 이 두 검사와 메뉴 구문 검사만 돌리고, 메뉴·게임 전체 테스트는 돌리지 않는다.
