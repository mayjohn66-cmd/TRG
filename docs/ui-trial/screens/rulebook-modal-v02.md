# 크게 보는 도감 항목 상세 — 2026-10-28

도감 상세는 가로 캔버스 폭의 88%, 위아래 논리 여백 24px의 넓은 쪽으로 열린다. 따로 둔 쪽 컨테이너 덕분에 가죽·종이 틀, 내용, 입력 경계가 함께 커지고, 아래 책 어둡게 하기는 원래 그린 윤곽을 유지한다. 원래 기본 규칙 노트는 이전 배치를 유지한다.

상세 내용은 1.4배로 키운다. 카드 앞면은 그 확대 전에 170×238에서 240×336으로, 다른 그림은 132×132에서 220×220으로 커진다. 큰 그림·카드는 왼쪽, 요약·규칙·메모는 그 오른쪽에 모은다. 긴 규칙은 기존 끌기 스크롤을 유지하고, 확대된 칸의 지역 좌표로 바꿔 내용이 포인터 거리만큼 따라온다. [닫기]는 그대로 있고 ESC는 먼저 목록으로 돌아간다.

보이는 쪽 바깥 아무 데나 마우스·손가락을 누르면 그 동작 전체를 가져가 바깥에서 뗄 때 닫는다. 창 뒤의 머리 버튼·장 탭·격자 항목은 같은 탭을 받지 않는다. 틀 안 탭은 닫지 않고, 안에서 시작한 끌기가 틀 밖으로 나가도 닫히지 않는다. 닫으면 같은 도감 장으로 돌아가고 스크롤 위치도 유지한다.

도감 검사가 844×390·740×360·1366×768에서 실제·헤드리스 검사 745개를 통과했다: 큰 창 경계, 안·밖 포인터와 실제 터치 동작, 바깥 휠 막기, 실제 뒤쪽 장 버튼 위에서 닫기, 확대 상태의 끌기 거리. 카드 상세와 그림이 있는 도구 상세의 실제 렌더를 확인했다. 기존 메뉴 단언은 규칙 글이 그림 옆에 묶였으므로 실제 규칙 글을 재귀로 찾는다. 넓은 메뉴 검사는 구문 검사만 한다. 로컬 실행은 모두 `--audio-driver Dummy`. CI 범위는 그대로 `rulebook-scroll`이고 게임 전체 테스트는 없다.
