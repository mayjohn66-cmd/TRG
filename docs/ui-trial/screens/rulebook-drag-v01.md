# 규칙 도감 끌어서 스크롤과 꽉 찬 카드 — 2026-10-28

도감의 두 스크롤 칸은 카드 위를 포함해 내용 아무 데나 마우스·손가락을 누른 채 끌면 스크롤된다. 화면 8픽셀 이동을 기준으로 탭과 끌기를 나눈다. 이 동작은 자식 버튼이 카드를 고르기 전에 누름·뗌을 가져가므로, 쓸어 넘기다가 실수로 상세가 열리지 않는다. 짧게 탭하면 원래 항목이 열린다. 실제 터치는 손가락 하나만 받고, 흉내 낸 마우스 이벤트나 다른 손가락이 같은 동작을 두 번 스크롤하지 않는다. 휠·실제 스크롤바·장 버튼·키보드 선택은 원래 방식대로다. 상세 창은 뒤의 격자를 끄는 것을 막고, 창 안의 긴 실제 카드 규칙은 따로 스크롤된다.

둥근 책은 넓은 폰 비율에서 가운데 1366px 띠에 머물지 않고, 쓸 수 있는 가로 캔버스 폭을 따른다. 안쪽 여백·요약·머리 조작·내용 칸·상세 창 어둡게 하기와 가운데가 함께 크기를 바꾼다. 원래 왼쪽 탭은 상세 창 어둡게 하기 위에 남는다. 카드는 격자 열을 채우고, 원래 앞면을 같은 비율로 키운 크기로 줄마다 최소 높이를 정한다. 그림·테두리·누르는 영역이 일치하고, 그림을 늘리거나 오른쪽에 빈 띠를 남기지 않는다. 폰은 증강 기반 항목 3열, 세로 카드 4열, 데스크톱은 4열. 새 그림·색·게임 규칙은 없다.

`ui_rulebook_scroll_test.gd`가 실제 OpenGL과 헤드리스(`--audio-driver Dummy`)에서 검사 724개를 통과했다. 844×390·740×360 터치 배치와 1366×768 데스크톱, 도감 6장 전체, 카드 경계, 마우스·실제 터치 탭·끌기, 마지막 줄, 긴 실제 카드 규칙, 상세 창 분리, 살아 있는 장 버튼, 한·영·일 배치 넘침, 저장 기록 불변을 다룬다. 6장 전체와 상세 창의 실제 렌더를 확인했다. CI 범위 `rulebook-scroll`은 배포 전에 이 도감 검사만 돌린다.
