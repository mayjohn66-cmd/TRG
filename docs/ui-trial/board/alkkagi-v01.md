# 실제 보드 위의 흑돌 알까기

1회용 흑돌 필살기는 기존 마름모 보드를 잠시 위에서 내려다보는 시점으로 펼친다. 같은 보드 그림·칸·함정·실제 말 그림이 화면에 그대로 남는다. 따로 나무 판이나 흑백 돌 세트를 띄우지 않는다. 취소하거나 결과가 나오면 카메라는 저장된 시점 설정을 바꾸지 않고 원래 시점으로 돌아간다.

실제 흑돌을 누르면 바로 방향 화살표가 보인다. 뒤로 끌면 반대 방향으로 조준한다: 점점 커지는 노랑~주황 판으로 된 가는 대가 화살촉으로 이어진다. 힘이 커질수록 화살이 길어지고 촉이 빨갛게 짙어진다. 당김 끈과 예상 도착점까지 이어지는 점선이 숫자 없이 방향과 세기를 보여 준다. 손을 떼면 다른 준비 동작이나 막는 필살기 알림 없이 바로 미끄러지며 딱 소리가 난다. 다른 곳을 누르거나, 아주 조금 끌거나, ESC·오른쪽 클릭·취소 버튼·OS 터치 취소·초점 잃음·창 크기 변경이 있으면 필살기를 쓰지 않는다. (2026-11 모바일 개선: 터치 기기에서는 돌을 정확히 집지 않아도 화면 아무 데나 누르고 당기면 그 자리 기준으로 조준한다.)

실제 흑돌 그림이 빠르게 미끄러지다 느려진다. 엔진이 정한 피해자는 공간 순서대로 접촉하고, 작은 불꽃·마른 타격음·65ms 짧은 정지를 받는다. 그 뒤 실제 말 그림이 위로, 바깥으로 굴러 보드 밖으로 날아간다. 쏜 돌이 결과 칸에 자리 잡은 뒤 카메라가 돌아오고 이어지는 착지 효과가 재개된다. 일반 잡기 컷인과 중복 사출은 이미 애니메이션된 피해자에게만 막는다. 상관없는 착지 잡기는 평소 대기열을 쓴다.

`AlkkagiStage`가 조작 피드백과 지역 연출 시간을 맡는다. `MainBoard`가 그 덮개를 보드에 투영하고 기존 말 그림을 움직인다. 힘·방향·맞을 수 있는 적·면역·착지·1회 소모는 `PawnSkills.shot_result`가 정한다. 이 연출은 새 튕김·무작위 결과·연쇄 잡기 규칙을 더하지 않고 `Engine.time_scale`을 바꾸지 않는다. 원격·봇 필살기 사건도 같은 경로를 쓴다.

`tests/ui_alkkagi_test.gd`가 돌만 고르기, 즉시 방향 피드백, 마우스·터치 떼기, 취소된 터치, 아주 작은 끌기, 좌표 방향, 미리보기·엔진 일치, 아군·보호막 제외, 순서 있는 접촉, 짧은 정지, 감속, 빗나감, 실제 상대 그림 이동, 카메라 복원, 대기열 완료, 초기화를 검사한다. 1366×768·844×390 실제 캡처와 녹화 데모는 작업 공간 `outputs/alkkagi-board-v02`에 있다. CI는 이 테스트를 기존 UI 스모크·UI 연출 전체 테스트와 함께 돌린다.
