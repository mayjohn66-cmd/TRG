# 중립 기물 경로 경고 그림

중립 기물(NPC) 공격 경로는 코드로 그린 해골 대신 `assets/board/decals/NPC_WARNING.png`를 쓴다. 생성한 투명 그림으로, 산호색 삼각형·짙은 빨강 안쪽 테두리·상아색 바깥 선·큰 상아색 느낌표로 되어 있다. 바깥 선 덕분에 보통 보드 크기에서도 깜빡이는 빨간 경로 바닥과 아이콘이 구분된다.

이 그림은 지형·함정 그림과 같은 보드 평면 투영과 변별 방향을 쓴다. 일반 칸은 짧은 변의 72%, 코너는 59% 크기다. 작은 상아색 화살표가 NPC의 실제 투영된 진행 방향을 따른다. 등각 좌표가 늘어나고 기울어져 있어, 화면 방향을 보드로 되돌릴 때 아핀 역변환을 쓴다.

위험 2단계에서는 기호가 겹치지 않게 경고 그림이 지형·부스터·함정 그림을 대신한다. 아래 칸과 함정 상태는 그대로 남고, 위험이 풀리면 그림도 돌아온다. 바닥만 깜빡이고 경고는 깜빡이는 동안에도 읽힌다. NPC 이동·범위·목표·잡기 규칙은 바뀌지 않았다.

원본 그림은 픽셀 수정 없이 보관했다. 256px 밉맵 텍스처로 임포트하고, 투명 경계 아틀라스 영역으로 게임에서 투명 여백을 잘라 낸다. 화살표는 기존 두꺼운 코너 화살표 그림을 다시 쓴다.

제작 기록: 작업 공간 `outputs/npc-warning-v01/prompt.json`·`manifest.json`, 내장 `image_gen` 생성, 투명 출력, 보정 재생성 0회. 시각 검수: 실제 보드, 보드 네 변 전체, 지형·부스터·코너·함정 겹침·복원을 담은 칸 갤러리. UI 연출 회귀 테스트도 경고 그림 표시·투영된 진행 방향·지우기와 복원을 확인한다.
