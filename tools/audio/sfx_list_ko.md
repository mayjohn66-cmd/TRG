# TRG 효과음 목록 — 기존 + 추가 제안

기준: `local/v1.01` 코드 (2026-11-03). 기존 목록은 `scenes/sfx.gd`·`assets/sfx/curated/catalog.gd`와 코드의 `Sfx.play(...)` 호출을 직접 세어 만들었다.
추가 목록은 "지금 소리가 없는 장면"과 "범용음 하나를 여러 장면이 나눠 쓰는 곳"을 코드에서 찾아 제안한 것이다 (★ = 우선순위 높음).

---

## 0. 공통 규격 (모든 프롬프트에 붙일 것)

- **톤**: 귀여운 2D 애니메이션 보드게임. 장난감·테이블 소품(나무 말, 플라스틱 칩, 종이 카드, 주사위) 질감 + 만화풍 과장. 피 튀기는 리얼 사운드, 무거운 영화 트레일러풍은 피한다.
- **형식**: OGG(또는 WAV), 모노, 44.1kHz, 피크 −1 dBFS, 앞 무음 0ms(바로 시작), 꼬리는 자연스럽게 페이드.
- **길이**: UI 0.05~0.2초 / 일반 효과 0.2~0.8초 / 알림·스팅어 0.8~2초 / 결과 팡파르 2~4초.
- **변형**: 자주 반복되는 소리(말 착지, 카드, 클릭, 틱)는 2~3개 변형(`_01`, `_02`, `_03`)을 만들면 게임이 무작위로 돌려 쓴다.
- **넣는 법**: `content_trickcal/audio/sfx/<이름>_01.ogg`에 넣으면 코드 수정 없이 기존 소리보다 우선 재생된다. **신규 이름(2장)은 코드 연결이 필요**하다.

## 3. 요약

- 기존: 효과음 62종(별칭 8개를 더하면 부를 수 있는 이름 70개) + 배경음 2종. 정의만 있고 쓰이지 않는 것 2개(`ui_hover`, `roll_other`).
- 범용음 과다 사용: `good` 13곳, `slam` 11곳, `charge` 9곳, `toy_click` 9곳 → 2-1장에서 분리.
- 추가 제안: **164개 파일** (2-1~2-12장, ★ 14개 우선). `victory_law_01~09`처럼 한 줄에 여러 파일이 묶인 것은 파일 수로 셌다.
- 신규 이름은 파일만 넣어서는 안 울리고 코드 연결이 필요하다. 파일이 들어오면 이름 그대로 연결하면 된다.
