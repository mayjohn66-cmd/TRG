# 에르핀 로비 아바타 고해상도 시범 적용 v0.1

- 출처: https://viewer.dclnslde.com/ 의 에르핀 사도 `Normal` 스킨, `Idle_1` 애니메이션.
- 뷰어 UI에서 카메라 1536px, 일시정지·타임라인 탐색·현재 프레임 PNG 저장으로 43장을 추출했다. 첫 프레임 이후 상호작용 모드는 끈 상태다.
- 저장된 PNG는 각 1536 × 1536 RGBA이며 원본 픽셀·알파를 그대로 보관한다. 재생 화면의 스크린샷, 기존 512px 프레임의 확대, 생성형 이미지 재작화는 사용하지 않았다.
- 추출 시점은 `manifest.json`의 `seek_percent`에 기록했다. UI 슬라이더의 약 1% 간격 반올림이 있어 엄밀한 1/16초 샘플링은 아니며, 재생은 기존과 같은 43장·16fps(한 주기 2.6875초)다.
- Godot 임포트는 1024 × 1024, `compress/mode=0`(무손실), 밉맵 사용이다. 1536px 소스의 2/3 해상도를 사용하므로 무축소 원본 표시로 표기하지 않는다.
- `../idle_hq.tres`의 각 AtlasTexture는 동일한 영역을 참조한다. 소스 좌표는 (88, 140, 1373, 1253), 임포트 좌표는 (58.666667, 93.333333, 915.333333, 835.333333)이다. 프레임별 크롭으로 중심이 흔들리는 것을 방지한다.
- 화면에 쓰이는 영역 높이는 약 835px로 기존 512px보다 약 1.63배다. 바탕 투명 여백을 제외한 캐릭터 형상의 높이도 약 819px로 기존 약 492px보다 크다.
- `HubKit.avatar_full()`은 `idle_hq.tres`를 선택한 사도의 큰 로비 아바타에서만 우선 로드한다. 작은 프로필 및 감정 애니메이션은 기존 에셋 경로를 사용한다.
- 43개 임포트 CTEX 합계는 약 29.52MiB로 기존 약 3.36MiB보다 크다. 밉맵을 포함한 RGBA8 GPU 텍스처 예상치는 약 229MiB다. 선택한 캐릭터의 로비 노드가 프레임을 참조하며 로비를 떠나면 참조를 해제한다. 전체 캐릭터로 확장하기 전 용량·메모리 최적화를 검토해야 한다.
- 파일별 원본 경로·크기·SHA256 및 공통 실루엣 영역은 `manifest.json`에 기록했다.
- 검증: 43장 해시 모두 다름, 원본과 프로젝트 복사본 해시 일치, 43개 리소스 로드·임포트 크기·공통 표시 영역 확인. 로컬 `UI_MENU_OK`, 그래픽 실행 GDScript·셰이더 오류 없음.

## v0.2 웹 용량 최적화 (2026-10-21)
- 원본 PNG(1536px)는 그대로 두고 임포트 설정만 바꿨다: 640px 임포트, 손실 WebP 품질 0.85, 밉맵 끔 (`tools/optimize_texture_imports.py`).
- `../idle_hq.tres`의 AtlasTexture 영역도 640px 기준으로 맞췄다: (36.6667, 58.3333, 572.083, 522.083). 로비 표시 높이 520px와 거의 1:1이며 다른 사도의 512px 프레임보다 크다.
- 43개 CTEX 합계 약 29.52MiB → 약 2.89MiB. GPU 메모리도 1024px+밉맵 대비 약 1/3 수준이다.
