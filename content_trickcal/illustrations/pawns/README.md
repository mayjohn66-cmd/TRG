# 보드 기물 이미지 규격 v0.4

기본·세부 병종 21종 + 쇼기 승급 4종 + 중립 NPC 2종, 총 27종을 각자의 투명 PNG로 표시한다. 정상 설치에서 도형이나 다른 병종 그림으로 대체되는 기물은 없다. 파일 누락/로드 실패에 대비한 코드 도형 폴백만 유지한다.

## 생성·보존

- 모든 PNG는 native image_gen.imagegen으로 각각 생성했다. 이미지 모델 ID는 도구에서 공개하지 않는다.
- 기존 첫 6종은 흰 배경 이미지 생성 후 같은 도구로 투명 배경을 만들었다. 나머지 21종은 처음부터 투명 배경으로 생성했다.
- 선택 원본을 픽셀 수정 없이 복사하고 SHA-256 일치를 확인한다. 원본 위치·프롬프트·실제 크기·RGBA·알파 범위·해시·채택 예외는 manifest.json에 기록한다.
- 팔레트와 카메라 각도는 생성 목표이며 수학적으로 강제한 값이 아니다. 미세 농도 및 안티앨리어싱을 포함한다.
- 룩은 지정한 3개 대신 4개의 성가퀴로 생성됐으며 실루엣이 명료해 채택했다.

## 수치·표시

- 런타임 최대 256px, 밉맵. 첫 6종은 손실 압축(mode=1, quality=0.9), 추가 21종은 무손실(mode=0).
- 보드 본체 최대 26 × 31px. 바닥 접촉 원점 (0,0), 하단 y=0. 종횡비를 유지하며 플레이어 받침대와 그림자는 별도 렌더링한다. NPC 본체 최대 28 × 32px.
- 알파 0.08 이상 실루엣 + 임포트 텍스처 2px 여유. 원본 PNG는 크롭하거나 늘이지 않는다.
- 플레이어: P1 #E5484D / P2 #3E8BFF / P3 #30A46C / P4 #F5B700. 받침대 윗면 반지름 (15,6), 측면 y=3, 안쪽 반지름 (11,3.5).
- 본체 외곽 플레이어 색상 0.7px, 쇼기 승급 붉은 외곽 #FF5E50 1.4px. 승급은 기본 그림의 재색칠이 아니라 각 병종의 승급 전용 PNG를 읽는다.
- 호기: 좌상단 (-12,-27), 외경 11.4px, 글자 9px. 업기: 받침대 20 × 9px 배지의 xN. 필살기: 우측 번개, 1.4초 주기 알파 0.7~1.0.
- 클릭 영역 (-18,-34), 36 × 42px. 보드 깊이 축소는 균일 배율, TILT 접지 보정 2px.
- 프로필 38px 슬롯 0.88배 / 48px 슬롯 1.12배, 하단 독 1.28배 y=44, 이동 선택 0.95배, 진화 선택 2.05배.

## 역할·매핑

- 장기 각인: 포 包 / 차 車 / 마 馬 / 상 象. 쇼기 기본: 보병 歩 / 비차 飛 / 각행 角 / 계마 桂.
- 쇼기 승급은 붉은 각인: 토금 と / 용왕 龍 / 용마 馬 / 성계 金. 성계의 金은 이 게임이 쓰는 승급 약어 '금'에 맞춘 식별 기호다.
- 흑/백돌은 광택과 명도, 도적은 후드·가면·자루, 고스트는 청록 몸체·분홍 안쪽 테두리·두 눈으로 구분한다.
- 자동 로드: 세부 타입_NARI → 공통 SHOGI_NARI → 세부 타입 → 윷/쇼기 별칭 → 계열 대표 → 도형 폴백. 현재는 세부/별칭 단계에서 27종 모두 해결된다.
- 보드·프로필 슬롯·하단 독·이동/진화 선택은 공통 PawnToken을 사용한다. 게임 규칙·이동·스킬 조건은 변경하지 않는다.

## 검증

- tests/test_pawn_art.gd는 실제 PawnCatalog와 NPC 열거형을 순회해 27종의 고유 경로·투명 알파·크기 제한·유효한 영역을 확인한다. 쇼기 승급이 기본 이미지로 폴백해도 실패한다. 기존 전체 테스트 러너에 등록했다.
- 실제 실행 갤러리와 보드 화면, 추가 병종·승급·NPC 화면을 확인한다. 검증 결과는 작업 산출물의 배포 기록에 남긴다.
- v0.4 로컬 결과: PAWN_ART_COVERAGE 27/27, 전체 322 tests / 25301 assertions / 0 failures. 실제 갤러리 27개 경로 모두 고유 PNG, 도형 대체 0건. 장기·흑백돌·쇼기 기본/승급·NPC 소환 상태를 1366 × 768 실제 보드에서 확인했다.
