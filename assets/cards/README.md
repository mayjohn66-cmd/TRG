# 캐릭터 참조 카드 삽화

2026-10-17: ACT_01~08·TRP_01~05·SUM_01~02의 전용 일러스트 15장을 연결했다. 이전 소품 시안 3장도 교체했다.

모두 1448×1086 PNG(4:3). ACT_01·04·07·08은 v0.2, 나머지는 v0.1. 엘레나는 결승선을 제거한 전진 장면, 벨리타는 작은 카드 탑, 리뉴아는 단독 캐릭터와 톱니바퀴 룰렛이다. 파일별 버전·SHA256은 [illustrations.json](illustrations.json)에 기록했다. 원작 캐릭터 참조 이미지는 배포하지 않는다.

2026-10-20 (v4.0 카드 개편): 카드 ID가 바뀐 4장은 같은 그림을 이름만 바꿔 쓴다 (ACT_05 → CNT_01, TRP_01 → CNT_02, ACT_01 → CNT_03, TRP_04 → TRP_C01). 새 카드 16장(CNT_04~07, ACT_10~15, TRP_06~08, TRP_C02~04)은 `tools/generate_emoji_icons.py`가 Noto Color Emoji(SIL OFL 1.1) 글리프를 카드 종류 색 배경 위에 얹어 만든 임시 그림이다 (같은 1448×1086).

현재 레지스트리는 32종이다. ACT_09는 전용 삽화가 없어 기존 이름 첫 글자 표식을 유지한다. 다른 카드 그림을 재사용하지 않는다.

2026-10-20 (캐릭터 삽화 1차): ACT_10~15의 임시 이모지 6장을 전용 캐릭터 장면으로 교체했다. 빠루(에르핀), 밑장빼기(셰이디), 더 월드(다야), 어디로든 문(실라), 알고리즘 밴(엘레나), 우노 스킵(버터). 원본은 1448×1086이며 기존 1024px 손실 압축·밉맵 설정을 유지한다. 현재 캐릭터 삽화 21장, 이모지 임시 그림 10장, 글자 폴백 1장이다. [검수 기록](../../docs/ui-trial/card-actions-v01.md).

2026-10-20 (캐릭터 삽화 수정): ACT_10은 헤일리의 양손 빠루 내려찍기, ACT_12는 리뉴아의 시간 정지, ACT_14는 아멜리아의 금지 도장, ACT_15는 앨리스의 금지 카드 포즈로 교체했다. 밑장빼기·어디로든 문은 유지했다. [수정 기록](../../docs/ui-trial/card-actions-v02.md).

공통 표시 코드는 `scenes/card_skin.gd`. 손패·드래그·발동 알림·미리보기·확대에서 같은 자산을 읽는다. 삽화 전체가 들어오도록 비율을 유지해 중앙 정렬하고 둥근 창 안쪽에 클립한다. 제목·효과·종류·사용 상태는 실제 게임 데이터와 ONE Mobile POP 서체로 표시한다.

게임 규칙·카드명·효과 문구는 이번 삽화 연결에서 변경하지 않는다. 다른 작업에서 추가된 ACT_04 긴급 로켓 부스터(+3) 변경을 함께 반영했고, 엘레나 전진 장면을 그대로 연결했다. 숨겨진 상대 손패와 보드상의 비공개 함정에는 앞면을 노출하지 않는다.

검수·치수: [전체 삽화 적용 v0.2](../../docs/ui-trial/card-illustrations-v02.md).
