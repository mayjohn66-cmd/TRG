# 카드 삽화 시범 적용

2026-10-17: 앞서 검토한 생성 삽화 3장을 원본 PNG 그대로 연결했다. 그림 안에 카드명·효과·숫자를 합성하지 않는다.

| 자산 | 카드 | 크기 |
|---|---|---|
| ACT_06.png | 이의 있음! 법전 파기 | 1448×1086 |
| TRP_03.png | 지뢰찾기 | 1448×1086 |
| SUM_01.png | 카탄의 도적떼 | 1448×1086 |

이 파일은 카드 전체 PNG가 아니라 삽화만 담는다. 제목·종류·효과·사용 상태는 실제 게임 데이터와 ONE Mobile POP 서체로 표시한다. SUM_01은 원작 캐릭터 확정 디자인이 아닌 익명 도적 피규어 시안이다.

현재 15종 중 위 3종에 개별 삽화가 있고, 나머지 12종은 이름 첫 글자 표식을 유지한다. 다른 카드의 그림을 돌려 쓰지 않는다. 지뢰 그림 양옆의 빈 타일에 숫자 1을 추가하지 않는다. 숫자 표시 타일 기능은 현재 규칙에 없다. 보드상의 비공개 함정 표식에는 카드 앞면을 사용하지 않는다.

공통 프레임 및 레이아웃 원본: `scenes/card_skin.gd`. 자세한 치수와 검수: `docs/ui-trial/card-skin-v01.md`.
