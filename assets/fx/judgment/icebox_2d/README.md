# 아이스크림 뽑기 — 2D 그림

사용자 요청에 따라 아이스크림 뽑기 소품은 기존 `icecream_bar.png`의 2D 붓 질감·갈색 외곽선을 기준으로 다시 제작했다. 3D 렌더 이미지를 변환한 것이 아니라 내장 image_gen으로 그린 새 2D 그림이다.

- `v1/icebox_ice.png`: 열린 파란 아이스박스와 얼음. 투명 배경, 글자 없음.
- `v1/wrapper_strawberry.png`, `wrapper_chocolate.png`, `wrapper_mint.png`: 개별 포장 그림. 문양과 색으로 구분하며 내용물과 분리한다.
- `../icecream_variants/v2/`: 딸기초코·초코·민트초코의 2D 내용물. 딸기초코는 기존 그림을 보존해 재사용했고 나머지 둘은 같은 그림을 참고한 새 변형이다. 나무 막대는 기존 먹기 연출처럼 코드에서 별도로 그린다.
- 그림·프롬프트·참고 원본 경로: `v1/manifest.json`.
- 배치: `scenes/icebox_pick_art.gd`. 사용자 참고 사진처럼 7개 포장의 기울기·높이·깊이를 다르게 두고, 뒤쪽 박스/얼음 → 개별 포장 → 불규칙한 앞쪽 얼음 → 앞벽/테두리 순서로 그린다. 앞쪽 얼음은 원본 얼음 윤곽을 따라 UV 마스크로 표시하며 포장 밑부분을 덮는다. 이미지 원본은 자르거나 덮어쓰지 않는다.
- 배치 확인: `tools/art/preview_icebox_2d.gd`. 각 포장은 독립 노드이므로 향후 꺼내기 연출에서는 선택한 포장만 이동할 수 있다.
- 현재는 그림 준비·배치 미리보기 단계다. 실제 꺼내기·포장 벗기기와 기존 먹기 연출 연결은 다음 작업에서 한다.
- 이후 게임 임포트 시 아이스박스는 최대 1024px, 개별 포장·내용물은 최대 512px·밉맵 기준으로 확인한다. 본체·포장·내용물을 단일 그림으로 합쳐 저장하지 않는다.
