# 규칙 도감 아이콘 v05 — 2026-11-28

도감 메뉴의 보드판·말(v04)과 나머지 다섯 분류의 선 굵기·명암·세부 밀도를 맞추기 위해 native image_gen으로 새 투명 PNG 5종을 생성했다.

- 도구: 1·2·3 눈이 보이는 상아색 주사위와 짧은 청록 굴림 곡선.
- 카드: 산호색 말 문양 카드와 작은 장갑 손.
- 법전: 큰 금색 저울 문양이 있는 청록색 책.
- 보급: 카드 1장과 물약 1개가 든 둥근 나무 상자.
- 초증강: 단순한 보라 결정·금색 번개·작은 주사위.

원본은 1254×1254 RGBA로 보존한다. 웹 임포트는 256px, 손실 품질 0.85, 밉맵을 사용한다. `regions.json`은 알파 0.08 이상인 실루엣에 5px 여유를 더한 정규화 표시 영역이며, PNG 픽셀을 자르거나 다시 그리지 않는다.

`manifest.json`에 생성 도구·전체 프롬프트·원본 경로·SHA-256·검수 결과를 기록했다. 보드판·말의 승인된 v04 그림과 기존 UI 치수·입력·게임 규칙은 유지한다. 공유 역할 `tool_swap`·`card_law`도 같은 새 그림을 참조해 기본 규칙과 도감 메뉴가 다시 달라지지 않게 한다.
