# 규칙 도감 아이콘 v04 복원

이 폴더는 이전 `trg-v13-card-art` 작업 폴더에만 남아 있던 승인된 PNG 15종이다. 2026-11-28 현재 버전 `dev`의 규칙 도감에 재연결했다. 새로 생성하거나 원본 픽셀을 수정하지 않았다.

- `manifest.json`: 기존 생성 프롬프트·원본 경로 및 복원 파일의 SHA-256.
- `regions.json`: 투명 여백을 뺀 정규화 크롭 범위. 임포트 크기가 바뀌어도 같은 실루엣을 표시한다.
- `rulebook_visuals.gd`: 장 버튼·목록·상세·보드 설명에서 같은 이미지와 크롭을 사용한다.
- 아이콘은 기존 설정(512px 제한, 손실 압축 0.85, 밉맵)을 유지한다. 인게임 발판 그림이나 게임 규칙은 바꾸지 않는다.
- `start`·`turn`·`tool_swap`·`card_law`는 기존 v02 시상대·정산·주사위·법전 그림을 재사용한다.
- 잡기 방어·공격 방어·함정 방어·만능 방어는 각각 잡기·공격·함정 카드·기존 CNT_01 삽화를 재사용해 구별한다 (`RULEBOOK_SPEC` UI-07).

검증: `tests/ui_rulebook_scroll_test.gd`는 실제 `_art()`가 v04 이미지를 반환하는지, 크롭 경계·클릭 통과·방어 5종 구분·PC/터치/한·영·일 도감 동작을 확인한다. 나머지 HANDOFF-012 UI 개선은 이 이미지 복원에 포함하지 않는다.
