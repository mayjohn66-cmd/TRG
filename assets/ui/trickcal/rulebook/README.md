# 규칙 도감 개별 아트 v0.1

화면 전체 시안을 통짜 배경으로 사용하지 않는다. PNG 9개를 각각 독립된 UI 노드에 연결한다.

| 역할 | 개별 리소스 | 논리 표시 크기 |
|---|---|---|
| 왼쪽 시작하기 | UI_RULE_START | 40 × 40 |
| 왼쪽 한 턴 | UI_RULE_TURN | 40 × 40 |
| 왼쪽 보드 | UI_RULE_BOARD | 40 × 40 |
| 왼쪽 잡기 | UI_RULE_CAPTURE | 40 × 40 |
| 첫 장 기물 능력 안내 | UI_RULE_PAWN_ABILITY | 36 × 36 |
| 첫 장 도구 교체 안내 | UI_RULE_TOOL_SWAP | 36 × 36 |
| 첫 장 카드·법전 안내 | UI_RULE_CARD_LAW | 36 × 36 |
| 첫 장 공정한 확률 안내 | UI_RULE_FAIR_ROLL | 36 × 36 |
| 설명장 위 도감 메달 | UI_RULE_BADGE | 80 × 96, 위치 (740, 112) |

- 각 PNG는 native `image_gen.imagegen`의 독립 생성 결과다. 원본 픽셀·알파를 그대로 보존한다.
- 원본은 1254 × 1254 RGBA. 런타임은 각 PNG를 256px 크기 제한, 무손실, 밉맵으로 가져온다.
- `.tres` AtlasTexture는 알파 20/255 이상인 실루엣에 원본 4px 여유를 더한 영역을 참조한다. 영역 값은 256px 텍스처 기준이며 임포트 크기를 바꾸면 함께 갱신해야 한다. PNG 자체를 크롭하거나 찌그러뜨리지 않는다.
- 실제 표시는 비율 유지 + 중앙 정렬. 이미지 노드는 입력을 가로채지 않는다.
- 왼쪽 목차의 선택 상태·버튼 클릭·본문 스크롤·페이지 전환·동적 글씨는 기존 UI 노드에서 처리한다.
- 역할 ID로 매핑하므로 다른 장의 동일한 임시 `crown`, `gear`, `sword` 도형을 전역 치환하지 않는다.
- 적용 범위는 위 9개 요소다. 두 번째 목차 그룹 및 다른 장의 안내 아이콘은 기존 구성으로 남아 있다.
- 생성 프롬프트·파일 해시·실루엣 영역: `manifest.json`, 새 배지 프롬프트: `badge-prompt.md`.
- 생성 색상에는 미세 농도 변화와 안티앨리어싱이 있어 엄격한 제한 팔레트 확정본은 아니다.
