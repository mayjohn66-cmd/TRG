# Rulebook artwork v02

Generated with the built-in `image_gen` tool with transparent backgrounds. The selected original PNGs are copied unchanged from Codex generated_images; manifest.json records hashes, full prompts, source locations and alpha bounds.

## Symbol roles

Fourteen independent images replace unrelated reuse of crowns, swords, generic buttons and numeric-only turn symbols. Six existing board/pawn images are reused for their actual matching concepts. Existing card, pawn, tool and augment catalog illustrations remain linked to their real data.

The neutral panel is used as a tinted nine-slice skin at existing colors. Paper and page ribbon are image textures. Technical clipping masks, selection outlines, table rules, text, and live board path arrows stay exact to layout/data. This changes presentation only.

## Import/display

Icons: 256 px engine limit, lossily compressed at 0.7 with mipmaps. Panel: 512 px. Paper: 768 px. Ribbon: 512 px. Source originals retain their full resolution and alpha. Normalized alpha regions in `scenes/rulebook_visuals.gd` exclude empty margins independently of imported dimensions.

## Validation scope

Only rulebook presentation is checked: script parsing and native Godot captures of ten chapters and entry details; navigation buttons, entry selection, scroll, keyboard chapter changes and close. The CI marker `[check:rulebook-art]` selects a rulebook parse check and web export without the full gameplay suite.
