# 로비 개별 이미지 v0.1

로비 화면을 통짜 이미지로 교체하지 않고, 기능 아이콘·메뉴 바탕·원형 받침을 각각 별도 리소스로 사용한다. 글씨는 ONE Mobile POP과 기존 Label 노드가 표시한다.

| 리소스 | UX 역할 | 논리 표시 크기 |
|---|---|---|
| UI_HUB_PRACTICE | 놀이터 / 말과 연습 표적 | 58 × 58 |
| UI_HUB_FRIEND | 친선전 초대 / 하트 열쇠 | 58 × 58 |
| UI_HUB_MATCH | 익명 상대 매칭 / 셔플 | 58 × 58 |
| UI_HUB_TIP | 도움말 / 새싹 전구 | 26 × 26 |
| UI_HUB_RULES | 규칙 도감 / 잎사귀 책 | 34 × 34 |
| UI_HUB_SETTINGS | 설정 / 둥근 톱니바퀴 | 34 × 34 |
| UI_HUB_NEXT | 선택·다음 팁 / 굵은 화살표 | 44 × 44, 팁 안에서는 30 × 24 |
| UI_HUB_MODE_GREEN / BLUE / PINK | 모드 선택 메뉴 바탕 | 640 × 124 이상 |
| UI_HUB_TIP_PLATE | 팁 안내 띠 바탕 | 560 × 56 이상 |
| UI_HUB_ICON_DISC | 모드·팁 아이콘 원형 받침 | 82 × 82 / 38 × 38 |
| UI_HUB_ROUND_BUTTON | 도감·설정 원형 버튼 바탕 | 56 × 56 |

- 닉네임 이름표는 녹색 메뉴 스킨을 높이 42px로 준비해 공유한다. 팁 넘기기 버튼은 같은 스킨의 높이 38px 버전이다.
- 아이콘/받침은 256px, 가로 스킨은 1024px 크기 제한으로 무손실 임포트하며 밉맵을 사용한다.
- 각 `.tres` AtlasTexture는 알파 24/255 이상인 영역에 원본 4px 여유를 더해 참조한다. PNG 원본은 수정하지 않았다. 원본 크기·영역·해시는 `manifest.json`에 기록했다.
- `HubArt.skin()`은 스킨 영역만 표시 높이에 맞춰 메모리에서 한 번 리샘플링한 뒤 중앙을 9-slice로 늘린다. 모서리 여백은 표시 높이의 0.48배다. PNG 파일 자체를 늘려 저장하지 않는다.
- 버튼 상태는 같은 스킨의 modulate로 표시한다: 기본 1.00, hover 1.07, pressed 0.90, disabled RGB 0.70 / alpha 0.65. 기존 통통 튀는 버튼 동작과 클릭 영역은 유지한다.
- 전체 아트는 native `image_gen.imagegen`으로 각각 생성했다. 이미지 모델 ID는 공개되지 않았다. 셔플 아이콘은 화살표별 색 연결을 한 번 수정했다. 원본과 수정 프롬프트를 모두 manifest에 보존한다.
- 프롬프트의 색상 토큰은 목표값이다. 생성 원본에는 안티앨리어싱과 부드러운 농도 변화가 있다.
- 캐릭터·로고·로비 배치·기존 작은 크림색 버튼은 기존 리소스를 사용한다.
- 검증: `UI_MENU_OK`, 1366 × 768 / 844 × 390 실행 화면에서 글씨 여백·끝 모서리·원형 받침·메뉴 배치 확인. GDScript 오류 없음.
