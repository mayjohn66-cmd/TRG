# 판정 카드 그림 v0.1

홀덤·화투·타로 판정 도구의 실제 카드 노드에 사용하는 개별 그림이다. 통짜 화면 이미지가 아니다. 원본 게임 규칙과 추첨은 `core_engine/tools/`가 결정하고 이 폴더는 표현만 담당한다.

| 파일 | 수량 | 원본 | 런타임 상한 |
| --- | ---: | --- | --- |
| `suits/SUIT_*.png` | 4 | 1254×1254 RGBA | 256px |
| `hwatu/HWATU_01.png`–`HWATU_12.png` | 12 | 1254×1254 RGBA | 256px |
| `tarot/TAROT_*.png` | 5 | 1254×1254 RGBA | 256px |
| `backs/*_BACK.png` | 3 | 1024×1536 RGB | 512px |

총 24장은 내장 `image_gen.imagegen`으로 생성했다. 생성 원본 픽셀을 그대로 보관하며, 런타임 크기 제한·무손실 압축·mipmap은 Godot importer가 처리한다. 배경 제거, 분할, 색칠 등의 사후 픽셀 편집은 하지 않았다. 생성 프롬프트·원본 파일·저장 경로·SHA-256·검수 기록은 [manifest.json](manifest.json)에 기록한다. 모델 이름은 도구가 공개하지 않는다.

화풍은 둥근 실루엣, 굵고 연속된 외곽선, 단순한 셀 명암과 따뜻한 파스텔 색상이다. 숫자·한글·로마 숫자는 이미지에 생성하지 않고 실제 게임 폰트로 그린다. 카드 프레임과 텍스트는 Godot UI이며, 문양·월별 소재·타로 물체와 뒷면은 생성 그림이다.

## 그림과 게임 ID

- 홀덤: 클럽·다이아·하트·스페이드 순서와 엔진의 2–A 랭크로 52장을 구성한다. A와 2–10은 실제 문양 개수를 지키며 J/Q/K는 큰 문자와 해당 문양을 사용한다.
- 화투: 12개월 소재를 공유하고, 각 패의 월과 광/열끗/띠/피는 엔진의 `ToolHwatu.card_type()`을 그대로 표시한다. 48장 각각의 전통 도안을 재현한 것이 아니라 현재 게임 규칙에 맞춘 간략한 카드다. 일부 월에는 엔진상 열끗이 두 장 존재한다.
- 타로: 광대(모자와 보따리), 전차(전차), 운명의 수레바퀴(바퀴), 매달린 남자(거꾸로 매달린 말), 세계(지구와 월계수) 5종이다. 선택되지 않은 네 장에는 앞면 그림 자체를 지정하지 않는다.
- 뒷면: 홀덤 녹색·클로버, 화투 붉은색·꽃, 타로 보라색·달. 모서리 알파는 런타임 전용 셰이더로 둥글게 제한한다.

화투 월별 소재는 [한국민족문화대백과사전 「화투」](https://encykorea.aks.ac.kr/Article/E0064919)의 한국식 순서(11월 오동, 12월 비)를 참고했다. 원격 이미지를 복제하거나 내려받지 않았다.

검수상 허용한 작은 차이는 광대 모자의 방울 3개, 세계의 두 큰 대륙과 작은 섬 1개다. 판정 정보를 뜻하는 수량은 아니며, 엔진의 카드 ID·랭크·패 종류에는 영향을 주지 않는다. 세부 기록은 manifest에 남긴다.

실제 배치와 연출 수치는 [판정 카드 연출 규격](../../../../docs/ui-trial/judgment-card-roll-v01.md)을 따른다.
