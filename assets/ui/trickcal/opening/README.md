# 레이스 시작 리본 v0.1

기존 오프닝의 화면 전체 갈색 패널을 개별 투명 PNG 그림으로 교체한다. 연두 리본, 크림색 글자 영역, 체크 깃발과 두 게임말을 그렸으며, 한글·영문은 ONE 모바일 POP 글꼴로 게임에서 별도 표시한다.

## 이미지 및 출력 규격

- `UI_RACE_START_RIBBON.png`: 2172 × 724, 3:1, PNG RGBA. 내장 `image_gen.imagegen`으로 1회 생성. 원본 픽셀과 알파 보존, 후처리 없음.
- 원본·프롬프트·해시·검수 기록: `manifest.json`, `prompt.txt`.
- Godot import: 무손실, 밉맵, 최대 2048px, 알파 가장자리 보정.
- 논리 화면 기준 최대 폭 960px, 화면 폭의 86% 이하. 원본 비율 유지 후 화면 가운데 배치.
- 중앙 글자 영역: x=폭의 28%, 너비=49%. 제목 54px, 부제 18px. 폭이 줄면 동일 배율로 글자도 축소.
- 시작 크기 0.88 → 1.0을 양 축에 동일하게 적용하여 그림이 세로로 찌그러지지 않는다.
- 기존 문구, 효과음, 약 1초 표시, 클릭 건너뛰기와 게임 시작 순서는 유지한다.

## 검증

실제 Godot 화면 1366 × 768, 1920 × 920, 1920 × 1061을 확인했다. 그림·제목·부제 겹침 및 외곽의 흰 매트가 보이지 않으며, 자연 종료와 클릭 건너뛰기가 입력 잠금을 해제한다. 생성 소스와 저장 PNG의 SHA-256이 일치한다. 알파 20 이상인 본체는 (67,111)–(2105,574)에 완전히 들어간다. 낮은 불투명도의 그림자가 캔버스 가장자리 일부에 닿는 점은 본체가 잘리지 않아 채택했다.

로컬 Windows 캡처 종료 시 기존 GLES 텍스처·자원 정리 경고가 발생한다. 신규 스크립트 파싱 오류 없음. 캡처는 로컬 실행 결과이며, 배포 후 브라우저 화면 확인과 구분한다.
