# Board skin v0.9

검토한 보드 시안을 실제 게임 렌더링에 연결한다. 판면은 텍스처, 29개 발판·경로·문양·선택 윤곽은 `scenes/board_skin.gd`와 `main_board.gd`의 실제 좌표로 출력한다. 카드 시안의 이미지/레이아웃은 이번 변경에 포함하지 않는다.

- `board_surface.png`: 내장 이미지 생성 도구로 제작한 글자·경로 없는 1254×1254 판면. 크림색 테두리와 녹색 내부 면을 사용한다. 확대 시안과 같은 원본을 그대로 재사용한다.
- `arrow_rounded.svg`: 사용자가 지정한 둥근 굵은 화살표를 수동 재구성한 단색 벡터 원본. 런타임은 동일한 베지어 좌표로 문양을 그린다.
- 논리 좌표는 `BoardLayout`의 0..28을 유지한다. 표시 좌표는 `0.08 + norm * 0.84`로 판 안쪽에 배치한다. 조준 궤적도 같은 변환을 사용한다.
- 일반/빵집·옷장/코너·중앙·출발의 판 좌표 직경은 0.068/0.078/0.104다. 주요 발판은 둥근 팔각형, 나머지는 원형이다.
- 기울임: 세로 배율 0.90, 먼 쪽 가로 배율 0.90. 평면 모드도 같은 스킨을 사용한다.
- 발판 앞면은 판면과 함께 투영한다. 문양은 발판 중심을 따라가되 화면상 가로·세로 같은 배율로 표시한다.
- 실제 판 크기에서의 두께는 `2.5 * span / 760 * depth`px다. 썸네일용 두께를 그대로 붙이지 않는다.
- 클릭 판정은 원형/팔각형의 투영 윤곽을 사용한다. 이동 예고·설치 타일 선택 윤곽도 같은 모양을 따른다. 함정 배지와 은신 정보는 기존 규칙을 유지한다.
- 기본 코너 방향: 5→20, 10→25, 15→16. `LAW_01` 공사 중에는 5→6, 10→11로 갱신한다.
- 하단 발판을 가리지 않도록 작은 굴림 버튼 중심 y를 511에서 491로 이동했다.

검증: 프로젝트 import, `ui_fx_test`(29개 중심 클릭·윤곽 경계·문양 비율·교칙 화살표 포함), 기본 및 기울임 모드의 한 판 `ui_smoke` 통과. 자동 배포는 저장소의 전체 테스트와 웹 export를 다시 실행한다.
