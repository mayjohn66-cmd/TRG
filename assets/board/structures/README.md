# 설치형 기물 이미지

기존 코드 도형 두 종류를 다른 보드 기물과 같은 굵은 외곽선·광택 셀 셰이딩의 투명 이미지로 표시한다.

- `HOTEL.png`: 모노폴리 카가 설치하는 통행료 호텔. 크림색 건물, 붉은 지붕, 밝은 창, 출입구 위 금화로 표현한다. 원본 1086×1448 RGBA.
- `MINE.png`: 필살기로 설치하는 공개 지뢰. 짧고 둥근 가시, 검은 몸체, 빨간 경고등, 노란 받침 패널로 표현한다. 원본 1274×1235 RGBA.

두 이미지는 각각 built-in `image_gen.imagegen`으로 생성했다. 원본 픽셀을 수정하지 않고 복사했으며 생성 경로·최종 프롬프트 전문·SHA-256은 [source.json](source.json)에 기록했다. 이미지 모델 ID는 도구가 공개하지 않는다.

런타임은 최대 256px, lossy 0.85, mipmaps와 알파 경계 보정을 사용한다. `MainBoard.BoardStructure`는 `PawnArt.load_sprite`의 알파 실루엣 영역을 활용하여 비율을 유지한다. 호텔은 최대 32×40px, 지뢰는 30×27px이며 하단이 설치 칸에 닿는다. 플레이어 색 원판과 그림자, 지뢰 경고등의 맥동은 별도로 그린다. 설치 시 솟아오르는 기존 연출과 말이 앞에 그려지는 순서는 유지한다. 코드 모형은 파일이 없을 때만 폴백한다.

표시 조건은 그대로다. 호텔과 **공개** TRP_03만 모형이 보이며, 카드로 설치한 은신 지뢰에는 모형이 생기지 않는다. 함정 타일 심볼과 게임 규칙은 변경하지 않았다.

네 색의 호텔·공개 지뢰 8개, 말과 같은 칸의 겹침, 보드 두 시점, 원본 알파·크기 제한·정확한 이미지 로드·은신 지뢰 비노출·소모된 호텔 제거를 native Godot에서 확인했다. 캡처와 검증 로그는 작업 산출물 `outputs/structures-art-v01/`에 있다.
