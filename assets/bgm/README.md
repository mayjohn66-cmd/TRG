# 배경음 폴더

`<이름>.ogg` (또는 mp3/wav)를 넣으면 `Sfx.bgm_play(&"이름")`으로 재생할 수 있습니다. 출처는 루트 `CREDITS.md`에 기록하세요.

`lobby_daylife.ogg`: 사용자가 지정한 EPIDGames 공식 DayLife 영상의 약 40.43초 반복 구간. 시작 메뉴와 친선/랜덤 매칭 로비에서 연속 반복하고, 대전 입장 시 정지한다. 설정의 배경음악 크기·전체 음소거를 따른다. 출처 및 처리 기록은 `docs/ui-trial/lobby-daylife-bgm-v01.md` 참고.
