Licensed under SIL Open Font License 1.1; full license: `result/bangers-OFL.txt`.

Derived from the existing `result/bangers.ttf`, which remains unchanged. Keeps
the original decimal outlines, advance widths, ascent/descent and hinting;
only 7 receives a small slanted middle crossbar matching the comic typeface.
The renamed derivative family/PostScript name is TRG Comic Result Digits /
TRGComicResultDigits. It contains decimal glyphs only (approximately 7 KB).

`ResultTypography` applies it only to the result screen's existing Bangers
labels. All other characters use the existing typeface. General UI, tool
result captions and text sizes retain their original fonts and dimensions.
Rebuild: `tools/art/build_result_digits.py`; provenance and hashes:
`TRGComicResultDigits-manifest.json`.
