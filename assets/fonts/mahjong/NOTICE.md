# TRG Mahjong Glyphs

마작 패 표면의 `一二三四五六七八九萬發中`과 공백만 포함하는 4,956바이트 글꼴이다. 일반 UI에는 기존 ONE Mobile POP을 계속 사용한다.

- 원본: [Google Fonts의 Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp)
- 다운로드: `NotoSansJP[wght].ttf`, 2026-10-18
- 원본 SHA-256: `c2f3b4d463500a2ddcd3849cded1fceeb9fd6d1c32e6cbecd568453ba50fc68f`
- FontTools 4.67.0으로 weight 700을 고정하고 필요한 글리프만 남겼다.
- 수정 글꼴 이름을 `TRG Mahjong Glyphs Bold`로 변경했다. 원본 저작권·라이선스 메타데이터를 유지했다.
- 라이선스: 동봉한 [SIL Open Font License 1.1](OFL.txt).

플레이어의 운영체제 글꼴이나 웹 외부 폰트 요청에 의존하지 않는다.
