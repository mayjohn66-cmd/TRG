# TRG Gothic Bold (TRGGothic-Bold.ttf)

- 원본: NanumGothic Bold (NAVER, SIL Open Font License 1.1, Google Fonts 배포본)
- 변경: 게임에서 쓰는 글자(ASCII, KS X 1001 한글 2,350자, 한글 자모, 게임 문구·데이터에 쓰인 모든 글자)만 남긴 서브셋. 힌팅 제거.
- 원본 글꼴에는 예약 글꼴 이름(Nanum, NanumGothic 등)이 있어, OFL 조건에 따라 변경본의 글꼴 이름을 "TRG Gothic"으로 바꿨다.
- 라이선스 전문: 같은 폴더의 `OFL.txt` (SIL Open Font License 1.1).
- 용도: 작은 글자(13px 이하 라벨, 액션 로그, 굴림 패드 안내)가 ONE Mobile POP에서 뭉개져 보여 대신 쓴다. 이 서브셋에 없는 글자는 NanumGothic Regular로 대체된다.
