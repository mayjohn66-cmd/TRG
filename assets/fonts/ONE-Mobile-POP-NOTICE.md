# ONE 모바일 POP체

- 제작·권리자: ㈜원스토어
- 공식 안내: https://www.onestorecorp.com/sv/fordev_font/
- 공식 배포 파일: https://www.onestorecorp.com/assets/fonts/ONE%20Mobile%20POP.zip
- 포함 파일: 공식 배포본의 `ONE Mobile POP OTF.otf`를 내용 변경 없이 `ONE-Mobile-POP.otf`로 저장.
- 용도: 게임 UI 기본 글꼴. 폰트 단독 판매·배포용 패키지가 아니다.
- 적용일: 2026-10-16
- OTF SHA-256: `7e8c6c5d7bdf4b9e3f171b8e5577ab36cc780735d978db08006fae8306e6bae2`

`game_ui_font.tres`가 ONE 모바일 POP체를 기본으로 사용한다. 이 글꼴에 없는 문자에는 기존 나눔고딕을 보조로 지정했다. 나눔고딕의 이용 조건은 같은 폴더의 `OFL.txt`에 있다.

기존 UI의 글자 크기와 텍스트를 유지하고 기본 글꼴만 교체한다. 새 글꼴의 폭·높이에 따라 레이아웃을 실제 렌더링에서 확인한다.
